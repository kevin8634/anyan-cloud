## 二、画质升级方案（不换引擎）
按「低 / 中 / 高 / 极致」画质档分级，2060 6G 目标：高档 1080p 稳 60 帧，极致档 45 帧以上。低档保持现状，保证评委电脑都能跑。

| 项 | 做法（Three.js 现有能力） | 档位 |
|---|---|---|
| 渲染后端 | WebGPURenderer（three r16x+）优先，不支持自动回退 WebGL2；先做开关，验证无误再默认 | 高/极致 |
| 色调与调色 | ACES/AgX 色调映射 + 场景分区 3D LUT 调色（沉钟海岸青冷、熔炉橙暖、深渊紫黑） | 全部 |
| 环境光照 | 每张地图一张 HDRI/烘焙环境贴图 + PMREM，替代纯平行光补光；关键场景烘焙光照贴图/AO 贴图 | 中起 |
| 阴影 | 级联阴影 CSM（近处清晰、远处不糊）+ PCF 软阴影；角色接触阴影 | 中起 |
| 环境光遮蔽 | GTAO/SSAO 后期，石缝、墙角、地面接触更实 | 高起 |
| 泛光与光效 | 选择性 Bloom（只让熔炉、符文、武器光效发光），避免全屏发白 | 中起 |
| 体积光与雾 | 光束（god rays）+ 高度雾 + 分层薄雾，天顶破口月光、熔炉热浪 | 高起 |
| 水面 | 平面反射/SSR + 法线流动 + 焦散贴图 + 岸边泡沫（沿用 sea5 成果升级） | 高起 |
| 抗锯齿 | SMAA（中）/ TAA（高起），解决武器边缘闪烁 | 中起 |
| 景深与镜头 | 地标展示镜头、铸造成形、选角界面用 DOF + 暗角 + 轻微色差 | 演出时 |
| 资产 | 所有模型 PBR 贴图（基础色/法线/粗糙/金属/AO），KTX2 压缩纹理 + Draco/Meshopt 几何压缩，LOD 分级 | 全部 |
| 粒子 | GPU 粒子（火星、灰烬、能量池上升光点、水滴涟漪），WebGPU 下用 compute | 高起 |

性能护栏：画质档自动检测 + 手动切换；每项可单独关；极致档才开 TAA+GTAO+体积光全套。每档出对比截图。
