## 三、B 技能替换联动规则（全职业：天赋 / 英灵 / 装备）

规则「槽位继承 + 元素转译」：
1. 天赋点名技能（skillIds）→ 已按槽位生效（v0.7.4），保持。
2. 本系元素天赋（match.elements）→ 除了对该元素技能生效，也对「原技能是该元素的槽位」生效。例：炽焰「炽热」火焰技能伤害，技能 1 换成闪电链后仍加成闪电链。
3. 天赋附加的持续伤害 / 地面区域，元素随当前技能改变，并按命名表改名：燎原在闪电链上 →「雷殛场」（自然 / 雷）、冻伤在火焰新星上 →「灼伤」等。
4. 代码判定的元素关键（炽燃 = 火焰暴击、爆燃 = 火焰暴击）同样认「槽位原元素」。
5. 装备：skillIds 词条随槽位（已有）；元素词条（火焰伤害 +X%）是元素构筑，不随槽位；符文绑定单技能，不随槽位。
6. 英灵：无槽位/技能 ID 效果，无需改；以后新增英灵效果按本规则写。
7. 以后新增任何「点名技能 / 元素」的天赋、英灵、装备，都必须过 dev/talent_audit 与联动测试。

受影响节点（本体）：炽热、余烬、炽燃、燎原、熔火陨星、冰脆、寒流（关键）、刺骨、冻伤、奥术易伤、硝石、爆燃、冲击波、腐蚀、蚀骨、焦土。

## 四、C 元素变种命名

原则：一眼看出属性，用意象字而非「火焰·」直译；两字前缀或整名，同一属性用同一组字。
| 属性 | 用字 | 持续伤害名 | 地面名 |
|---|---|---|---|
| 火 | 焚 / 燎 / 烬 | 灼烧 | 燎原 |
| 冰 | 霜 / 凛 / 霰 | 冻伤 | 霜原 |
| 雷（自然·雷） | 霆 / 殛 / 掣 | 感电 | 雷殛场 |
| 毒（自然·毒） | 蚀 / 瘴 | 蚀毒 | 瘴沼 |
| 暗影 | 冥 / 晦 | 暗蚀 | 冥土 |
| 奥术 | 星 / 辉 | 星蚀 | 星域 |
| 物理 | 裂 / 创 | 流血 | 碎地 |

示例：烈焰弹带燎原 + 换闪电链 →「掣雷链·雷殛场」；闪电链火焰符文「火链」→「燎链」。全职业完整命名表随实现一起出（docs/设计/元素变种命名表.md）。

## 七、多重元素附加（2026-10-30 15:55 用户定）
- 技能被附加多种元素时，每种元素是独立一段伤害：独立暴击、按该元素抗性结算、各自命中特效，不再“转成某一种元素”。
