# 二、两种打开方式的区别

| 打开方式 | 能否在线 AI 生成 | 说明 |
|---|---|---|
| 直接双击 `暗岩传说_深渊回响_评委版.html`（本地版） | 不能 | 只能从预置武器库挑一把，或「导入本地 GLB」。铸造台顶部显示「本地版」。不会发起任何扣分请求。 |
| 双击 `启动铸造服务.exe`（本机服务版） | 能 | 程序在本机 127.0.0.1 开一个小服务，托管同一份游戏并替浏览器转发 Aholo 请求。铸造台顶部显示「本机铸造服务 · 在线生成」。 |

为什么本地版不能直接在线生成：Aholo 接口的预检请求允许跨域，但**正式响应不带跨域许可头**，浏览器直连时请求已经到达服务端（**会扣积分**），却拿不到任务号和模型。所以本地版里彻底禁止发起生成，在线生成只能通过服务端中转（本机「启动铸造服务」或魔搭 server.js）。

# 三、新工具「启动铸造服务」使用教程

## 1. 准备
- 把评委压缩包**完整解压**。`启动铸造服务.exe` 必须和 `暗岩传说_深渊回响_评委版.html`、`music` 文件夹放在同一目录。
- Windows 不需要安装 Node、Python 或其他软件。macOS / Linux：安装 Node.js 18 以上，在该目录打开终端运行 `node 启动铸造服务.js`。
- 准备一个自己的 Aholo（Lux3D）API Key，账户里有积分（每次约 13 积分）。

## 2. 启动
双击 `启动铸造服务.exe`，会弹出一个黑色窗口并自动用默认浏览器打开 `http://127.0.0.1:17860/`（端口被占用会自动换成 17861、17862……，以窗口里「游戏地址」一行为准）。浏览器没自动打开时，手动用 Chrome / Edge 打开那个地址。

![启动铸造服务：黑色窗口显示游戏地址](real_tool_1_started.png)

**Windows 安全提示**：出现蓝色「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。杀毒软件拦截选「允许 / 信任」（程序暂未数字签名）。防火墙询问选「允许」或「取消」都可以——服务只监听本机 127.0.0.1。

## 3. 填 Key 并测试
进入游戏，打开铸造台，确认顶部是「本机铸造服务 · 在线生成」。在底部「本机铸造服务的 Aholo Key」粘贴 Key → 点「保存并测试」（只查询任务列表，**不扣积分**）。出现绿色「Key 正确……」即可。勾选「记在本机」下次免填（只保存在本机用户目录 `.darkrock_forge` 里）；不想留下点「清除」。

![Key 测试通过：绿色提示](real_2_key_green.png)

## 4. 铸造
输入一句话描述武器 → 点「铸造」。约 30–90 秒后模型自动取回、播放成形演出、换到主手并收进「我的铸造品」，不用手动操作。中途关掉网页也不要紧：下次打开铸造台自动续取，**不会重复生成、不会重复扣积分**。

## 5. 退出
玩的过程中别关黑色窗口（可最小化）。退出时先关游戏网页，再关黑色窗口（点 × 或按 Ctrl+C）。通过 127.0.0.1 打开的游戏与直接双击 html 的存档互相独立。

## 6. 常见提示对照
| 提示 | 含义 / 处理 | 扣分吗 |
|---|---|---|
| 还没有填写 Key | 在铸造台底部粘贴 Key 并「保存并测试」 | 不扣 |
| Key 错误或已过期 | 到 aholo3d.cn 核对后重新粘贴 | 不扣 |
| 本机铸造服务连不上 Lux3D | 电脑没联网，或防火墙 / 代理拦截了程序 | 不扣 |
| Lux3D 接口繁忙或超时 | Aholo 那边忙，稍后再试 | 不扣 |
| 连不上本机铸造服务 | 黑色窗口被关了，重新双击启动 | 不扣 |
| 没有找到游戏页面 | exe 和 html 不在同一文件夹 | 不扣 |
| 启动失败：端口都被占用了 | 重启电脑再试 | 不扣 |
| 今天的在线铸造已用完 | 本机服务每天最多 30 次，次日恢复 | — |
| 生成超时 / 模型下载失败（任务已保留） | 已扣的积分不白扣，下次打开铸造台自动续取 | 已扣 1 次 |

**安全设计**：Key 不在程序里、不在压缩包里，只由玩家在铸造台填写、只发给本机服务，由它转发到 Aholo 官方接口。每次生成前先测 Key，测不通不发起生成。服务只接受 127.0.0.1/localhost 的同源 JSON 请求，防止其他网页借用。

# 五、问题与建议

## A. 本地（评委包）问题

- **L1 武器类型跟主手走（已在修）**：提示词写「长剑」，生成的是单手斧。改为按提示词识别类型；识别不到才按主手；与主手不同类的成品只收进「我的铸造品」，不硬套。
- **L2 装备图标 / 名称 / 手持模型不一致（已列入开发计划）**：如图标是匕首、名字叫法杖、手里又是别的模型。计划全量核查装备表和掉落表，加自动校验脚本逐件修复并截图验收。
- **L3 一条模拟用例失败**：「本地版测试 Key 成功 → 绿色」用的是假接口返回；现实中真实 Aholo 响应不允许跨域，本地版只会显示红字，这条绿色路径实际碰不到，不影响评委。原因未定位，排查脚本已写待跑。
- **L4 exe 未数字签名**：Windows 会弹 SmartScreen、部分杀毒会拦截，说明里已教「更多信息→仍要运行」。彻底解决需要代码签名证书（见 C）。
- **L5 exe 体积约 110 MB**：内含 bun 运行时。可接受；若要瘦身需改写为 Go 等原生程序（约 1 天）。
- **L6 沙箱测试环境不稳定**：本轮沙箱重置 1 次，导致回归中断重跑。只影响开发效率，不影响产品。

## B. 魔搭创空间：需要拆分 / 绕开的问题

- **M1 网关单请求约 120 秒硬上限、下行约 0.3 MB/s**：生成本身 30–90 秒，加下载会超时。已拆成**异步任务**：提交秒回任务号 → 轮询状态 → 模型**分块取回**、可断点续取。
- **M2 原始 GLB ~10 MB**：服务端先把贴图压成 1024 JPEG（~0.9 MB）再分块下发，否则下载要半分钟以上。
- **M3 页面本体 ~130 MB，魔搭构建不拉 Git LFS**：游戏页面拆成 17 个 gzip 分片（`public/page.gz.partNN`），server.js 启动时拼接。
- **M4 魔搭 git 推送常 504**：需逐提交重试推送。
- **M5 /tmp 重启丢失**：任务表与模型改存持久盘 `/mnt/workspace/forge_glb`（v1.2.47 已做，魔搭尚未部署该版）。
- **M6 免费 2 核 8G、全站限额**：每天全站 5 次、每 IP 2 次（建议比赛期 DAILY_LIMIT 调到 10）；Key 由你在创空间密钥 AHOLO_API_KEY 设置，用你的积分。
- **M7 私有空间需登录才能访问**，沙箱无法实测，需你在浏览器验证后再决定是否公开。
- **M8 魔搭目前仍是 v1.2.46**，按规则等你说「上魔搭」再一次性部署完整版（含轻量化比赛版、定时领取、持久盘、版本自检）。

## C. 想做到「生成完直接生效」需要的支持

目标：玩家输入一句话 → 无需任何额外程序、无需等待领取，模型直接出现在手上。按影响从大到小：

1. **Aholo 正式响应加跨域许可头（最关键）**：GET/POST 正式响应带 `Access-Control-Allow-Origin`（预检已经有了，只差正式响应）。有了它，直接双击 html 就能在线生成，不需要「启动铸造服务」，评委零门槛。建议用已给你的 CORS 说明信向 Aholo 官方反馈。
2. **Aholo 提供临时令牌或限额子 Key**：让网页只拿到一次性 / 限额令牌而不是主 Key，评委无需自己的 Key，也不怕泄露。
3. **生成完成回调（Webhook）或更快的模型档**：省去轮询；若有 ≤30 秒的快速档，体感就是「即时生效」。
4. **服务端直接返回压缩版 GLB（1024 贴图）**：省掉 10 MB 下载与本地压缩，魔搭网关下也能一次取回。
5. **魔搭侧**：放宽单请求超时或支持流式下载；公开空间 + 持久盘；比赛期提高每日次数。
6. **代码签名证书**（约数百元 / 年）：exe 不再被 SmartScreen / 杀毒拦截。

在 1 未实现前，当前最稳妥方案就是：**评委包内「启动铸造服务」+ 评委自填 Key**（已验收通过），魔搭线上作为备用演示，比赛展示以视频 / 本地版为主。
