# 铸造台三段式 CG 整合方案（CG-1 全屏版）· 2026-10-31 待 Rhett 确认

素材：incoming/forge_cg_v1（f1 投纸 / f2 循环 / f3 出炉 / f4 熄炉，Seedance 2.0，1280×720，各 5.06 秒，h264+aac）。

## 现有流程（smithy.ts / forgeshow.ts）
1. 快速铸造面板输入描述 → 点「铸造」→ 关面板，forgeshow 全屏 WebGL 演出：熔岩翻腾（brew，至少 2.6 秒）。
2. smithyRun：有 pending 先续取；在线 POST /forge → 每 3 秒查状态 → 分块下载 → 登记 GLB；底部字幕显示「排队 / 生成中 xx 秒 / 取回 x/y MB」。
3. 拿到模型 → reveal：溶解成形 → 三记锻锤 → 转一圈飞向角色 → 换上主手（同族武器）→ 分享卡。
4. 失败 / 超时 / 本地版：自动从武器库挑最接近的一把，照样 reveal，字幕「炉火未通 · 从武器库取出一把」；下载失败保留 pending 下次续取。
5. 魔搭定时领取模式：提交后不演出，面板显示「约 2 分钟后来取」倒计时，回来取回时播成形。

| 字幕里的秒数 / MB | 只写阶段词（排队中 / 炉火锻造中 / 出炉），配铃声次数 + 火星强度 |

- 切换：只在 ② 的循环切点（约每秒）切，0.3 秒交叉淡入（两个 video 元素交替）；GLB 解析完才进 ③；结果在 ① 播完前就到 → ① 直接接 ③。
- 续传：smithyPending 有任务时打开铸造台 → 从 ② 开始。
- 本地版 / 评委包（无服务端，武器库秒出）：① → ③ → 成形，评委路线约 10 秒一套完整演出。
- 魔搭定时领取：① + ② 播约 10 秒后收起，显示倒计时；回来领取时播 ③ + 成形。
- 可跳过：① / ③ 点击或 Esc 跳到下一段；② 不可跳（本来就在等）。
- 兜底：视频解码失败 / 被浏览器拦自动播放 / 低端机 → 退回现有熔岩 brew，不影响铸造。
- 声音：视频自带音频，播放时游戏音乐压低，结束恢复。
