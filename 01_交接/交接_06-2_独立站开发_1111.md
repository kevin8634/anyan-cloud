## 4. 中间件与恢复（原路径 = 旧项目 /workspace/projects/<项目id>/work/；新账号用新项目 work/ 目录，下面记为 $W）
```bash
R=/workspace/work/anyan-cloud/02_工程包/06_变现/独立站
W=/workspace/projects/<新项目id>/work && mkdir -p $W && cd $W
md5sum $R/工程/*.tgz $R/中间件/*.tgz $R/产物/*.tgz   # 对照第 3 节
tar xzf $R/工程/site_本地工程.tgz          # → $W/site

git bundle verify $R/工程/anyan-tome_root..main_6ad4326.bundle
cd $W/site && node --version   # 需 Node ≥ 22.5；站点零依赖，无需 npm ci
npm test                       # 后端 e2e
pip install brotli             # 字体裁剪 tools/subset-font.py 需要
```
