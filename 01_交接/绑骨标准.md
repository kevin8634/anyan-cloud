# 模型绑骨标准（Rhett 定，2026-11-01；11-02 16:40 修订）

> **11-02 16:40 Rhett 定（最高优先，覆盖下文一切冲突写法）**
> 1. **人物 / 人形角色（玩家职业、NPC、人形怪、人形首领）一律走 Lux3D 绑骨，按 Lux3D 官方标准执行**；不再使用 Mixamo（免费绑骨已从计划删除），也不用本地精绑顶替人形角色。
> 2. Lux3D 标准：**严格 T-Pose**（双臂水平伸直与肩同高、手掌朝下、五指张开，双腿分开与肩同宽、双脚完整可见）；类人形；Y 上 Z 前；无动画；空手、服装贴身、无超出人形轮廓的大附件。**A 字不合格**（11-01 三次失败的主因，11-02 萨琳再次因 A 字失败）。
> 3. 链路固定：严格 T 字设定图（单图）→ **逐张核对姿势** → 四视图 → G1 多图生 3D → 减面绑骨件（tools/lux3d-riginput.mjs，约 1.5 万面 <1 MB）→ humanoidAutoRig → 权重转移到显示件（tools/lux3d-weightxfer.mjs）。
> 4. **设定图不是严格 T 字，一律不得进入四视图 / G1 等后续付费步骤**：在批准额度内重出，或停手报 Rhett。每个付费步骤前对照本标准过目，不合格不往下走。不乱花积分。
> 5. 武器、灯杖、长袍下摆、披风等绑骨后本地加（刚性件挂手骨 / 附加蒙皮下摆），只改贴图不影响权重。
> 6. **11-02 16:44 Rhett：之后凡需绑骨一律走 Lux3D。** Lux3D 绑骨官方只支持类人形；非人形（如莫尔维斯鮟鱇）怎么处理须先报 Rhett 定，不得自行改用本地精绑或其他方案（11-02 16:47 Rhett 定：莫尔维斯按原计划本地精绑 rigfine2 + 逐招关键帧）。
> 8. **两道关卡（防绑骨失败）**：① 设定图人工核对严格 T 字；② G1 出件后、提交绑骨前，量绑骨件包围盒「双臂展宽 / 身高」≥ 0.9（T 字约 1.0；A 字约 0.75，如萨琳 A 字件 0.76），并出正面图核对手指分开、双腿分开、无大附件。任一不过就停，不提交绑骨。
> 7. 归档：不合格（A 字等）的设定图 / 四视图 / G1 件一律移入 `_archive_Apose/` 归档，不删除、不再使用。

适用：主线、DLC、长副本 raidA 分支及以后所有窗口 / 账号。

## 规则
1. 所有会动的角色模型（怪物、首领、NPC）必须**先绑骨、验收动作后**才能进游戏。不再接受「静态模型 + 整体晃动 / 顶点波浪」充当动作。
2. Lux3D 生成的模型本身**没有骨骼和权重**，且整只是一张连通皮（武器常和手、腿熔在一起）。纯程序化自动绑骨（v1.2.73 procrig 自动版）在这类模型上会拉出长三角，已被 Rhett 否决，只能当低画质 / 临时回退。
3. 合格绑骨的做法（11-02 起：人形 = 只走 Lux3D；非人形 = 本地精绑；Mixamo 已删除）：
   - **精绑（本地，不花积分）**：逐只手工摆骨 → 按身体区域分配候选骨 → 切掉跨区粘连三角（手-腿、武器-腿）→ 武器整块刚性绑手 → 区域内平滑权重。工具 tools/rigfine/（rigfine.py 出权重 JSON；view.html + shoot.mjs 独立预览出 GIF）。
   - ~~Mixamo 人形自动绑骨~~：**11-02 Rhett 删除，不再使用。**
   - **Lux3D 人形自动绑骨 + 动作迁移（付费，须 Rhett 事先批准并记台账）**：humanoidAutoRig 出带骨骼蒙皮的 GLB，再用 animationRetarget 套 85 个预置动作（Walk_Loop / Sword_Attack / Death01 / Hit_Chest / Zombie_Walk_Fwd_Loop / Spell_Simple_* 等）。只支持人形，带资格校验；武器熔连的模型建议先 part-split 拆件。
4. 验收：每只模型出一张 GIF（待机、走、预备→出手→收招、受击或施法、死亡），发 Rhett 看过才接入。拉伸检查：test/rig73_dbg.mjs 的边拉伸统计。
5. 新生成的人形模型：提示词里要求 **严格 T 字姿势（不是 A 字）、空手、服装贴身、四肢不贴身**；设定图出来先核对，不合格不进后续付费步骤。

## 小怪 / 首领分级（Rhett 11-01 13:55 定）

- **小怪**：本地精绑（tools/rigfine/rigfine2.py + cfg/<模型>.py）+ 通用动作模板（待机/走/攻击/死亡，漂浮体用裙摆骨链）即可，达到摆渡死渡、断绳残响 GIF 的水准就算合格。
- **首领（BOSS）**：必须精细化。每个技能、每种攻击都要有自己专属的动作（含前摇、出手、收招），不同技能之间不能共用同一段动作，也不能只换速度/幅度凑数；死亡、转阶段、登场也单独做。验收时按「技能表 ↔ 动作表」逐条对 GIF。

## Lux3D 自动绑骨资格校验记录（规则，11-01 Rhett 定：边做边记）
每次 Lux3D 绑骨都在下表登记：模型、外形特征、面数、结果、实际扣分。生成前按「预检清单」自查。

### 预检清单（生成设定图/模型前就要满足）
1. 标准人形，**严格 T 字姿势**（A 字不合格）：双臂水平与肩同高，双腿分开、脚可见。
2. 服装贴身：窄袖、下摆不过大腿中部、两侧开衩露腿；禁止拖地长袍、宽袖、披风、飘带、碎布条、锁链缠身。
3. 空手：武器、提灯、盾牌等全部不带，进游戏后另做刚性件挂手骨。
4. 手指分开，脚掌完整；不要纯骷髅细骨（疑似人体检测失败，待验证）。
5. 顺序：生成 → 减面（约 1.5 万面，tools/lux3d-riginput.mjs，普通 GLB，<1 MB）→ 贴图局部重绘 → 最后绑骨。
   绑骨权重按顶点记录，绑骨之后任何改形体/改顶点的操作都要重绑；只改贴图不影响。减面过狠会把手指、双腿粘连，导致校验失败。
