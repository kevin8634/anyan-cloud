暗岩传说：深渊回响 · Windows 桌面版（测试版，分支 wip/electron1109）

怎么运行
1. 把整个 zip 解压到一个本地文件夹（不要直接在 zip 里双击；路径里有中文也没关系）。
2. 双击 DarkRock.exe。第一次运行 Windows 可能弹「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（没签名的测试版都会这样）。
3. 窗口默认最大化。F11 或 Alt+Enter 切全屏，F12 打开开发者工具（排查用），Ctrl+R 重载。

说明
- 内容就是比赛版网页（本体 + DLC1），游戏代码没改，只是换成独立窗口运行，强制开 GPU 加速、优先独显。
- 存档存在 %APPDATA%\暗岩传说 里，和浏览器里玩的存档不互通。
- 每次启动会在 %APPDATA%\暗岩传说\launch.log 记一行「页面载入完成用了多少毫秒」，测完可以把这个文件发回来。
- 画面异常可以试试用命令行启动：DarkRock.exe --angle=gl（或 --angle=vulkan）。
