# 《暗岩传说：深渊回响》模型替换计划（2026-10-23 起）

> 依据：`docs/plan/模型替换调研_2026-10-22.md`、`docs/plan/DLC1_交接计划.md`「v0.9.8 模型替换一期」。
> 原则：写实比例（Quaternius Universal 体系 / Bestiary），**不要 Q 版、不要拼装几何体**；先建适配层，再按模块逐块替换；每块约 8% 日额度、可独立发布；任何一块都能在设置里切回旧模型（KayKit）。
> 版本号：在 v1.1.2 之后用 **v1.2.0-m1、v1.2.0-m2 …**（m = 模型模块），全部做完合并为 **v1.2.0**。DLC 进度号（d1.10 起）不受影响，模型模块和 DLC 模块可以穿插发布。

## 统一技术方案（适配层，m1 建立，后续模块复用）

| 项 | 做法 |
|---|---|
| 骨骼统一 | `web/rig.ts`：逻辑骨骼名（`head` / `chest` / `hips` / `handR` / `handL` / `footR` / `footL` / `back`）→ 每套模型的实际骨骼名映射表。KayKit 映射到 `head` / `chest` / `hips` / `handslotr` / `handslotl`；Quaternius UBC（Mixamo 兼容 53 骨）映射到 `Head` / `Spine2` / `Hips` / `RightHand` / `LeftHand`。gear.ts、ClassExt.dress、包挂件（渊噬部件：头 / 胸 / 右手 / 胯）一律走逻辑名，**旧调用的 KayKit 名自动翻译**，所以 DLC 两职业挂件不用改代码。 |
| 动画重定向 | 7 个逻辑动作：待机 / 走 / 跑 / 攻击 / 施法 / 受击 / 死亡。每套模型一张「逻辑动作 → 片段名」表；UAL 片段按骨骼名重定向（同名骨直接复用 AnimationClip，KayKit 继续用自带片段）。找不到的动作回退到最近的（施法→攻击，受击→待机）。 |
| 武器挂手骨 | 挂件挂在逻辑 `handR`/`handL`，每套模型带一个「手骨本地偏移 + 旋转 + 比例」校准值，保证剑柄在掌心。 |
| 压缩 | glTF 用 meshopt（`gltfpack -cc -tc` 或 `meshoptimizer` 的 EXT_meshopt_compression），贴图统一 512（手机 256）；运行时 `MeshoptDecoder` 解码。 |
| 共享 | 每个模型只解析一次：几何体、材质贴图、AnimationClip 全局缓存；实例用 `SkeletonUtils.clone`。 |
| 降级 | 设置「角色模型：新 / 经典」；手机或低画质默认可选经典；新模型加载失败自动回退 KayKit。本体不装 DLC 也完整可用。 |
| 授权记录 | `assets/MODEL_SOURCES.md`：每个外部模型一行（文件、用途、来源、作者、授权、可商用、替换状态）；CC-BY 进制作名单。 |

## 各模块细则

### m1 适配层 + 战士
- 范围：见上表。战士 3 种配色（换 Outfits 配色贴图或材质染色），其余职业仍用 KayKit。
- 验收：设置切「新模型」后战士为写实板甲人形，7 个动作都能播放；武器 / 盾牌在手里；切回「经典」后与 v1.1.2 完全一致；本体 / dlc1 构建都能进游戏；渊噬部件、灵契猎手 / 负棺人挂件在 KayKit 路径不受影响。
- 测试：tsc（src/web、dev/tsconfig.dlc.json）、gen-assets、build-web 本体 + --dlc=dlc1、check-purity、dev/smoke.mjs、playtest hub / tutorial / packs + 新 playtest models；新旧截图对照。
- 风险：素材下载（itch.io 需要走「自定价格 $0」流程，可能要浏览器）；UBC 和 UAL 骨骼命名与 KayKit 不同，挂点偏移要逐件调；离线 HTML 体积。
- 素材拿不到时：先用仓库现有 KayKit 把适配层做完（映射表、动作表、开关、挂点走逻辑名），新模型留空槽。

### m2–m9
- 每块验收共同项：新旧开关可切；同模型只解析一次；手机降级仍是 KayKit 或减面版；离线 HTML 体积不超预估上限；playtest 相关场景截图存档。
- m3/m8 额外：DLC 素材只进 `src/dlc/dlc1`，本体构建 check-purity 通过。
- m5/m6 额外：首领体型（缩放 1.6–1.8）下挂点、碰撞半径、血条高度用 modelHeight 重新计算。
- m9 额外：如果总量超 22 MB，优先把动作片段合成一份共享 GLB、贴图降到 256。

### m2a 进度（v1.2.17）
- 动作来源三层：UAL Standard（CC0，15 个）→ 合成变体（rig.ts UBC_VARIANTS：镜像 / 上身扭转 / 前倾 / 截取，10 个）→ Mixamo 动作库（Mixamo_Anims.glb，16 个，tools/mixamo-anims.mjs 从 FBX 转；MX_VARIANTS 截取 4 个）。UAL Standard 原包其实只有 1 个剑击 + 2 个拳 + 施法射击，所以主要攻击 / 施法 / 投掷 / 受击 / 死亡用 Mixamo。
- 重定向：retargetClips 新增 align（两边绑定姿势不同：按骨骼方向补对齐旋转，朝向相反整体转 180°）+ 去根位移（攻击片段去掉整体漂移、水平晃动压到 35%，死亡保留）。
- 动作表按职业：HdRig.clipSets（CharOpts.clipSet 选用），每项按顺序取第一个存在的片段，`a|b` = 随机挑一个（受击）。本体 4 职业已配（UBC_CLIPSETS）；内容包职业由包自己往 HD_RIGS.UBC_Male.clipSets 里加（m3）。
- 战士（写实）：待机 MX_Idle_SS、攻击 1/2/3 = 剑盾攻击 / 剑盾斩（截取）/ 下劈，重击 = 大剑斩（截取），回旋 = 合成 Sword_Spin，受击 3 选 1，死亡 MX_Death，跑 / 走 Mixamo。
- 挂点：gear.ts 写实模型的 bind.pos 换成 KayKit 骑士的骨骼位置，attach 时按 HD_ATTACH（每骨骼缩放 s + 偏移）从 KayKit 空间搬到真实骨骼——头盔 / 头饰 / 肩甲 / 胸甲 / 药瓶 / 时轮 / 包挂件统一生效；propClone 道具（武器、盾、头盔、披风）走别名节点 k（UBC：头 0.34、胸 0.55、腰 0.65、手 0.7）；披风写实下纵向拉长 1.75 倍；穿肩 / 胸装备时 ubcPlate 程序化板甲隐藏。
- 剩余：spin（回旋）仍是合成动作；内容包骨骼（back 等）未进偏移表（m3）；Mixamo 带皮肤角色（Paladin / Knight）未用，m3 视画风决定。
