# 职业装备限定 + 怪物建模路线（2026-10-21 构思稿）

## A. 职业装备限定
- 护甲：战士 = 重甲（现代码叫「板甲」plate）；时砂行者（刺客定位）= 皮甲；法师、炼金 = 布甲（法袍）；链甲 mail 新增枚举，暂无职业，基础物品不进掉落池。
- 现状核对：
  - 穿戴限制已存在：Inventory.whyCannotEquip 按护甲类型和武器类型拦截。
  - 随机掉落已按职业过滤：护甲基础物品 8 件/职业都带 cls，LootGenerator.forClass 只挑本职业。
  - 有 4 件基础物品没带 cls（2 布、1 皮、1 板），要补标或下架。
  - 法师和炼金都穿布甲，但布甲基础物品是分开的（各 8 件），互相不掉；如果希望两职业共享布甲，改成 cls: ['mage','alchemy']。
- 要补的口子：商店白装、兑换、任务奖励、世界事件奖励、副本小套、套装、暗金、精英件逐条审计；generate 出口加一道兜底「当前职业不能穿 → 重抽」。
- 名称统一：UI 文案「板甲」改「重甲」，「布甲」显示为「布甲（法袍）」，新增「链甲」。
- 旧存档：背包里已有的非本职业装备保留，标红「不可穿戴」，分解给双倍材料。
- 估算：2–3% 日额度。

## B. 怪物与首领外观（尽量贴近概念图）
现状：人形角色/敌人基本是 KayKit 4 个 CC0 人物（Barbarian/Knight/Mage/Rogue）换色；蛤蟆、树人、蜘蛛、狼等是代码拼的几何体。离概念图差距大。

路线（推荐 1 为主，2 补量）：
1. 概念图 → AI 生成 3D 模型 → 程序化清理 → 绑骨 → 进游戏
   - 每个怪先出一张三视图（正/侧/背，A-pose，纯色背景），比群像图更适合转模型。
   - 用 Tripo / Meshy 这类图转 3D 服务出带贴图的模型（需要用户的账号 API key，按次计费）。沙箱没有 GPU，跑不了开源的 Hunyuan3D。
   - 清理用 node 的 gltf-transform + meshoptimizer：减面（小怪 ≤4k 三角面、首领 ≤15k）、贴图压到 512/1024、合并材质，再套现有 refineChar 手绘描边 shader，统一画风。
   - 绑骨：人形用服务自带的自动绑骨 + 通用动作；巨蠕、龙、猛犸这类非人形在代码里程序化建骨骼和动作（巨蠕沿样条线分节、龙翼拍动、四足步态）。
   - 预期：剪影和配色约 80% 接近概念图，细节看生成质量，不满意可以重生成或局部修。
2. CC0 怪物资源包（Quaternius、KayKit 等）+ 换色 + 程序化挂件：给小怪变种补量，不用每只都生成。
3. 纯程序化拼装（现在的做法）：只留给召唤物、小型元素等简单造型。

性能约束：同屏骨骼动画怪 ≤ 40，首领单独 1 个；贴图共用图集；远处切低模。

先做 1 个样板验证（建议流沙巨蠕或沙葬法老），确认贴近程度和帧数后再批量：约 20 种副本小怪 + 约 25 个副本首领（含隐藏） + 4 个世界首领。
- 估算：样板 3–5% 日额度（不含 3D 服务费用）；批量每个首领 1–2%，小怪每种 <1%。
