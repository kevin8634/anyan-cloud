# v0.9.6 创意方案：M 地图 / 掉落查询 / HUD 的 3D + 粒子升级（2026-10-22）
概念图：项目根 c095_map3d.png、c095_dungeon3d.png、c095_loot3d.png、c095_hud.png；现状截图 /tmp/ui_*.png（uishot.mjs）

## 一、现状问题
### M 地图（shopmap.ts / mappoi.ts / raidmap.ts）
1. 世界总览：2D 底图按比例缩放，上下留大块蓝边；区域名牌 + 一排小图标挤在一起，副本区虚线框压住名字。
2. 区域详图：纯 2D 色块和线，没有地形高低；新迷雾是平涂一层，没有「拨云」的感觉。
3. 副本地图：黑底 + 几个节点，空；右侧文字墙（说明、掉落、首领故事全堆一列）。
4. 三级切换（世界 → 区域 → 副本）是硬切，没有缩放过渡，玩家不知道自己在哪一级。
5. 图例在底部一长条，传送石、宝箱等新图标越来越多，已经放不下。
### 掉落查询（dropguide.ts / panels 说明书 / raidmap 掉落列表）
1. 两套入口内容重复：说明书按来源分页，副本地图右侧又列一遍，样式不同。
2. 左侧来源列表 40+ 条纯文字，没有首领头像，找某个首领要一直滚。
3. 物品卡全是文字，同等视觉权重，橙装、暗金、套装一眼看不出来；试穿要另开角色面板。
4. 反查缺失：只能「首领 → 掉什么」，不能「这件装备 → 哪里掉」「我还缺哪些」。
5. 收集进度只有一行 0/165。
### HUD（hudbar.ts / index.html）
1. 左上头像 + 血条偏小，资源条（怒气/法力/沙）不显眼。
2. 右上区域名换行（「赤砂裂谷 · 赤岩驿站」折成两行），小地图下面 3 个按钮挤。
3. 任务追踪、成就提示、拾取提示位置分散，提示文字直接压在场景上可读性差。
4. 首领血条没有阶段刻度；技能就绪没有反馈；经验条太细。

## 二、创意方向：「战图沙盘 + 战利品祭坛 + 符文 HUD」
统一主题：**一张摆在战桌上的立体战图**。地图是沙盘，掉落是祭坛，HUD 是嵌在边框上的符文器物。三者共用一套粒子语言（余烬 = 当前 / 紫光 = 副本 / 红光 = 首领 / 金线 = 路线 / 云雾 = 未探索）。

### 1. M 地图 → 3D 沙盘（c095_map3d / c095_dungeon3d）
- 独立小渲染器（第二个 WebGLRenderer 或同一个 renderer 的离屏 pass），只在地图打开时渲染，主场景降到 15 fps。
- 世界：底图贴到一块 128×72 网格上，用各区域 palette + 简单高度图（山 / 火山 / 雪岭）抬起来；四周木桌 + 铜框；相机 45° 可拖动旋转 ±25°、滚轮缩放。
- 未探索：GPU 点精灵云雾（每块区域 200–400 个大粒子，用 fog.ts 的格子决定透明度），新点亮时云从边缘「卷走」散开。
- 地点：光柱 + 上升粒子（金 = 你在这 / 紫 = 副本 / 红 = 世界首领 / 青 = 传送石），悬停放大并弹出羊皮纸卡。
- 世界 → 区域：相机推近 + 云雾散开过渡 0.6 秒；区域 → 副本：区域淡出，副本「浮岛」从下面升起。
- 副本：每个首领一块浮岛 + 首领小雕像（v0.9.4 的 GLB / 程序模型缩小复用），桥和岩浆连起来；击杀后雕像变灰熄火；路线是流动的金色箭头粒子。
- 回退：低配 / 手机设置里可切回现在的 2D 地图（保留现有代码当 fallback）。
### 2. 掉落查询 → 战利品祭坛（c095_loot3d）
- 说明书和副本地图掉落列表合成一个组件，副本地图里点首领直接打开同一个祭坛页。
- 中间符文祭坛：选中的装备用游戏内真模型（models.makeLootItem / 武器模型）在上方旋转，按品质套现有掉落光效（橙光柱 / 暗金黑焰 / 套装红光）；其余可掉物品绕圈环绕，点击切换。
- 祭坛后方是首领的余烬全息剪影（首领模型 + 溶解 shader 只留边缘光）。
- 左侧来源列表改成「首领头像徽章 + 分组折叠」，顶部搜索框 + 「我缺的」筛选。
- 右侧物品卡 + 掉率条；新增「这件在哪掉」反查（列全部来源 + 一键在地图上定位）。
- 收集墙：每个来源一个星座，收集过的装备是亮星，凑齐一个首领点亮整片星座 + 粒子。
### 3. HUD → 符文器物（c095_hud）
- 左下血球 + 资源球：shader 液面（正弦波 + 噪声），受击液面晃、低血量发红脉冲；经验改成血球旁的弧形条。（手机可改回左上横条）
- 右下技能环：保留 v0.9.2a 环形布局，加冷却扫光、就绪时一圈小火星；闪避独立。
- 右上：圆形罗盘小地图（带迷雾边缘），区域名单行横幅，不再换行；3 个按钮收进罗盘下方的一排小符文。
- 顶部首领血条：阶段符印刻度 + 余烬粒子，过阶段时符印碎裂。
- 左侧任务追踪：半透明羊皮纸条；成就 / 拾取提示统一进右侧通知栏，带一道粒子拖尾。
- 实现：HUD 主体仍是 DOM/CSS（便宜、清晰），血球和粒子用一个小的透明 canvas（2D 或 WebGL 共享）叠加。

## 三、性能约束（手机 30 帧）
- 地图 / 祭坛只在面板打开时渲染，关闭即释放；打开时主场景暂停或降频。
- 粒子上限：沙盘 ≤ 3000 点精灵（一次 draw call），祭坛 ≤ 800，HUD ≤ 200。
- 贴图复用 vfx.ts 的 4×4 粒子图集，不加新大图；HTML 体积目标 +≤ 200KB。
- 设置项：「3D 地图 / 2D 地图」「HUD 粒子 开 / 关」。

## 四、追加需求（2026-10-22 12:55）：长副本 / 深渊掉落重做 + 太古系统 + 玩法介绍
分配表：docs/plan/v0.9.6_掉落池分配表.xlsx（96 件橙装逐件来源 + 掉率表）；概念图 c096_ancient_reward.png

### 4.1 96 件橙装分配规则
- 96 件 = 4 职业 × 24（3 专精 × 8 部位，全部已实现）。每职业拆成：熔心王座 7 / 永霜墓穴 7 / 深渊首领层 6 / 深渊 20 层顶级 4。**长副本和深渊零重复**。
- 主题：熔心王座 = 爆发进攻专精（狂怒 / 火焰 / 回声 / 爆破）；永霜墓穴 = 控制防守专精（防护 / 冰霜 / 时痕 / 地面）；深渊 = 第三专精（武器 / 奥术 / 回溯 / 炮台）。数量不齐的从饰品 / 戒指这类通用部位挪。
- 长副本每职业 7 件：5 个首领各 1 件独特（尾王拿武器 / 副手），2 件全副本共享。
- 深渊 20 层顶级 4 件 = 每职业改变技能形态的那几件（如战士 风暴战斧 / 斩首者 / 双生之心 / 回响指环；法师 裂光法杖 / 霜火法珠 / 时序法典 / 星界披风）。
- 套装只占头 / 肩 / 胸 / 手 / 腿 / 腕，橙装只占主副手 / 项链 / 披风 / 腰带 / 鞋 / 戒指 / 饰品：长副本一套刷下来两者正好互补。
- 野外 / 普通副本的随机橙装照旧从全库随机（低掉率），长副本 / 深渊是定向来源；太古只在这两处出。

### 4.2 长副本掉落（只掉套装 + 橙装，尾王暗金不变）
| 每个首领 | 普通 | 炼狱 |
|---|---|---|
| 本职业套装部件 | 35% | 45% |
| 本首领独特橙装 | 18% | 25% |
| 副本共享橙装（2 选 1） | 12% | 18% |
| 保底 | 以上都没出 → 必出 1 件套装或共享橙装 | 同左 |
| 尾王暗金 | 5%（每周首通 ×2） | 10% |
- 取消紫装和随机装备填充；原 30 件长副本命名紫装移进 30 级随机紫装池。金币 / 精魄 / 星辉碎片 / 货币不变。每周首通加倍改成「尾王池再出 1 件」。
### 4.3 深渊掉落（取消紫装）
- 普通层：金币 + 魔尘 / 星辉碎片 / 精魄 + 深渊碎片；「遗落宝箱」岔路改成材料包。
- 5 / 10 / 15 层首领：深渊池必掉 3 件不重复橙装 + 金币 + 材料 + 深渊碎片 + 暗金碎片 3 / 6 / 9。
- 20 层尾王：顶级池 4 选 3 必掉 + 材料 / 货币；结算页弹出「本职业全部暗金 + 本职业套装部件」，自选 1 件，每次通关都能领。
### 4.4 太古系统
- 出现：长副本炼狱的套装 / 橙装 / 暗金每件 4%；深渊 20 层 3 件橙装每件 6%；20 层结算自选那件 10%（领取时判定）。
- 效果：所有词条取该装等区间峰值；橙装 / 暗金特效数值 ×2。不能直接翻倍的按规则换算：几率类 ×2 封顶 60%（重置类封顶 50%）；冷却缩减 ×2 封顶 -60%；「每第 N 次」改为 N-1（最少 2）；弹射 / 投射物数量 +100% 向下取整；持续时间 ×1.5；套装无特效，只取峰值词条。lgfx.ts 的代码型钩子读 item.ancient 倍率。
- 表现：名字红色 #ff2a2a + 结尾「（太古）」；物品格子 / 提示框红色描边 + 余烬粒子；掉落光柱 = 深红金边双螺旋 + 地面太古符环（套装已经是红光柱，太古必须用双螺旋和金边拉开）；穿戴后武器红色边缘光 + 少量火星；掉落时全屏红色横幅 + 音效。
- 存档：ItemInstance 加 ancient 字段；分解太古给双倍材料 + 1 个新货币「太古余烬」（以后做重铸 / 外观用，本次只计数）。
### 4.5 玩法介绍（全部做完后）
- 「推荐下一步」按钮升级为「玩法介绍」：首页保留「当前推荐」卡片（原下一步逻辑），下面按章节介绍：战斗与职业、套装与橙装、暗金与太古、长副本、深渊、野外探索（迷雾 / 瞭望塔 / 传送石）、世界首领、声望。
- 每章配游戏内 3D 小场景或物品祭坛预览（复用 6d 的祭坛组件），未解锁的章节灰显并写解锁条件；新系统解锁时按钮冒火星提示。
