# 武器惊艳化技术方案（交接用）

> 整理时间：2026-10-26 03:30 CST ｜ 对应版本：v1.2.41（commit bf41b4d）｜ 作者：Hark（与 Rhett 讨论结论）
> 目的：让比赛版「铸造台 · 一句话铸武器」和武器展示在评委面前足够惊艳。

## 0. 结论
- 在「浏览器实时渲染 + 单文件离线 HTML」框架内，最有效的手段是：**渲染（后处理）+ 着色器光效 + 演出镜头**，而不是继续堆面数。
- 模型细节上限 = Lux3D 原始输出（约 10 万面 + 2048 贴图）。要更好的**造型**，只能「先出概念图 → 图生 3D」重新生成（约 20 积分/把）。
- 做不到：真正的高模烘焙法线（没有高模源）、光线追踪。
- 建议顺序：**① 熔炉成形动画 → ② 流光着色器 + 选择性 Bloom/ACES → ③ 其余 9 把武器高清化 → ④ 展示镜头/拍照模式 → ⑤（花积分）造型差的武器重生成**。

## 2. 技术手段明细

### ① 熔炉成形动画（优先级最高，零积分）
- 触发：铸造台提交描述后。等待期（在线 30–120 秒）熔炉持续翻腾：熔岩面（滚动噪声 UV + 发光）、火星粒子、符文环旋转、钟声节奏脉冲。
- 成形：拿到 GLB 后镜头推近 → 武器从熔岩升起 → **溶解着色器**（`onBeforeCompile` 注入：按模型局部 Y 高度 + 噪声做 discard 阈值，阈值边缘加橙红发光带）自下而上「烧」出 → 空中转一圈约 3 秒 → 飞入角色主手。
- 离线回退 / 失败 / 超时：播放同一套演出，换成预制武器库模型。
- 风险低：只动 `src/dlc/dlc1/smithy.ts` + 新增特效模块；镜头复用现有相机接口。

### ② 流光着色器 + 选择性 Bloom + ACES（全局提升最大）
- **流光着色器**（零积分）：
  - Fresnel 边缘光（视角掠射处发光，颜色按武器主题）。
  - 发光遮罩上的 **UV 滚动能量脉络**（emissive × 滚动噪声），让武器「活」起来。
  - 统一做成 `weaponfx` 里的材质补丁，按武器配置颜色/速度。
- **后处理**：`EffectComposer` + `UnrealBloomPass`（或用 layer 做**选择性 Bloom**，只让水晶、符文、魂火、钟鸣特效泛光，避免全屏发白）；`renderer.toneMapping = ACESFilmicToneMapping`；可加 FXAA/SMAA。
- 注意：确认对构建体积（three/examples 模块）和帧率的影响；只在「高质量」档/比赛演示开启，低端设备关闭；ACES 会改变现有整体色调，需全场景回归截图。

### ③ 其余 9 把武器高清化（零积分）
- 照法杖流程跑 `tools/weapon-hd.mjs`：2–3 万面、2048 贴图、法线、发光遮罩。
- 每把单独光效，不要统一发光：剑刃挥砍拖尾、斧锤熔岩裂纹、轮刃时光残影、药瓶液体晃动光、魔杖符文点。
- 包体：每把约 2 MB，10 把约 20 MB → 建议高清件**懒加载**，不全部塞进单文件 HTML（或只在比赛版塞入）。

### ④ 展示镜头 / 拍照模式（低风险）
- 换装后自动近景环绕 2 秒。
- 拍照模式：隐藏 UI、自由镜头、距离/角度、景深构图；用于报告和录屏。复用截图脚本与相机接口。
- 「比赛体验」按钮：开始界面直进满装备展示场景，跳过练级，直达铸造台、法杖、首领。

### ⑤ 高质量画质档（中期）
- 设置：自动 / 经典 / 写实 / 高质量。高质量直接用 Lux3D 原始约 10 万面 + 2048 贴图（写实档仍是约 8 千面 / 1024）。
- 自动档按设备性能选择；资源懒加载。代价：包体、加载时间、显存。
- 先只给法杖、角色、首领做按需加载演示，不一次性全量。

### ⑥ 造型重生成（花积分）
- 问题武器（如法杖短粗）：先用文生图出概念图（指定比例，如「长杖，长宽比约 1:8」），再 Lux3D 图生 3D（G1 精修约 20 积分/把），然后走 ③ 流水线。
- 提示词约定：「只有一个物体」「不是雕像，没有任何台座」。

### 暂缓
- 铸造墙（工坊展示玩家生成的武器、点赞/精选）。
- 全部 94 个原始模型高质量化；额外 Lux3D 批量生成。

## 3. 约束与注意事项（接手必读）
- **DLC 纯净**：铸造台 / 熔炉相关代码只放 `src/dlc/dlc1/`；本体不能出现 DLC 文字（check-purity）。通用材质/后处理可放 `src/web/`。
- **不改 data/ 职业表**（会改指纹，simPacks 报错）；铸造只改外观，不改属性。
- **云函数**：前端调 `POST <地址>/forge`，请求 `{ prompt, weaponType }`，返回 `{ url }` / `{ glb: base64 }` / `{ error }`；地址来自 `?forge=<url>` 或 `localStorage.darkrock_forge_api`。**云函数本身尚需部署**，Lux3D Key 只能放在云函数环境变量里，不能进前端。每日在线生成上限 3 次，结果存 IndexedDB。
- **Lux3D**：并发上限 5（有时更低，失败单独重跑）；Key 不打印不落盘。
- **测试**：改动后跑 `dev/smithyshot.mjs`（握法）、`dev/staffshot.mjs`（光效）；发版用 `tools/release.sh`（全量检查 + commit + tag + 打包）。沙箱重启后先 `bash tools/setup_env.sh`。
- **性能预算建议**：比赛演示机目标 ≥50 fps；Bloom 半分辨率；单把高清武器 ≤3 万面、≤2.5 MB。
- **交付**：云盘 `02_工程包`、`03_离线版` 只保留最新版本，新版上传成功后删旧版；同步更新 `01_交接` 四份文档和 `版本号.txt`。
- **额度停止线**：日额度已用 ≥90% 或周期额度已用 ≥94% 立即停手、发版、写交接。
