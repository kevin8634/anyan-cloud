## 0. 职业视觉主题

- **材料**：**玻璃药瓶实体**（手吹玻璃，气泡与壁厚不均，软木塞 + 黄铜箍 + 蜡封）、**真实液体**（瓶内液面随抛物线晃动、落地碎瓶溅射、流淌、渗进地缝）、红火 / 蓝霜 / 绿腐蚀三种试剂、铸铁大釜（黄铜管、压力表、铆钉、铜绿）。发光只给燃烧的火芯与反应瞬间的闪光；液体本身是**不发光的有色透明介质**。
- **主色**：玻璃 #CFDAD6（低不透明度 + 折射）、黄铜 #A07A3C、铸铁 #2B2826；红火试剂液 #B8321C（燃起后火 #E2481B、火芯 #FFE7A3）、蓝霜试剂液 #2E6F9A（霜 #9FD8E8、白霜 #F2FBFF）、绿腐蚀试剂液 #7E9A2E（毒雾 #9DBA3A / #3D4A1E）。**禁止荧光绿**：现代码 `COLOR_HEX.g = 0x6aff4a`、`ZONE_COL.poison = 0x5aff3a`、`ELEMENT_COLOR.nature = #7dff5a` 全部换成色板值。
- **电影参照**：《大侦探福尔摩斯》（2009）的实验室与慢镜爆破、《绝命毒师》的化学写实（液体、烟、腐蚀）、《黑暗骑士》的实拍爆炸（黑烟比火多）、《加勒比海盗》的燃烧瓶与火药。
- **动作重量感**：手腕抛投，轻；但每瓶落地都要有「玻璃碎 + 液体泼」的物理感：碎瓶 0.05 秒内完成，液体 0.2 秒内铺开，反应爆炸才是重拍。节奏：「叮（瓶碰瓶）— 嗖（抛）— 啪（碎）— 轰 / 嘶（反应）」。

## 3. 混合试剂规则（视觉）

### 3.1 瓶与液体

1. **形态归技能**：所有药剂都是「玻璃瓶抛物线 → 碎瓶 → 液体泼开 → 配方结果」，形态永远不变；配方只决定液体外观与结果材质（总纲第 4 节第 1 条）。
2. **单色**：一种液体，圆底烧瓶，液体占瓶 70%。
3. **双色混合**：双颈瓶。**先按的颜色在下层占 60%，后按的颜色在上层占 40%**（总纲「主元素 60%」）；调配动作中第二瓶倒入第一瓶时两层分明，**飞行中瓶身自转把两层搅成螺旋大理石纹**；落地时两种液体先分开溅出（各自占溅射的 60/40 扇面），0.1 秒后在中心相遇触发配方结果。
4. **同色双按（rr / bb / gg）**：浓缩液——同一颜色更深一档、瓶身 ×1.2、瓶壁有压力裂纹、软木塞被顶出一半。
5. **地面反应**（后一瓶落在已有区域上）：结果层叠在区域上，原区域被「消耗」或「改性」（见 3.3），不另起圆圈。
6. **附加元素**（v1.2.66 `addElement` / `elemHit`，例如橙装「回响指环」给红瓶加闪电弹射）：附加元素不改液体，只加在**瓶外**：
   - 火 = 软木塞上一截燃烧的引信；冰 = 瓶外壁结霜；雷 = 瓶身缠细铜丝、丝上跳 0.08 秒电弧；暗影 = 瓶内液体里游动墨丝；奥术 = 瓶身刻发光符文（只刻痕亮）。
   - 落地时附加元素各出一层命中层（按总纲第 4 节：火 = 火星焦痕，冰 = 冰晶沿 3 米传导结霜，雷 = 分叉电弧跳向周围）。
   - ⚠ 代码现状：`buildSkill`（`alchemy.ts:127`）对混合药剂 `effects = []`，**附加元素、符文附加效果在混合瓶上全部丢失**，只有单投保留——视觉规范按「混合瓶也带附加层」写，需程序确认这是否是有意的数值设计。

### 连锁爆裂（chain_bomb）· 技能4 · 火焰 · 瞬发（弹射 4 次）
- **定位**：30 级技能 4，弹射 4 次的爆裂瓶（每跳 70%），每次命中再 3 米小范围爆炸（50%），冷却 12 秒，不消耗试剂。

  ⑤ 余韵 4 秒：每个爆点一块小焦痕贴花（最多 5 块），连起来就是这次弹射的路径。
- **材料与色板**：铁丝笼 #5A5550、厚玻璃 #CFDAD6、液体 #B8321C、火 #E2481B、黑烟 #2A2421、焦痕 #1A0C06。
- **多元素变体**：三系节点：大爆炸 = 每跳火团更大；蚀日 = 引信更短更亮；重炮 = 小爆半径大（贴花同比）。穿透符文（无半径技能的第 3 符文：命中后 2.5 米小爆）= 每跳多一圈尘土冲击波。**双元素例**（火 + 附加雷）：弹跳路径上**额外**拉一条红黄色 `ArcBolt`（火 + 雷 = 红黄电弧带火星，不是蓝色），形态仍是瓶在弹——电弧只是附加层。**三元素例**（火 + 雷 + 冰）：每跳爆点先火团、再霜晶沿 3 米传导、再分叉电弧跳向周围，三层依次 0.05 秒错开。
- **镜头与打击感**：只在第一跳顿帧 60ms，最后一跳 80ms；每跳方向震屏 0.2（沿弹跳方向）。
- **音效**：铁笼撞击「当」（音高逐跳上升）+ 小爆「嘭」+ 最后一跳玻璃碎 + 较大爆炸。
