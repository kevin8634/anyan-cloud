# 怪物 · 副本与团本首领 · 技能与机制特效（v1，2026-10-30）

> 色板、组件、5 段分镜照《00_总纲/总纲.md》；地板照《未来开发报告 v5》第 3 节；锁血阶段转换照第 6.3 节与总纲第 7 节（1.5 秒电影镜头：拉远 + 低角度）。
> 以代码为准，覆盖：本体 2 个入门副本、2 个 30 级长副本（熔心王座、永霜墓穴）、3 个 30 级三首领副本（沙葬王陵、巨魔冰窟、灰烬铸造厂，各含隐藏首领）、第六章剧情终战；资料片无声钟楼（5 层 + 沉眠者 A / B）、钟铜熔炉（3 首领）。共 **35 位首领**。长副本 A / B（潮渊钟井、镜渊倒塔）见《长副本》文件。
> **DLC 铁律**：本体首领只换画法，机制、判定、数值不动，阶段转换只加镜头不锁血；锁血 / 状态 / 控制机制库只用于资料片首领（报告第 19 节第 2 条）。
> 深渊（暗岩深渊 20 层）借用三首领副本的场地和首领，视觉与本文件同一套，不另写。

数据来源：`src/data/dungeon_darkrock.ts`、`dungeon_swamp.ts`、`raid_molten.ts`、`raid_frost.ts`、`dungeon_new.ts`、`raids.ts`、`story_ch6.ts`（+ `web/raid.ts` 第 1586 行剧情替身）、`src/dlc/dlc1/belltower.ts`、`forge.ts`。模型以比赛版为准（`enemy_types.ts LUX_MOBS` 按显示名换 Lux3D；没有条目的走原程序化 / KayKit）。

## 0. 通用规则

### 0.1 本文件用到的地板 `fx`
报告 5 个（`lavaCrack / iceCrack / poisonFog / bloodTide / fireSpread`）+ 野外首领文件补的 4 个（`rootBurst / sandSink / quakeRing / tideSurge`）+ 本文件新增 4 个：

| `fx` | 预警 | 生效 | 残留 |
|---|---|---|---|
| `rockfall` 落石 | 天花板落灰、细砂先洒下，地面出现越来越清晰的石块阴影 | 石块砸落碎开（实体碎块网格） | 碎石堆 6 秒 |
| `inkSilence` 死寂（暗影） | 地面的颜色一点点被吸走（去饱和 + 变暗），落在上面的灰尘不再扬起——「声音被吸走」 | 墨烟从地面渗出贴地（反向加深） | 墨迹 6 秒 |
| `moltenPour` 铁水浇注 | 头顶坩埚倾斜、第一滴铁水先落下溅开 | 一滩铁水摊开（发光只在液面中心，边缘迅速冷却变暗） | 冷却铁壳 + 余热 8 秒 |
| `bellWave` 钟波（钟楼 / 熔炉） | 地面灰尘随低频「嗡」声成同心纹跳动，青铜器物共振 | 声波冲击：空气扭曲环（屏幕空间扭曲，不发光）推开尘土 | 尘土落定 |

### 0.2 首领出手的通用动作约束
- 每个 `groundSlam` 的预警期 = 首领的「预备」动作（后摆），伤害帧 = 动作出手帧；`cast` 的读条期 = 读条姿态，打断 = 受击后仰 0.4 秒 + 「打断」字。现状是同帧扣血 + 整体前倾，见动作文件。
- 本体首领阶段转换：`CineCam` 1.5 秒（拉远 + 低角度）+ 首领原地演出 + 喊话，**不锁血、不改机制**（首领在镜头期间照常可被攻击 / 照常行动的部分按原逻辑）。资料片首领可锁血。
- 召唤物出场一律「从场景里出来」（地缝、熔炉、镜面、水洼），不凭空出现。

### 0.3 首领死亡（四类，按材质）
倒地 / 碎裂 / 化灰 / 灵雾（定义见《精英与稀有》第 6.2 节），首领版：时长 ×1.5，叠 0.3 秒慢动作 + 低角度镜头，残留 12 秒。现 `bossfx.bossDeath` 的发光爆炸与光柱去掉。

## 10. 实现要点

- 本体副本首领的 `guide.mechanics` 是文字，机制在 `raid.ts` 各自的实现里；改画法时只替换 `raid.ts` 里调用 `BFX.teleWarn / shockwave / pillar` 与 `telegraphMaterial` 的地方为 `GroundFx.spawn(fx, …)`，判定不动。
- 本体首领的阶段转换：`raid.ts` 已有阶段切换喊话处加 `CineCam.phase(boss, 1.5)`；首领不锁血。
- 资料片首领在 `PackDungeonBoss / BtBoss` 上加 `lock?: { at, transition, time }`（报告第 18 节 BossBrain `lockAt + transition`），钟铜熔炉先接。
- 两个未接 Lux 的回响首领（钟楼 b4 / b5）：在 `LUX_MOBS` 加显示名映射到 `dt_setekh` / `raid_valkaz`，并套回响半透明边缘。

## 11. 验收

1. 35 位首领每人至少截 1 个招牌机制的预警 50% 帧：无整圆色块、无发光环；本体首领与改前判定半径一致（自动比对 `BossBrain.activeTelegraphs`）。
2. 双生焰灵：血量差 0% / 10% / 20% 三帧，火焰丝带张力可辨。
3. 锻炉傀儡：热度 0 / 50 / 90 / 100 四帧，本体颜色逐级变化，100 时亮度 ≤ ×1.5。
4. 钟母熔铸：钟壳闭合帧、3 颗熔芯、20 秒倒计时颜色变化录屏。
5. 阶段转换镜头：每位首领 `CineCam` 日志一条，时长 1.5 ± 0.1 秒。
