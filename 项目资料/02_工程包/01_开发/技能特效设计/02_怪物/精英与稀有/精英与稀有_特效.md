- 精英 / 稀有只有名牌颜色与体型区别；死亡统一走 `vfx.ts enemyDeath()`：灰烟 + **紫色灵魂粒子** + 精英多一个发光符印 `sigil` + 星形闪光；`main.ts` 里死亡 = 整体 `root.rotation.z` 转 90° 侧翻 → 1.2 秒后透明下沉。所有怪物（狼、石像、幽魂、鲸）死法一样。
- 自爆者 / 图腾 / 治疗读条用通用红圈和发光法阵。

## 1. 精英通用标识：三层，不画光圈

精英不是「多一个发光圈」，而是**它身边的物质被它的力量扰动**。每个精英 / 词缀都拆成三层：

| 层 | 位置 | 规则 | 组件 |
|---|---|---|---|
| ① 光环层（身体） | 怪物身上 | 材质层改变：裂纹发光、结霜、渗毒、包铁、冒烟；**不加外描边**。顶点着色器在原材质上叠一层（沿用 `creatures_glb.ts` 已有的物体空间 Voronoi 裂纹思路），亮度 ≤ 场景最亮点 ×1.5 | 材质叠层 + `VolSmoke` |
| ② 地面层 | 脚下 2–3 米 | 怪物走过 / 站着的地方被改变：焦痕、霜纹、湿印、血脚印、腐蚀斑。随怪物移动留下 4–8 秒的脚印贴花（每步 1 个，上限 6） | `GroundFx` 小半径 + 脚印贴花 |
| ③ 命中层 | 打到玩家 / 被玩家打 | 精英出手时多一层元素命中（`HitLayer` 叠层），被打时按材质出受击（第 5 节） | `HitLayer` |

**统一精英辨识**（所有精英共用，叠在词缀之上）：
- 名牌左侧加青铜八角小框（同天赋纹章风格），不在模型上画圈。
- 体型：精英 ×1.15–1.3（已有 `miniEliteType` ×1.3）。
- 脚步：精英每步有尘土小团（`VolSmoke`，尘土 #8B6F4E，6–10 粒，普通混合），走路带重量感。
- 开战吼：精英进入战斗时 0.3 秒「预备姿态」（动作模板的威吓动作：人形握拳后仰、四足压低前身、甲壳竖螯），配一次低频音。

## 5. 精英处决演出（报告第 15 节建议 2，阶段 1 简版必做）

### 5.1 规则（只定视觉 / 镜头，数值走打击感方案）

## 7. 实现要点

- 精英词缀视觉挂在 `EliteMech` / `MutId` → 一张 `ELITE_FX` 表（`body / ground / hit / onTrigger` 四个字段），`raid.ts` 生成精英时套用；本体与 DLC 共用（只是画法，不改机制）。
- 死亡类型：在 `LUX_MOBS` / `LUX_DLC` 条目旁加 `hitMat`（缺省按体型模板推断：S → 石、F → 幽魂、Q / H → 血肉），`vfx.ts enemyDeath()` 按 `hitMat` 分发四种死亡；`main.ts` 死亡分支去掉 `rotation.z` 侧翻，改调动作模板的 `death`。
- 碎裂死亡复用绑骨的顶点分区结果（同一张 `partId` 属性），不另做切割。
- 预算：词缀身体层每只 ≤ 30 粒子；深渊满层时词缀地面贴花共享上限 12；处决期间暂停新词缀粒子发射。

## 8. 验收

1. 截图：同一位置分别放 9 种 `EliteMech` 精英，正面 / 背面各一张，人眼能不看名牌说出盾卫正背、自爆倒计时阶段、幻影与真身（幻影无影子）。
2. 自爆者：e2e 记录死亡后 0 / 1.0 / 1.6 / 2.0 秒四帧，膨胀与裂纹逐帧增强，爆点与伤害结算同一帧（± 1 帧）。
3. 死亡：狼（倒地）、石傀儡（碎裂）、熔岩幼体（化灰）、镜像碎影（灵雾）各截 0 / 0.5 / 1.2 秒；不得出现整体侧翻 90°、不得出现紫色灵魂粒子。
4. 处决：慢镜时长 0.3 ± 0.02 秒（`CineCam` 时间缩放日志），处决动作与伤害数字同帧。
5. 亮度：精英身体层自发光像素亮度 ≤ 场景最亮点 ×1.5（截图直方图脚本）。
