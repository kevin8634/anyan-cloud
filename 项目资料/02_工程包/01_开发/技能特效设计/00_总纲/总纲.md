# 技能特效设计 · 总纲（v1，2026-10-30）

> 适用：本体四职业 + 资料片两职业 + 全部怪物。目标：把现有「发光几何体 + 地面色块」的特效彻底换成**写实材料 + 电影镜头语言**。数值、判定形状不改，只改「怎么放」和「看起来是什么」。
> 依据：《未来开发报告 v5》第 2–5 节（写实特效库八元素、地板写实化、打击感、五种释放方式）+ 概念图。

## 1. 用户反馈的典型错误（必须杜绝）

| 现象 | 错在哪 | 正确做法 |
|---|---|---|
| 奥术风暴从天上砸下 + 地面一大片绿色区域 | 释放方式错（应瞬发 + 区域持续），颜色错（奥术不是绿），用平面色块表现范围 | 瞬发；目标区域上空 0.3 秒内卷起紫黑雷云，区域内 6 秒持续落下蓝紫奥术闪电；地面是被电焦的裂纹与符文残光，不画色块 |
| 闪电链（附加火 / 冰后）变成光球飞出 | 元素附加时套了「投射物」外观，丢掉了技能本身的形态 | 形态由技能决定（链 = 折线电弧瞬间连接），元素只改颜色、材料、附加层 |
| 附火的闪电还是蓝色 | 没有元素混色 | 火 = 红黄电弧带火星；冰 = 青白电弧带霜晶；冰火雷 = 三色电束绞合，命中后冰沿链传导到周围 |
| 4 技能图标没换 | 图标流程漏了 skill4 | 每个技能（含 skill4、绝技、变身技）都有专属图标，元素附加后图标角标变色 |
| 怪物滑过来跳数字 | 写实怪物无骨骼、无动作 | 见 02_怪物/动作与绑骨 |

## 2. 视觉总基调：「暗岩 · 铜锈 · 深渊」

- **世界观材料**：黑色玄武岩、青铜（新铜金 → 铜绿锈）、潮湿、海盐结晶、旧布、骨。特效要像「这个世界里的物质被力量扰动」，而不是凭空出现的光。
- **电影感参照**：《指环王》《沙丘》《权力的游戏》的实拍质感，《暗黑破坏神 4》的低饱和写实 ARPG 画面，《战神》（2018）的重量感与镜头推拉。避免：手游式满屏高饱和光效、描边光圈、卡通星星。
- **亮度预算**：特效最亮处 ≤ 场景最亮点 × 1.5；只有本身是光源的（火芯、电弧、符文刻痕、熔岩）进泛光层。烟、尘、血、毒、水、冰用普通混合（会挡光）。
- **每个技能都留下痕迹**：焦痕、冰面、血迹、湿地、碎石、电焦裂纹，4–8 秒淡出。
- **地面不画几何圈**：范围用材质边缘表达（冰面蔓延边、裂纹、雾的边缘），可读性靠边缘纹理 + 音效 + 小地图标记；必要时保留 15% 不透明度的细边。

|---|---|---|---|---|---|
| 物理 | 铁灰 #8A8F96 | 尘土 #8B6F4E | 火星 #FFC56B | 刀风扭曲、尘土、碎石、血雾 | 刮痕、碎石、血迹 |
| 火焰 | 橙红 #E2481B | 焦黑烟 #2A2421 | 白黄火芯 #FFE7A3 | 序列帧火 + 黑烟 + 余烬 + 热扭曲 | 焦痕、余烬 |
| 冰霜 | 冰青 #9FD8E8 | 深蓝冰体 #2E5F7A | 白霜 #F2FBFF | 冰面贴花（会长）、冰刺、霜粒、冰块折射 | 冰面、霜纹 |

**禁止**：奥术用绿色；雷电用纯白大光球；任何元素用不透明大面积纯色地板。

## 4. 多元素混合规则（v1.2.66 多重元素附加的视觉规范）

1. **形态归技能，颜色归元素**：链、弹、锥、圈、地面、引导等形态永远由技能决定；附加元素只改变材质和附加层，绝不把技能换成另一种形态。
2. **主元素 = 技能原元素**（占画面 60%），附加元素按顺序各占 20–25%。
3. **双元素**：两股能量绞合（螺旋缠绕或并行两束），命中点出现两种残留（例：火 + 冰 = 焦痕边缘结霜、蒸汽爆）。
4. **三元素**：三色电束绞合；命中时按元素各自出一层：火 = 炸开火星和焦痕，冰 = 冰晶沿链传导到 3 米内的敌人并结霜，雷 = 分叉电弧跳到周围。
5. **元素反应特效**（只有视觉，数值按现有规则）：火 + 冰 = 蒸汽爆白雾；火 + 毒 = 毒雾点燃成闪燃；冰 + 雷 = 冰晶导电（冰面上电弧乱窜）；奥 + 任意 = 该元素被符文框住，带紫色边光。
6. **图标**：图标右下角加元素角标（小圆点，按色板），多元素时并排 2–3 个。

## 5. 特效分层（每个技能都按这 5 段写分镜）

| 段 | 时长 | 内容 |
|---|---|---|
| ① 预兆 | 0–0.3 秒（读条技能更长） | 身上 / 武器 / 目标处的能量聚集：尘土被吸、霜气凝结、电荷噼啪、符文亮起 |
| ② 出手 | 0.05–0.15 秒 | 角色动作最高点，顿帧 + 镜头方向震动，主光源闪一下 |
| ③ 飞行 / 持续 | 视技能 | 投射物、电弧、风涡、雷云、冰面蔓延 |
| ④ 命中 | 0.1–0.3 秒 | 按目标材质的命中特效 + 元素命中层 + 伤害数字 |
| ⑤ 余韵 | 4–8 秒 | 残留贴花、烟、余烬、冰面、血迹，淡出 |

## 6. 五种释放方式（报告 5.1，所有技能必须归类）

瞬发 / 引导（可移动、免控、不能放别的）/ 读条（站定、可打断）/ 蓄力（按住松开）/ 延迟落点（指定点 1–1.5 秒后落下，必须有天空或地面预兆）。
**只有「延迟落点」类技能可以从天上下来**（陨星、群棺坠等）；风暴、雷云类是「瞬发 + 区域持续」。

## 7. 镜头与打击感

- 顿帧：轻 40ms / 重 80ms / 暴击 100ms / 大招最后一击 140ms，多目标只顿一次。
- 震屏带方向，沿攻击方向推；大招开场 0.3 秒轻推镜头（FOV −4°）再回弹。
- 击杀精英 0.1 秒慢动作（时间 ×0.3）；BOSS 锁血阶段转换做 1.5 秒电影镜头（拉远 + 低角度）。
- 受击：闪白 0.06 秒、按材质命中特效（血肉 / 骨 / 金属 / 石 / 甲壳 / 幽魂）。

## 8. 特效组件库（实现时统一用这些名字）

| 组件 | 用途 | 关键实现 |
|---|---|---|
| `ArcBolt` | 闪电 / 电束（单段、链、绞合多色） | 中点位移分形折线 + 分支；每 0.05 秒重生形状；多色 = 2–3 条偏移曲线 + 不同颜色；加色混合；端点光源 |
| `StormCell` | 区域持续风暴（奥术风暴、雷暴） | 头顶体积云（噪声软粒子，普通混合）+ 随机落雷 ArcBolt + 地面焦痕贴花 |
| `GroundFx` | 地面蔓延类（冰面、焦土、腐蚀、裂纹、血潮） | 贴花 + 噪声遮罩随时间扩张 + 法线 / 粗糙度动画 |
| `VolSmoke` | 烟、尘、毒雾、墨烟、蒸汽 | 软粒子（深度淡出）+ 卷曲噪声速度场；普通混合 / 反向加深 |
| `FlameSeq` | 火焰本体 | 序列帧或噪声火焰 shader + 余烬粒子 + 热扭曲 |
| `IceForm` | 冰刺、冰块、冰晶 | 低多边形网格 + 折射 / 菲涅尔 + 内部气泡贴图 |
| `WindVortex` | 风涡、刀风 | 屏幕空间扭曲 + 灰色拖尾带 + 尘土草屑粒子 |
| `GhostMesh` | 幽魂、兽魂、回声残影 | 菲涅尔半透明 + 拖尾雾，不进泛光 |
| `RuneDecal` | 符文、时痕、法阵刻痕 | 发光刻痕贴花（只刻痕发光），慢转呼吸 |
| `Projectile3D` | 实体投射物（火球、冰枪、药瓶、飞轮） | 实体网格 + 拖尾 + 命中时交给 GroundFx / 命中层 |
| `HitLayer` | 命中层 | 按目标材质 + 元素组合；多元素逐层叠加 |
| `CineCam` | 镜头 | 顿帧、方向震屏、推拉、慢动作、阶段转换镜头 |

**性能预算**：同屏粒子 ≤ 3000（中画质 1500，低画质 600）；贴花 ≤ 36；光源 ≤ 6 个动态点光；低画质关闭扭曲与软粒子深度淡出。

## 9. 图标规范

- 128×128 + 64×64，深色岩石底 + 青铜八角框（沿用天赋纹章风格）；主体是技能的「物质」而不是抽象符号（例：闪电链 = 三段蓝紫电弧连着三个剪影）。
- 槽位色边：普攻灰、1 号铜、2 号青铜、3 号钢蓝、4 号暗金、大招 / 绝技 金红；元素角标见第 4 节。
- 产出流程：概念图 → 程序化 canvas 绘制（与 talent_sigils.ts 同一套）或 AI 出图后统一调色；不得留空用旧图标。
