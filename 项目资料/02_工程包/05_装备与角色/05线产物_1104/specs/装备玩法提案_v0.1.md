## 1. 余烬灌注（太古余烬的用途）

**一句话卖点**：攒够太古余烬，就能把你最爱的那件橙装「烧」成太古，非酋也有确定的终点。

**玩法机制**
- 铁匠新增「余烬灌注」：选一件**非太古**的橙装 / 暗金 / 套装件，花 N 个太古余烬 + 金币，把它变成太古（词条全部峰值、特效 ×2，规则与掉落的太古完全一样）。
- 价格初稿：套装件 8 个、橙装 10 个、暗金 15 个。一件太古分解得 1 个余烬，所以相当于「分解 8~15 件太古，换一件指定的太古」。
- 另加一个小档「余烬回火」：花 2 个余烬，把一件太古上**一条被淬炼过的词条**拉回峰值（太古淬炼本来就锁 r=1，这一档主要给拓印 / 觉醒之后的边角情况用，也可以不做）。
- 限制：已强化的格子不影响（强化跟着格子走）；灌注前先还原强化再重算，做法与 `recast()` 相同。

**和现有系统的衔接**
- 直接调 `LootGenerator.ancientify()`；它要求 `upgrade` 为空，所以按 `Forge.recast()` 的写法先 `applyUpgrade(item, 0)` 再还原。
- 材料用现成的 `mat_ember`，扣费沿用 `Forge` 的 `whyCannot*` + `spendGold / useStack`。
- 铁匠界面在淬炼 / 重铸旁边加一个页签。

**对玩家目标 / 重复刷的价值**
- 给后期「为了太古反复刷」一个**确定的保底终点**。分解太古不再是「白扔」，每件太古都在推进进度。
- 太古掉率只有 4%~10%，现在全靠运气；有了灌注，长期玩家的挫败感会降很多。

**实现量级**：**小**。01 需要新增：`Forge.infuse(item, gen)` + `infuseCost()`（约 30 行）、铁匠页签 UI、`shop.ts` 里余烬的说明文字改掉。存档**不用改**（`ancient` 字段已有）。

**风险**
- 太古 ×2 特效很强，确定获取会让后期强度上限更早到达。缓解：价格偏贵；暗金的太古只能灌注 1 次 / 周（复用 `Exchange` 的每周限购）。
- 和「太古只能掉落」的稀有感有冲突：灌注出来的太古名字可以加一个小标记（如「（太古·灌注）」），也可以不区分，请 Rhett 定。

## 2. 传说心愿单（定向保底）

**一句话卖点**：标记一个你想要的传说特效，每次首领没出它都在「攒运」，最迟 N 次必出。

**玩法机制**
- 角色面板的「掉落说明书」里，每个本职业传说特效旁边加一颗星，**同时只能标 1 个**（DLC1 后可开到 2 个）。
- 每次击杀首领级敌人（`boss = true` 的掉落判定），如果这次没有掉出心愿特效，心愿计数 +1。
- 计数 ≥ 8：本次掉橙装时，心愿特效的权重 ×3。
- 计数 ≥ 20：这次首领**必定额外掉一件心愿特效的橙装**，然后计数归零。
- 改心愿会让计数减半，防止「快满的时候换目标」。

**和现有系统的衔接**
- 保底结构照搬 `core/Sets.ts` 的 `SetPityState { dry, seen }` 和 `rollSetPiece` 的写法。
- 必出时调 `LootGenerator.generateLegendary(lgId, ilvl)`（已经能按特效生成，名字也会和底材对上）。
- 权重加成在 `generate()` 里选 `lg` 那一步改成加权（现在是均匀随机）。
- `minLevel` 照样生效：38 级前不能把 40 级特效设为心愿。

**对玩家目标 / 重复刷的价值**
- 本体 4 个职业各有 24 个特效，DLC 职业又有一批，**想要的那件可能刷 50 次都不出**。心愿单把「目标」写在界面上，每次击杀都看得到进度条，重复刷就有了方向。
- 和第 1 项连起来：心愿保底拿到想要的特效，余烬灌注把它变成太古，就是一条完整的后期目标链。

**实现量级**：**小**。01 需要新增：存档字段 `wish: { lgId, dry }`（老存档没有字段时默认为空，不用迁移）、`core/Wish.ts`（约 50 行，照抄 `Sets.ts` 的保底）、首领掉落入口挂 1 处、说明书 UI 加星标和进度条。

**风险**
- 掉橙变得可以预期，可能削弱惊喜。缓解：只管「哪个特效」，不管品质和词条，太古和好词条仍然要看运气。
- 首领掉落入口散在野外首领、副本、长副本、深渊、世界首领几处，01 需要确认都走 `LootGenerator.roll(..., boss=true)`。

## 3. 元素合鸣（双元素交汇）

**一句话卖点**：火 6 + 霜 6 不只是各拿两档——会叫出「蒸汽爆裂」这种第三种效果，凑出你自己的元素流派。

**玩法机制**
- 现在的共鸣是 4 个元素各管各的。新增 6 种**两两合鸣**：两个元素都达到 6 条时，额外激活一条组合效果。（估算：16 件 × 平均约 3 条随机词条 ≈ 48 条，其中一半带元素 ≈ 24 条；同时凑两个 6 需要 12 条，是要靠淬炼元素去凑的取舍，凑两个 9 基本做不到。套装件 / 橙装的固定词条不带元素，实际会更少，需要 01 用存档样本核对。）
- 6 种合鸣初稿：

| 组合 | 名字 | 效果（初稿，纯修饰器） |
|---|---|---|
| 火 + 霜 | 蒸汽爆裂 | 对减速中的敌人造成火焰伤害时，引发小爆炸（半径 2.5，30%） |
| 火 + 影 | 噬焰 | 灼烧中的敌人被暴击时，吸血 +4% |
| 火 + 岩 | 熔岩 | 范围技能留下 3 秒熔岩地面（groundZone，火） |
| 霜 + 影 | 冥霜 | 对减速目标暴击率 +6% |
| 霜 + 岩 | 冰川壁垒 | 生命 +6%，受击时 10% 几率获得 8% 最大生命的护盾（内置冷却） |
| 影 + 岩 | 暗岩 | 护甲 +6%、暴击伤害 +12%（本游戏同名的「主题合鸣」） |

- 一个角色最多同时激活 **1 条**合鸣（取两个元素条数之和最高的那组），避免叠爆。

**和现有系统的衔接**
- 全部在 `core/Resonance.ts` 里：`resonanceOf()` 已经算好了 `counts`，只需在后面再判定一次，把合鸣修饰器塞进现有的那件虚拟装备 `item`（`id: 'resonance'`）。
- 效果只用现成的 `EffectDef` 类型（`explode / heal / groundZone / shield`）和条件（`targetHasEffect`），**不碰 web 层**。
- 淬炼里的「重铸元素」（`reforge mode 'elem'`）自然就成了凑合鸣的工具，不用新做系统。
- 外观规格里「元素决定武器光的色相」可以接上：激活合鸣时武器光变成双色（可选，放 DLC1）。

**对玩家目标 / 重复刷的价值**
- 给紫装、蓝装上那些「带元素标签的普通词条」更多价值：一件装备的好坏不只看数值，还看它帮你凑哪一组。
- 刷宝时多了一层判断（「这件带霜，我正好差 1 条到 6」），淬炼元素也有了明确目的。

**实现量级**：**小~中**。01 需要新增：`RESONANCE_PAIR` 数据表 + `resonanceOf()` 加约 25 行；角色面板的共鸣说明加一行；`npm run` 校验脚本加一个用例。存档**不用改**。

**风险**
- 属于主线 core 改动，必须在 11-12 前合进去，否则只能等 DLC1 之后。
- 平衡：6 种强度不一，初稿后需要实测。最多 1 条合鸣的限制会把风险压住。

## 4. 传说萃取 · 钟铜之心（传说特效收藏槽）

**一句话卖点**：刷到重复的橙装别分解了——把它的传说特效萃取进图鉴，再挑 1 个装进「钟铜之心」，等于多穿一件橙装。

**玩法机制**
- 铁匠 / DLC1 戈兹新增「萃取」：消耗一件橙装 + **传说之魂**（现在橙装分解给但没处用）+ 金币，把它的传说特效**永久记入「传说图鉴」**，装备本身销毁。
- 「钟铜之心」有 3 个心槽：**武器 / 护甲 / 首饰**，每槽从图鉴里选 1 个**对应部位类别**的特效装上（类似暗黑 3 卡奈魔盒）。
- 分期解锁：主线只开 **1 个心槽**（玩家自选类别）；DLC1 钟铜熔炉噩梦首通后开第 2 个，结局任务后开第 3 个。
- 规则：心槽里的特效永远是**普通版**（不吃太古 ×2）；和身上已经穿着的同一特效不叠加；切换只能在战斗外，和装备方案 `GearSets` 一起保存。

**和现有系统的衔接**
- 心槽效果做成一件虚拟装备交给 `Loadout.setItems()`，写法和 `Resonance` 的 `{ id: 'resonance', ... }` 一样，不用改 `Loadout`。
- 特效数据直接读 `LootData.legendaries`（含 DLC 包合并进来的），按 `cls` 过滤（`Loadout` 已按 `classId` 过滤 `m.cls`）。
- 图鉴 UI 可以复用纹语图鉴（`web/awaken_ui.ts`）的「已发现 / 未发现」列表样式。
- 材料：`mat_soul` 传说之魂；DLC1 的第 2、3 槽解锁挂到 `PackManifest` 的任务 / 首领回调。

**对玩家目标 / 重复刷的价值**
- **重复橙装从垃圾变成进度**；图鉴「24/24」是天然的收藏目标。
- 搭配深度大增：心槽里的特效 + 身上的橙装 + 套装 + 拓印，可以组出更多构筑。
- 传说之魂终于有用。

**实现量级**：**中**。01 需要新增：存档字段 `codex: string[]`、`heart: (string|null)[]`；`core/Codex.ts`（萃取、装卸、生成虚拟装备，约 80 行）；铁匠萃取页 + 角色面板「钟铜之心」页；`GearSets` 加一个字段；`gearScore` 的「失去特效」提示（`lostEffects`）要把心槽算进去。

**风险**
- **强度膨胀**最大：相当于多一件橙装特效。缓解：只用普通版、主线只开 1 槽、同特效不叠加；有些「代码型钩子」特效（`web/lgfx.ts` 里按战况挂 `lgMods` 的那些）只认身上的装备，**放进心槽会不生效**，需要 01 把这类特效标为「不可萃取」，或者让钩子也读心槽。
- 冻结前做完 1 槽版本比较紧，建议主线只先留存档字段和萃取，心槽 UI 放 DLC1。

## 5. 钟铜盲铸（神秘铸造）

**一句话卖点**：指定部位，花材料盲铸一件——可能是紫装，也可能是你等了一周的太古橙。

**玩法机制**
- DLC1 钟楼营地 / 镜渊城加一个 NPC「盲铸匠」（或放进领地 A 的熔炉，B 结局放在卡戎处，两边都能用）。
- 选**部位**（16 个穿戴格之一），花「深渊碎片」+ 金币，生成一件该部位、当前满级装等的装备。
- 出货概率（初稿）：紫 70% / 橙 28% / 暗金 0%（不出，保住暗金的来源） / 套装件 2%；出橙时照常判定太古（4%）。
- 价格：首饰与武器比护甲贵 1.5 倍；每天前 3 次半价，鼓励每天来一下。
- 和心愿单联动：盲铸出橙装时同样吃心愿权重，但**不计入心愿计数**。

**和现有系统的衔接**
- 生成直接用 `LootGenerator.generate(ilvl, quality, [slot])`（已支持指定部位；没有传说特效的部位会自动降成紫）。
- 太古判定用 `rollAncient()`。
- 货币和扣费沿用 `Exchange.whyCannotPay / pay`，每日次数可以照搬 `ExchangeState` 的周刷新写法改成按天。
- NPC 交互走 `packInteractAt`（`ContentPacks.ts` 已有）。

**对玩家目标 / 重复刷的价值**
- 给深渊碎片、金币一个**无底的消耗出口**，后期刷图的每一份材料都有用处。
- 补「戒指 / 项链永远刷不到好的」这种部位卡关。

**实现量级**：**小**。01 需要新增：`src/dlc/dlc1/blindforge.ts`（概率表 + 生成 + 每日计数，约 80 行）、NPC 与对话框按钮、存档 `dlc.dlc1.blind = { day, used }`。主线不用改。

**风险**
- 经济：深渊碎片也是暗金重铸的材料，盲铸会和重铸抢材料。缓解：价格按 `simEconomy.ts` 跑一遍再定。
- 赌博感：单机没有付费，不涉及合规问题；但**以后商业化只卖外观**，这里绝不能接付费货币，请 Rhett 确认这条原则。

## 6. 渊蚀（高风险改造）

**一句话卖点**：把已经很好的装备丢进深渊再赌一次——可能超越太古，也可能就此定型、再也不能改。

**玩法机制**
- 用「深渊碎片」（主线材料，A / B 结局都能用）对一件**满耐久、未渊蚀**的装备执行「渊蚀」，结果四选一（初稿概率）：

| 结果 | 概率 | 效果 |
|---|---|---|
| 超越 | 15% | 随机一条词条变成 **120% 峰值**（`r = 1.2`），名字变暗紫 |
| 渊纹 | 30% | 加一条「渊蚀词条」（新的小池子，例如「每 10 秒下一次技能 +30% 伤害」「生命低于 35% 时 3 秒减伤 25%」） |
| 无事 | 35% | 什么都不变 |
| 裂变 | 20% | 随机一条词条重随（可能变差） |

- **不论结果如何，装备都变成「已渊蚀」**：不能再淬炼、重铸、拓印、灌注、萃取，只能强化和镶岩纹。
- 每件只能渊蚀一次，所以最佳时机是「太古 + 词条已经满意」之后，等于终局最后的一把赌。

**和现有系统的衔接**
- 改词条走 `affixLog` + `LootGenerator.rebuild()`；`r > 1` 需要 01 确认 `applyAffix` 不封顶（目前公式是 `min + r × (max - min)`，没有封顶），以及 `affixRollRange` / 淬炼峰值显示能接受 120%。
- 「已渊蚀」是 `ItemInstance` 新增的可选字段 `corrupt`，`Forge` 的各个 `whyCannot*` 各加一行判断。
- 渊蚀词条池做成和觉醒词条一样的数据表（`data/awaken.ts` 的 `AwkAffix` 格式），都是纯修饰器。
- 和 DLC1 结局 B「渊噬之躯」主题呼应，但材料用主线的，避免 A 结局玩家用不了。

**对玩家目标 / 重复刷的价值**
- 给满太古的终局玩家一个**真正的天花板之上**：继续刷是为了攒材料，也为了多攒几件「值得赌」的底子。
- 一次性的赌局让每件装备都有故事。

**实现量级**：**中**。01 需要新增：`core/Corrupt.ts`（约 70 行）+ 渊蚀词条表 + 铁匠页签 + 名字颜色 / 提示框标记；`Forge`、`Exchange`、拓印、萃取各加「已渊蚀」判断；存档只多一个可选字段，不用迁移。

**风险**
- 系统之间的判断点多（淬炼、重铸、拓印、灌注、萃取、太古），**漏一处就有绕过办法**，测试量比代码量大。
- `r = 1.2` 会让 `gearScore` 和「是否升级」判断出现大于峰值的情况，01 需要检查 `GearView` 的比较逻辑。
- 建议放 DLC1 之后（冻结前做不完测试）。

## 7. 沉钟海图（定向寻宝）

**一句话卖点**：首领掉一张海图，上面写着「本图必出护手」「怪物 +40% 生命」——你决定今晚刷什么。

**玩法机制**
- DLC 区域首领、钟楼守钟者掉「沉钟海图」（可堆叠物品），每张随机带：
  - **1 条宝藏**：指定部位 / 指定元素词条 / 指定传说类别（形态变换、连锁触发……来自 `LegendaryPower.kind`）/ 太古率翻倍；
  - **1~2 条凶兆**：怪物更多精英、更高生命、会留毒池、首领有额外阶段（直接复用深渊的畸变 `MUTS`）。
- 在潮痕营地「展开海图」，进入一张**复用现有场地**的小地图（沉钟海岸 / 镜渊城片区，或钟铜熔炉的布局），清完拿宝藏。
- 凶兆越多，宝藏额外加一档（多掉 1 件 / 太古率再提高）。海图可以合成：3 张同宝藏合成 1 张「必出橙」。

**和现有系统的衔接**
- 场地和摆怪复用 `PackManifest.dungeons`（`web/packdungeon.ts`）的四档难度框架，凶兆复用 `data/abyss.ts` 的 `MUTS`。
- 定向掉落：部位用 `generate(..., slots)`；传说类别用 `legendaries.filter(kind)` 再 `generateLegendary`；元素在 `rollAffixes` 时偏向指定元素。
- 海图作为 `Inventory` 的堆叠物品（`StackDef kind: 'currency'`）。

**对玩家目标 / 重复刷的价值**
- 把「无目标刷」变成「我手上这张图是刷护手的」，后期最重要的是**选择感**。
- 凶兆让玩家自己调难度换收益，接上深渊的乐趣，但奖励集中在装备上。

**实现量级**：**大**。01 需要新增：海图物品与生成、海图界面、小地图实例化（种子 → 场地 / 怪数 / 凶兆）、定向掉落的三种过滤、结算界面；全部可放 `src/dlc/dlc1/`，但需要 `PackManifest` 支持「由物品打开的副本」，可能要动一点框架。

**风险**
- 工作量最大，冻结前不可能做完，**放 DLC1 之后（DLC2 或 1.x 更新）**。
- 和深渊、副本誓约 / 异变功能接近，要在文案和奖励上拉开（海图 = 定向装备，深渊 = 爬层纪录）。

## 8. 名器铭刻（装备履历 → 名器）

**一句话卖点**：陪你打过 100 个首领的那把剑会「醒」——它会刻上你起的名字，带着专属光纹，一路陪你到满级。

**玩法机制**
- 现有的 `kills`（伴你击败的首领数）变成**名器进度**：50 / 150 / 400 个首领，分别达到「铭刻 Ⅰ / Ⅱ / Ⅲ」。
- 每一阶给：
  - **外观**：武器刃纹 / 护甲饰边多一层流光（Ⅰ 细纹，Ⅱ 常亮，Ⅲ 带粒子），走外观规格第 3 节的 shader，不换网格；
  - **铭文**：Ⅰ 阶可以给这件装备**改名**（限 8 个字，提示框显示「名器·xxx」和「随你击败 400 个首领」）；
  - **极小的属性**：只在 Ⅲ 阶给 +1% 全伤害，主要是纪念。
- **名器传承**：换装时可以花材料把「铭刻阶数 + 名字 + 光纹」转移到同部位的新装备上（阶数掉 1 级），避免「舍不得换装」。
- DLC1 联动：名器 Ⅲ 的光纹作为一个 `kind: 'base'` 外观解锁进幻化收藏，铸造台铸出的武器也能当名器。

**和现有系统的衔接**
- 进度直接用 `ItemInstance.kills`（`core/Awaken.ts` 已经在累加），零新统计。
- 光纹接 `装备外观系统规格_v0.1.md` 的品质 shader（多一个 `inscribe` 强度参数）。
- 改名只是 `item.name` + 一个 `inscribed` 可选字段；`rebuild()` 的 `keep` 列表要加上这个字段。
- 和觉醒的区别：觉醒是「攒 5 点历练换一条词条」的一次性奖励；名器是长线的**情感与外观**，几乎不加强度。

**对玩家目标 / 重复刷的价值**
- 给单机刷宝加上**个人故事**，截图分享（和铸造分享卡 `forgecard.ts` 一样）有话题；
- 不加强度，所以零平衡风险，又顺着「商业化只卖外观」的方向，玩家会更看重外观这一层。

**实现量级**：**小~中**。01 需要新增：阶数计算（几行）、改名弹窗、提示框行、传承功能（铁匠页签）；shader 一个强度参数取决于外观系统的进度（外观换色先落地，名器光纹才能做）。

**风险**
- 依赖外观系统：外观换色冻结前要落地，名器的光纹部分才能跟上；否则冻结前只能先做「改名 + 履历文字」。
- 玩家改名需要过滤敏感词（网页单机，只显示给自己，可以只做长度限制，请 Rhett 定）。

## 10. 推荐优先级前三

**① 传说心愿单（#2）**
- 解决刷宝游戏里玩家流失最大的那一点：**刷不到想要的那件**。本体 24 个特效 + 40 级池，现在全靠均匀随机。
- 代码几乎是照抄 `Sets.ts` 的保底，量级小、风险低，冻结前稳能做完。
- 每次首领击杀都有可见进度，直接提高「再刷一次」的动力。

**② 余烬灌注（#1）**
- 太古余烬是**现成的、玩家已经在攒的材料**，说明文字里已经许诺了「以后用于太古重铸」；不兑现就会一直挂着一个空头许诺。
- 只调现成的 `ancientify()`，存档不改，是最便宜的一项。
- 和心愿单连成**完整的后期目标链**：心愿拿到特效 → 灌注成太古 → 强化、岩纹收尾。

**③ 元素合鸣（#3）**
- 给大量蓝紫词条和「重铸元素」功能补上意义，让装备判断不只看数值，**构筑多样性的收益最高**。
- 纯修饰器数据，改动集中在 `Resonance.ts` 一个文件，不碰 web 层；但它是主线 core 改动，**错过 11-12 就要等到 DLC1 之后**，所以要优先。

**次选**：钟铜盲铸（#5）——完全在 `src/dlc/dlc1/` 里，不受主线冻结影响，可以和前三项并行，作为 11-12~11-19 之间 DLC1 内容的补充。

**DLC1 之后**：传说萃取完整版（#4，先留存档字段）、渊蚀（#6）、沉钟海图（#7）、名器光纹（#8，跟外观系统走）。
