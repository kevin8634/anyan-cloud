## 3. 新组件 API（`window.AnyanLoader`）

```js
AnyanLoader.show(opts?)        // 挂载。页面上已有静态 #anyan-loader 标记就直接接管，否则自建 DOM
  // opts: { root?: Element|'#sel', assetBase?: 'assets/', tips?: [{en, zh}], tipInterval?: 4600,
  //         autoTips?: true, zIndex?: 400, reducedMotion?: bool(默认跟随系统) }
AnyanLoader.setProgress(p, tip?) // p: 0..1（>1 视为百分数）；显示值单调递增、平滑追赶（约 1 秒追上）
                                 // tip 可选：{en, zh} 或 "中文"，顺便换一条提示
AnyanLoader.setStage(text)       // 进度条左下小字，如 "角色模型 · 2/5"
AnyanLoader.setTip(tip)          // 手动换提示（默认每 4.6 秒自动轮换内置 8 条中英占位文案）
AnyanLoader.finish(cb?)          // 1 秒内走满 → 钟体一震 + 强光声环 → 1.1 秒淡出 → 移除 DOM → cb()；返回 Promise（约 2.3 秒）
AnyanLoader.destroy()            // 立即移除（不播结尾）
AnyanLoader.state()              // 调试：{ shown, target, done, reducedMotion }
AnyanLoader.TIPS                 // 内置提示数组，可直接改/替换
```

脚本没跑之前（大 JS 下载/解析期间）：LOGO 浮现、进度条和提示淡入、熔铜流动、辉光呼吸都是**纯 CSS 动画**，照样在动；声波环、余烬、火星要等 JS 接管后才出现。

## 4. 开发窗口替换步骤（最小改动）

### 第 1 步：换 HTML（`src/web/index.html`）
把 **L1505–L1563**（旧注释 + `<style>` + `<div id="boot-load">…</div>`）整段删掉，原位置粘贴 `loading_inline_snippet.html` 的全部内容。
- 粘贴位置在 `<body>` 开头、游戏 `<script>/*GAME_JS*/</script>` 之前，所以 `window.AnyanLoader` 在游戏脚本执行前就已定义。
- 不想内联图片的话：把 `assets/` 拷到 `web/` 旁边，改用 `loading.css` + 本目录 `loading.html` 里 `↓↓↓ … ↑↑↑` 之间的标记 + `<script src>` 引 `loading.js`（单 HTML 离线分发时不推荐）。

### 第 2 步：改 `src/web/loading.ts`（保留 `loadTask` 的真实进度统计，只换显示层）
```ts
// 文件头加：
declare const AnyanLoader: {
  show(o?: object): unknown; setProgress(p: number, tip?: unknown): unknown;
  setStage(t: string): unknown; finish(cb?: () => void): Promise<void>;
};

// stage()：把 el.textContent = … 换成
AnyanLoader.setStage(cur ? `${cur.label} · ${n}/${tasks.length}` : tasks.length ? '准备场景…' : '正在接收资源…');

// paint() 整个删掉；tick() 改成（组件内部自带平滑和单调递增）：
function tick() { AnyanLoader.setProgress(finished ? 1 : Math.min(real(), 0.99)); raf = requestAnimationFrame(tick); }

// rotateTip() / TIPS / tipTimer 可删（组件自己轮换；要用游戏原有提示就在 show 里传 tips）

// loadingStart()：
export function loadingStart() {
  if (started) return; started = true;
  AnyanLoader.show();   // 可选：AnyanLoader.show({ tips: [...] })
  stage(); raf = requestAnimationFrame(tick);
}

// loadingFinish()：
export async function loadingFinish() {
  while (pending.size) await Promise.all([...pending]);
  finished = true; AnyanLoader.setStage('就绪');
  cancelAnimationFrame(raf);
  await AnyanLoader.finish();          // 一震 + 声环 + 淡出 + 移除，约 2.3 秒
}

// loadingDebug()：present 改查新 id
present: !!document.getElementById('anyan-loader')
```
`main.ts`、`creatures_glb.ts`、`envhd.ts` 的调用**都不用改**（`loadTask / loadingStart / loadingFinish` 签名不变）。

注意：
- `LOADING_ART`（比赛版背景）新组件暂不使用；`import { LOADING_ART }` 那行如果只剩它没用到，删掉以免 tsc 报未使用。
- 结尾比旧版多约 1.3 秒（旧版 320 ms + 700 ms；新版走满 ≤1 s + 一震 1.15 s + 淡出 1.1 s）。嫌长可改 `loading.js` 里 `finish()` 的两个 `1150`。
- 旧 `#boot-load` 的 CSS 只在被删掉的 `<style>` 里，没有别处引用（已 grep 过 `src/ test/ tools/`）；无头测试只用 `window.__loadDbg`，接口不变。

### 第 3 步：构建 + 自测
`npm run web:check && npm run web` → 打开 `web/index.html`：确认加载中百分比走动、阶段文字是真实任务名、100% 后一震淡出、开场正常接上。手机竖屏 / 系统「减少动态效果」各看一眼。

## 5. 效果说明

- **浮现**：纯黑底，LOGO 2.6 秒从 96.5% 缩放 + 透明缓缓浮现（纯 CSS）。
- **熔金点亮**：「深渊回响」默认是冷铁暗色，随进度从左到右被熔金点亮（软边遮罩），前沿有一条更亮的热区，已点亮部分带辉光呼吸。
- **青绿声波环**：以钟口沿为中心的扁椭圆，带轻微起伏不是死板正圆；前（下）亮后（上）暗，像绕到钟后面；间隔从 2.8 秒随进度缩到 1.2 秒，越接近完成越密越亮。
- **余烬**：桌面 64 / 手机 34 颗，从钟口下方和画面底部上浮、左右摆动、闪烁，亮度随进度增强。
- **熔铜进度条**：锻铁边框 + 两端菱形铆钉帽；熔金液面渐变 + 斜纹流动；末端白热光点 + 火星迸溅（推进越快火星越多）；下方左侧阶段文字、右侧百分比；再下面两行提示（上英斜体、下中），淡入淡出轮换。
- **100%**：钟体阻尼一震（约 1 秒），一圈金白强光声环 + 青绿余波荡开，余烬被声浪推散，画面淡出进入游戏。
- **适配**：16:9 下 LOGO 宽 `min(1080px, 90vw, (100vh−250px)×1.5)`；竖屏（宽高比 < 1）LOGO 放大到 118vw，两侧声波光晕允许出画，汉字和钟体完整；横屏手机压缩间距。已截图核对 1280×720、1920×1080、390×844、844×390。
- **性能**：一个 rAF；余烬/火星用预渲染光点精灵 `drawImage`，无 shadowBlur；DPR 上限 2（手机 1.5）；页面隐藏时自动停循环；图片合计 163 KB。
- **减少动态效果**（`prefers-reduced-motion` 或 `?rm`）：无余烬/火星、无震动、声环改为一圈随进度变亮的静态环，进度直接跳到目标值，LOGO 只做简单淡入。
