# 首领面数与贴图预算（11-01 Rhett 定方向，供主线与长副本 raidA 交接参考）

## 结论
首领战场景元素少、同屏只有 1 个首领（+少量小怪），且首领放大 2 倍左右显示，低面数的棱角和贴图糊会被放大。
所以首领单独放宽预算，小怪维持原标准。

| 类别 | 三角面 | 贴图 | 备注 |
|---|---|---|---|
| 小怪 / 召唤物 | 8k–12k | 1024 | 同屏多只，保持原标准 |
| 精英 | 12k–20k | 1024–2048 | |
| 首领（本体） | 30k–50k | 2048（可加法线贴图） | 同屏仅 1 只；放大显示 |
| 首领武器/提灯等刚性件 | 2k–5k | 1024 | 单独模型挂手骨 |
| 首领战场景（竞技场） | 总量控制在 ≤ 普通区域的 60% | | 给首领腾预算 |

## 做法
1. Lux3D G1 原始件约 10 万面，保留原始文件（/workspace/work/lux3d_raw/<taskId>/），首领后处理用 `--target 40000 --tex 2048` 重新出，不必重新生成、不花积分（`node tools/lux3d.mjs post 原始.glb --target 40000 --tex 2048 ...`）。
2. 绑骨仍用约 1.5 万面的绑骨输入件（上传 <1MB，过资格校验更稳）；绑好后把权重按最近顶点/重心插值传到 4 万面显示网格（权重转移，免费）。显示网格和绑骨网格分开存。
3. 准备 LOD：近景 40k，远景/低画质 15k（就是绑骨件），按画质档切换。
4. 蒙皮骨骼数控制在 ≤ 60 根，每顶点 ≤ 4 权重；SkinnedMesh 开销主要在顶点数，单只 40k 面可接受。
5. 性能验收：首领战场景在中档（swiftshader e2e）与演示机目标 ≥ 50 FPS；不达标先降场景再降首领。
