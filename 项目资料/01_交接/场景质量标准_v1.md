# 场景质量标准 v1（Rhett 11-02 13:33 定，全线适用）

> 目标：场景「高清、纹理真实、看着舒服」。优先级：光影调色 > 贴图 > 布景密度 > 模型面数。与「质量硬标准 8 条」并行生效。

## 1. 光影与调色（每个场景必做，0 积分）
- 每个区域/副本有自己的主色调与调色（图层专属调色），冷暖对比明确。
- 高度雾 / 分层体积雾（近淡远浓，按区域调色），不得只用全局单色雾。
- 环境光遮蔽（AO）：墙角、石缝、物件接地处必须发暗；物件不得「浮」在地面上。
- 主光 + 补光 + 关键点光（火盆、荧光、熔铜）有明确光源逻辑。
- 水面/镜面有反射或假反射。

## 2. 贴图（「高清、纹理真实」的主体）
- 贴图密度统一：同一镜头距离下地面、墙、道具清晰度一致，不允许「一件清、一件糊」。
- 重要表面用 PBR 三件套：底色 + 法线 + 粗糙度（湿石反光、干土哑光）。纯色材质只允许用于远景或特效。
- 大面积地形：可平铺材质 + 按掩码混合（泥/石/苔/沙/潮痕），再加贴花（水渍、裂纹、苔藓、铜锈）。
- 压面必配贴图重绘或法线烘焙（沿用戈尔顿 v4 标准）。

## 3. 布景密度
- 分层植被/礁石（地表碎件 → 灌木/小礁 → 大件），边缘有过渡，不留大片空地面。
- 散落小道具讲故事（锁链、碎钟片、缆绳、木栈、鲸骨、蜡烛）。
- 全部实例化合批，按四档画质分级。

## 4. 模型
- 轮廓好认、边缘倒角；地标主体（镜头会对着的 1–3 件）才用高精模型。
- 其余中等面数即可，不为面数花积分。

## 5. Lux3D / Aholo 积分用法
- 只花在「镜头会对着的地标主体」：Lux3D 图生 3D（约 20/件）或材质重绘（约 13–19/件）。
- 3D 高斯重建（20–100/次）需实景拍摄，本项目不用。
- AI 空间生成（10/次，出 360 全景 + 高斯点云）仅可试用于远景/天空盒，不作场景主体（无碰撞、不吃游戏灯光、体积大）。
- 任何生成先列清单与预估 → Rhett 确认 → 才生成 → 记台账。

## 6. 验收
- 每个场景改造前后同机位对照图（至少 3 个机位）+ 帧率读数（2060 高画质 ≥45、手机 30）。
- 截图由浏览器任务串行拍。
