# 井口码头 场景改造样板 · 怎么跑（raidA d915e72，11-03）

## 打开哪个文件
- `index_dlc1_比赛版.html`（本目录，比赛版 DLC 离线单文件）。直接双击用 Chrome / Edge 打开即可。
- 背景音乐在工程包 web/music/（同目录放一份 music/ 才有音乐；没有也不影响看场景）。

## 新旧切换（URL 参数）
- 改造后（默认）：`index_dlc1_比赛版.html?scene=new` 或不带参数
- 改造前：`index_dlc1_比赛版.html?scene=old`
- 在地址栏 .html 后面加参数回车即可；切换要刷新页面。
- 画质档：设置里选「高 / 极高」= 水面平面反射；「中」= 环境假反射（手机默认中档）；「低」= 只留一层雾。

## 怎么进井口码头（F12 控制台粘贴）
1. 进到标题页，等按钮变成「开始冒险」。
2. 控制台依次执行：
```js
__game.startGame('warrior')
```
```js
const g = __game; g.tutFinish?.(); g.progression.level = 40; g.packDungeon.enter('dlc1_well_dg', 'normal')
```
3. 进副本后传送到码头（首领戈尔顿就在这；想安心看景先开无敌）：
```js
const g = __game; g.player.maxHp = 1e12; g.player.hp = 1e12; g.player.pos.set(2700, 0, -2700 + 46 + 13)
```
- 其他机位：码头侧面 `pos.set(2688, 0, -2650)`；近景 `pos.set(2704, 0, -2648)`。
- 进区调色是渐变的：从远处走进码头 22 米内会看到雾色 / 曝光慢慢过渡；`__dlc1.well.debug().dockGrade` 看权重 w（0–1）。

## 改了什么（阶段 1）
程序化 IBL（PMREM：井口冷天光 + 湿岩暗部 + 暖灯斑）、本区调色（雾色 / 曝光，进区插值、出图恢复）、三层高度雾片（噪声流动、贴水浓上层淡）、4 盏鱼油灯暖点光 + 井口冷色聚光、木板 / 横梁 / 系船墩倒角 + 平滑法线、水面反射分档。代码：src/dlc/dlc1/well_dock_hd.ts（raid_well.ts 里按 ?scene 挂载）。
