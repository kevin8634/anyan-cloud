## 1. 职业视觉主题

- **主角是那口铁棺**：锈铁包角、焦黑棺木、铆钉、棺链——一个有重量的实物。它拖地会擦出火星，砸地会压出坑，开盖会吱呀作响；不是半透明发光的「棺影」。
- **魂是灰的，不是彩色光球**：亡魂用写实幽魂（`GhostMesh`：菲涅尔半透明、拖尾冷雾、隐约扭曲的人脸 / 兽脸），按魂种只做轻微色偏；不进泛光。
- **暗影 = 吸光**：墨烟（反向加深）、被吸暗的地面；**紫色腐蚀** = 偏灰的暗紫油烟 + 地面油膜状腐蚀纹 + 焦黑边，像尸油渗进石头。
- **葬礼的物件**：寿衣旧布、墓土、墓碑、纸钱灰、引魂幡、丧钟——每个技能都留下送葬过后的痕迹（墓土、碎骨、烧过的纸灰、腐蚀坑），4–8 秒淡出。
- 禁止：霓虹紫（现 `#9a70ff` 与奥术紫撞色）、墓绿（现 `#7fe0b0` 读起来像毒）、地面六芒法阵、白色星形闪光、实心色盘、发光的绿眼睛。

## 2. 三系视觉标签与绝技特效

> 以代码为准：`coffin.ts:34–44` 用 `talentTree3(COFFIN_TREE, …)` 把 `coffin_data.ts:61–68` 的三系 `c_und 送葬者 / c_war 守墓人 / c_fer 摆渡人` 重排成天赋 3.0；绝技（终极）为 `cs_full 满棺齐放`、`cg_night 永夜守陵`、`cr_styx 冥河摆渡人`。
> **与报告不一致**：报告 7.4 定稿的三系是「送葬者 / 饮血者 / 凋魂者」，代码仍是「送葬者 / 守墓人 / 摆渡人」。本文按代码三系出视觉，并把报告新增的两样东西挂到最贴近的系上：**恐惧 → 送葬者**（报告「哀魂」），**紫色腐蚀 → 守墓人**（报告「腐朽之地：立棺墓碑周围地面腐蚀」本就是墓碑机制）。若之后按报告改系，视觉标签整体迁移：凋魂者 = 紫色腐蚀 + 恐惧全套；饮血者 = 下表「摆渡人」的续航血雾层。

### 2.1 绝技特效

**送葬者 · 满棺齐放（`cs_full`：3 魂开棺伤害 +40%，开棺后返还 1 个随机魂）**
- 表现：3 魂开棺时，背棺先剧烈震动 0.2 秒（棺盖缝隙喷墨烟、棺链绷紧），棺盖不是「打开」而是**整块崩飞**（实体棺盖旋转飞出 3 米落地插进土里，4 秒后消失）；魂群涌出量 ×1.5；返还的那只魂开棺结束后从魂群里掉头，一头扎回棺中（0.4 秒，灰青拖尾），棺链「咔」地重新锁上。报告版（瞬间满魂并开棺，伤害 +50%）：开场 0.3 秒地面四周冒出 3 道魂雾被强行吸进棺里，再接上面整套。
- 镜头：崩盖瞬间顿帧 100ms + FOV −4° 推；魂群涌出沿面朝方向推镜。
- 音效：铁棺震颤（金属嗡鸣）→ 棺盖崩飞的爆裂 + 铁链崩断 → 魂群合唱般的低语；返魂时一声短促吸气 + 锁链声。

**守墓人 · 永夜守陵（`cg_night`：墓碑回响伤害 100%，墓碑周围减速 50%）**
- 表现：立着的墓碑（立棺）周围 5 米（含墓域加成）地面变成「夜土」——紫灰腐蚀纹从棺底呈树根状向外爬满（`GroundFx: corrode`），贴地暗紫油烟缓慢翻涌，雾里偶尔伸出一只半透明的手抓住敌人脚踝（减速 50% 的可见原因）；墓碑回响由「淡影重放」变为**实体重放**：从墓碑里伸出一具与负棺人同姿态的灰青亡者，完整复刻技能动作（见 3.1）。报告版「冥河凋零」（侵蚀满 30 层，8 秒每秒 1% 最大生命）挂在此系：目标全身爬满紫灰腐蚀纹、皮肤龟裂、每秒从裂缝里冒一股暗紫油烟（见 3.5）。
- 镜头：开启时低角度镜头掠过墓碑 0.6 秒（仅首次立棺，可在设置关闭）。
- 音效：远处丧钟一下 + 土下低语环境循环（墓碑 6 米内，3D）。

**摆渡人 · 冥河摆渡人（`cr_styx`：背棺普攻按伤害 6% 回血；棺满时再收魂改为回 5% 生命）**
- 表现：背棺链甩扫过的轨迹上留下 0.6 秒的**冥河水痕**（深海蓝薄水面 + 泡沫边，贴地），被扫中的敌人身上抽出一缕灰青魂雾沿链飘回负棺人胸口（回血可见）；棺满时收到的魂不进棺，而是在负棺人身前化作一盏摆渡人的灯（魂火冷白，0.6 秒）后熄灭，同时回血。
- 镜头：无额外镜头（高频）。
- 音效：链甩加一层水声泼溅；回血时轻微的水下吐息。

## 3. 系统特效（背棺 / 立棺 · 收魂 · 未亡 · 恐惧 · 紫色腐蚀）

### 3.1 背棺 / 立棺（F）与墓碑回响

- **现状问题**
  - **背棺普攻每一下都从 6 米高空砸下一口棺**：背棺态把普攻改成 `circle`（`coffin_runtime.ts:29` `setShape: 'circle'`，加 `aoe` 不加 `spin`）→ `src/web/casting.ts:191` 走 `nova` → `coffin_fx.ts:112–126` 落到默认分支 `coffinDrop(F, at, r, 1.4, 6, 0.22)`，还每下 `F.feel('heavy', 0.8)`（`coffin_fx.ts:46`）。背棺是默认棺态，所以玩家最常看到的普攻就是「天降铁棺」。
  - 立棺：`coffin_runtime.ts:78` 只画一个几何圈；`coffin_model.ts:163–165` 立起的棺材脚下常驻一圈加色发光环 `glow(0x9a90c0)`；墓碑减速没有可见原因。
  - 墓碑回响：`coffin_runtime.ts:157–170` 用 `fireFrom` 在墓碑处把整套技能表现原样再画一遍（同亮度、同音效），外加一个几何圈（`coffin_runtime.ts:169`），看起来像技能放了两次而不是「墓碑在回响」。
- **新做法**
  - 背棺（默认）：铁棺斜背，棺链在腰间绕两圈；魂数显示在棺盖缝隙（见 3.2）。走路时棺底偶尔磕地扬一点尘。
  - 立棺（按 F）：① 预兆 0.1 秒：负棺人反手解链；② 出手 0.08 秒：铁棺被**砸立进地里**（棺底插入 0.4 米，四周墓土翻起、碎石溅开，`GroundFx: crater` 小号）；③ 持续：棺身微倾成碑，棺盖上刻痕亮起魂火（冷白，亮度 ≤ 1.2）；碑周 5 米内贴地一层薄冷雾，敌人进入时脚边泥土被吸住般下陷（减速可见），**不画圆环**；④ 无命中；⑤ 收棺（再按 F / 走出 30 米）：棺链从远处飞回把棺拽出地面，留下一个土坑 6 秒。
  - 墓碑回响（技能 0.25 秒后在碑处再放 60%）：从棺中探出一具**灰青亡者**（`GhostMesh`，负棺人轮廓、无脸），以 70% 亮度、去饱和、无白闪复刻同一个技能动作；音效同技能但低通 1200Hz + 0.15 秒混响尾巴（像从棺里传出来的回声）；去掉几何圈。
- 实现：`coffin_fx.ts` 新增 `kind === 'nova' && s.tags.includes('back') && s.slot === 'basic'` → 链甩分支（见第 5 节「棺击」）；回响由 `coffin_runtime.ts` 在 `runEcho` 前置一个只读标记（如临时 `addTag('echo')` 修饰器，表现层读 `s.tags.includes('grave')` + `displayName` 前缀「墓·」）供 `coffin_fx.ts` 切换为亡者重放版；粒子上限（回响版）为原技能的 50%。

### 3.2 收魂（击杀 / 首领每掉 5% / 锁魂链）

- **现状问题**：`coffin_runtime.ts:84–99` 收魂只有数据；画面上只是背棺上 3 个小球换颜色（`coffin_model.ts:137–145`，`MeshBasicMaterial` 高饱和 `SOUL_COLOR`）；首领抽魂只有 toast（`coffin_runtime.ts:102–108`）。
- **新做法**
  - 击杀：尸体倒下 0.2 秒后，胸口被扯出一缕**带脸的魂**（`GhostMesh`，按魂种：兽 = 兽首轮廓、人 = 人脸、巨 = 宽大模糊的脸、异 = 扭曲多眼），挣扎着被拽向负棺人背后，被棺盖缝隙「吸」进去（0.5 秒，拖尾冷雾）；棺盖缝隙随魂数渗出 1 / 2 / 3 缕灰雾，第 3 缕带轻微墨烟（满魂可读）。
  - 首领 / 精英抽魂：每掉 5% 最大生命，首领身上被撕下一小片魂雾（不带脸，避免刷屏）飞入棺中；锁魂链命中精英时，链上逆流回一缕魂。
  - 棺满（3 魂）再收魂：魂撞在棺盖上被弹开、散成冷雾（摆渡人绝技改为化灯回血，见 2.1）。
- 材料：幽魂 #A9C3C6 + 魂种色偏 ≤ 25%；墨烟 #14101C。
- 音效：每收一魂一声短促的叹息 / 兽喘（按魂种 4 套）+ 棺盖轻磕；满魂时棺里持续极轻的低语（3D 跟随背棺）。
- 实现：表现由 `harvest / pullSoul` 发事件给 `coffin_model.ts`（新增 `soulFly(from, soul)`）；同屏飞魂上限 6，粒子上限 80 / 48 / 20；低画质飞魂改为无脸灰雾。

### 3.3 未亡 · 入殓（致命伤 → 躺进棺里 2 秒，每魂复活 15%）

- **现状问题**：`coffin_runtime.ts:237–240` 入殓只有 toast「入殓……」+ 几何圈；`coffin_model.ts:171–179` 放一口棺、玩家模型直接隐藏；复活只有 toast（`coffin_runtime.ts:187`）。
- **新做法**：① 致命一击时画面去饱和 0.3 秒、时间 ×0.5 慢放 0.2 秒；② 铁棺从背上翻落、棺盖弹开，负棺人仰面倒进棺里，棺盖自己合上，棺链缠紧（0.5 秒）；③ 入殓 2 秒：棺身周围地面渗墨烟，棺中魂一个个从缝隙渗出又绕棺一圈后钻回棺里（每魂一圈，玩家看得出用了几个魂）；④ 复活：棺盖被一脚踹开，负棺人带着一身墨烟站起，脚下墓土炸开一圈；⑤ 余韵：棺落处一个人形浅坑 + 碎骨 6 秒。
- 镜头：倒下时镜头轻微下沉；复活时低角度 0.4 秒推镜。音效：心跳一下 → 棺盖闷合 → 铁链 → 低语倒数 → 踹盖巨响 + 粗重吸气。
- 实现：`coffinVisual` 的 `rest` 分支替换为上述序列（DLC 内），粒子上限 120 / 70 / 30。

### 3.4 恐惧（新增；报告 7.4：送葬者「哀魂」开棺尖啸恐惧小怪 2 秒；侵蚀 10 层恐惧 1.5 秒；首领免疫改易伤）

- **现状**：代码中**不存在**——`src/core/types.ts` 的状态没有 `fear`，怪物没有「逃跑」AI；报告第 18 节计划在本体 `core/Combat.ts` 加 `fear`。本节只定画面。
- **画面**
  - 施加瞬间（0.2 秒）：一张半透明的**扭曲人脸**（`GhostMesh`，嘴张到撕裂）贴着敌人的脸尖啸冲过，敌人头部被冲得后仰；敌人身后被扯出一道自己的墨烟残影（反向加深，0.4 秒拖尾）。
  - 持续（1.5–2 秒）：敌人转身逃跑，动作慌乱（播放受击 + 跑动混合）；身后每 0.3 秒留下一团墨烟脚印；眼窝里各有一点冷白魂火在抖（唯一光源，亮度 ≤ 0.8）；状态字「恐惧」用 HUD，不在头顶画骷髅图标。
  - 首领（免疫，改易伤 +8% / +10%）：扭曲人脸撞在首领身上碎开，首领胸口留下一圈**紫灰腐蚀裂纹贴花**（易伤期间持续），首领不逃跑、只是动作顿 0.1 秒。
  - 结束：墨烟残影被吸回身体，敌人回头。
- 音效：尖啸（女声 + 风声合成采样，0.5 秒，3 变体）+ 敌人惊叫（按怪物类型，可无）；逃跑期间无额外音。
- 实现：表现注册在 DLC（`coffin_fx.ts` 新增 `fearFx(unit, dur, boss)`），由本体状态系统回调；同屏恐惧表现上限 12 个敌人，粒子上限 150 / 90 / 36；低画质去掉扭曲人脸，只留墨烟残影。

### 3.5 紫色腐蚀（新增「侵蚀」叠层；报告 7.4：暗影持续，吃急速不暴击；腐朽之地；10 层恐惧；30 层冥河凋零）

- **现状**：代码中**不存在**侵蚀机制；当前所有「暗影侵蚀」DoT（如 `AAA 幽冥开道`、`BHA 百鬼送葬`、`BBA 噬魂兽群`，`coffin_skills.ts:102、105、116`）走本体默认 DoT 表现，无专属画面。
- **画面分级（叠层越高越明显，玩家扫一眼就能判断层数）**

| 层数 | 目标身上 | 地面 / 环境 |
|---|---|---|

## 5. 技能分节

> 每节统一格式。「棺态差异」写背棺 / 立棺下的不同（棺态修饰见 `coffin_runtime.ts:26–34` `modeMods`；立棺时技能都会在墓碑处以亡者重放一次，统一见 3.1，各节不再重复）。粒子上限写作「高 / 中 / 低」。

### 棺击（cf_swing）· 普攻 · 物理 · 瞬发

- **定位**：铁棺砸向目标，24 伤害 / 0.9 秒，2.8 米单体。背棺：改为棺链横扫自身 3.2 米一圈（伤害 −15%）；立棺：墓碑处再砸一次。数值不改。
- **现状问题**：`coffin_fx.ts:64–67` 每下画一口加色紫色半透明「棺影」（`ghostMat(VIO,…)`）砸下，`coffin_fx.ts:68` 白色星形闪光，负棺人背上真正的铁棺反而不动；**背棺态**普攻变成 `circle` 后走 `nova` 默认分支，**每下从 6 米高空掉一口铁棺并触发重击震屏**（`coffin_runtime.ts:29`、`src/web/casting.ts:191`、`coffin_fx.ts:126`、`coffin_fx.ts:46`）。
- **分镜**
  - ① 预兆（0–0.08 秒）：负棺人肩一沉，背上铁棺随动作被甩到身前（实际挥动的是棺本身）。
  - ② 出手（0.07 秒）：铁棺抡下，锈铁包角先着；动作最高点无闪光。
  - ③ 飞行 / 持续：近战无；背棺见棺态差异。
  - ④ 命中（0.15 秒）：按材质 `HitLayer`（血肉 → 血雾；骨 → 骨屑；金属 → 火星 #FFC56B；石 → 碎石）+ 棺角撞出的锈屑（#5A4A40 小碎片）；目标被砸得一矮。
  - ⑤ 余韵（4 秒）：地上锈屑、骨屑贴花淡出。
- **棺态差异**：背棺（链甩）——负棺人松开半截棺链，铁棺在链上贴地横扫一周（3.2 米）：棺底擦地拖出一圈断续火星（`#FFC56B`，加色仅火星）+ 锈屑 + 尘弧，链节在空中留 0.15 秒铁灰残影（普通混合）；被扫中的敌人向外踉跄。立棺——墓碑处亡者重放（3.1）。
- **材料与色板**：锈铁 #5A4A40 / 铁 #3A3634 / 棺木 #1E1A18；火星 #FFC56B；骨屑 #CFC6B4；尘 #8B6F4E。
- **多元素变体**（形态不变：仍是一记砸 / 一圈链甩）：双（物理 + 暗影）：棺缝里随砸击喷出一股墨烟（反向加深），命中处留墨迹；三（物理 + 暗影 + 冰）：棺角结霜、命中处冰晶 + 墨烟，墨烟遇冰凝成黑色霜花（暗影 + 冰的视觉混合，冰沿地面传导到 3 米内敌人结霜）。
- **镜头与打击感**：顿帧 40ms（暴击 100ms）；沿挥砍方向震屏 1 像素；链甩多目标只顿一次 40ms，**不再每下触发重击震屏**。
- **音效**：铁棺挥动的沉重风声 + 铁木闷撞 + 材质层；链甩为铁链哗啦 + 棺底刮地。
- **实现要点**：`coffin_fx.ts` 的 `melee` 分支改为挥动背上真实的铁棺（`coffin_model.ts` 已有 `coffin_back`，动画层摆动）；`nova` 分支前加判断 `s.slot === 'basic' && s.tags.includes('back')` → 链甩分支（`WindVortex` 环形尘弧 + 实体链 + 火星）。粒子上限 50 / 30 / 14；低画质链残影关闭。
- **新图标**：深色岩石底 + 青铜八角框，灰色槽位边；主体：一口锈铁包角的铁棺抡下砸地，地面碎裂、锈屑飞溅。

### 拖棺冲锋（cf_drag）· 技能 1 · 物理 · 瞬发

- **定位**：12 米突进，32 伤害，撞晕 0.5 秒（背棺冷却 −15%）。数值不改。
- **现状问题**：拖棺 + 擦地火星的思路对（`coffin_fx.ts:74–75`、`216–220`），但 `coffin_fx.ts:80–81` 落点几何圈 + 白色 2.4 号星形闪光，`boneDust` 内含白→紫加色火花（`coffin_fx.ts:34`）。
- **分镜**

  - ③ 飞行（0.18 秒）：棺底犁地——一道连续犁沟（`GroundFx: furrow`），沟边翻起墓土和碎石，棺角擦出火星串；身后扬尘。

- **棺态差异**：背棺默认如上；立棺时冲锋不拖棺（棺在墓碑处），改为铁链从墓碑处拉一道直线到负棺人身上——提示「棺还在后面」。
- **材料与色板**：犁沟 #2A2622；墓土 #4A3A2C；火星 #FFC56B；尘 #8B6F4E。
- **多元素变体**：双（物理 + 火）：犁沟里烧起一溜低矮火焰（`FlameSeq` 小号），沟沿焦黑；三（物理 + 暗影 + 冰）：犁沟结冰、冰面下渗墨烟，撞击点冰晶炸开 + 墨迹。
- **镜头与打击感**：命中顿帧 80ms；沿冲锋方向推镜 2 像素。
- **音效**：铁棺犁地刮擦长音（随速度变调）+ 火星噼啪 + 肩撞闷响 + 棺撞金属声。
