## 1. 职业视觉主题

- **兽魂是「被契约召来的灵」，不是发光的动物**：灰青半透明（菲涅尔边缘 + 拖尾冷雾，`GhostMesh`，不进泛光），能看见毛流和呼吸白气，落地会踩起尘土。
- **三形态 = 三种物质**：狼 = 雷（短促分叉电弧、毛发静电、臭氧烟、电焦裂纹）；熊 = 土（尘土、碎石、翘起的岩板、沉闷的重量）；鹰 = 风（空气扭曲、羽屑、高空俯冲的破风线）。
- **契约 = 青铜**：契刃、图腾、锁链上的契纹是旧青铜刻痕（新铜金 → 铜绿锈），只有刻痕本身微亮，整件武器不发光。
- **猎人的痕迹**：每一击都留下爪痕、血迹、兽足印、羽毛或电焦纹，4–8 秒淡出——像一场真的围猎刚刚发生过。
- 禁止：整只发光的蓝狼 / 橙熊 / 青鹰、地面青色六芒法阵、白色星形闪光、实心色盘。

### 2.1 绝技特效

**雷狼 · 头狼（代码 `hw_alpha`；报告 7.4 定稿名「头狼 · 奔雷」）**
- 触发：成为狼形态时常驻；狼形命中流血 / 感电目标回兽魂（`hunter_runtime.ts:145`）；换形技「群狼扑袭」伤害 ×2。
- 表现：狼形期间猎手背后常驻一头 1.3 倍体型的**头狼兽魂**半身（只到胸口，贴着猎手后背，随动作前扑），鬃毛上的静电比普通狼形密一倍；回兽魂时，一缕灰青魂雾从目标飘回头狼口中（0.35 秒）。奔雷（报告版）爆发：感电满层触发落雷时，头狼仰头，一道真实分叉落雷（`ArcBolt` 主干 + 3–5 分支，0.1 秒亮、0.05 秒重生两次）劈在目标上，地面炸出放射状电焦裂纹（`GroundFx: scorchArc`，6 秒淡出）+ 臭氧白烟；随后电弧在 6 米内跳 3+2 个目标。
- 镜头：落雷顿帧 100ms，沿雷劈方向向下 2 像素震屏；首领身上只打 60ms。
- 音效：头狼低吼常驻（极低音量）；落雷 = 近处炸裂 + 远处滚雷尾音。

**巨熊 · 巨熊之怒（`hb_ursoc`）**
- 表现：破甲上限 5 → 8；当目标破甲 ≥ 5 层，猎手每次命中，目标脚下地面向外拱起一圈裂开的岩板（不是圆环，是 5–7 块不规则翘起的石板 + 尘土喷出），目标护甲裂纹透出暗红。猎手熊形时身后熊魂鼻息喷出白气。报告版（8 秒连续震地）：每 0.5 秒一次真实震地，地面逐次塌陷成浅坑（`GroundFx: crater`，坑叠坑），每杀一只小怪坑边溅起一圈碎骨。
- 镜头：每次震地 40ms 顿帧 + 垂直震屏 3 像素，连续震地只第一下推镜（FOV −3°）。
- 音效：闷重的地鼓 + 岩石崩裂 + 熊吼（只在第一下）。

**苍鹰 · 天空之王（`he_sky`）**
- 表现：标记增伤 +10%，鹰形普攻打中标记目标回兽魂。被标记目标头顶的鹰魂由 1 只变 2 只并压低盘旋；回兽魂时一根羽毛从目标飘回猎手肩头。报告版（10 秒羽矢必暴并穿透）：猎手肩上落一只半实体苍鹰（`GhostMesh`，羽毛 70% 实体感），每发羽矢穿透时在目标身后拉出一条 3 米的破风真空线（屏幕空间扭曲 + 尘土被吸起），暴击时羽矢尾部爆出一小簇羽屑。
- 镜头：穿透暴击 100ms 顿帧，镜头沿弹道方向推 1 像素。
- 音效：鹰唳（开启时一次）+ 每发羽矢破风「咻——嗤」。

## 3. 系统特效（形态变身 · 兽魂 · 雷狼机制）

### 3.1 形态变身（F 轮换 / Z 狼 / X 熊 / V 鹰）

- **现状问题**：`hunter_runtime.ts:81` 换形只画一个 `A.ring`（几何圈 + 实心色盘，见 `src/web/effects.ts:69–73`）；`hunter_model.ts:158–167` 的形态外观是头顶 2.75 米处浮着一个兽头 + 脚下常驻一个发光圆环（`glow(AURA_COL)`，`hunter_model.ts:134、163`），角色本身完全不变；狼形颜色 `#c8d8f0`、雷狼无任何电。
- **新做法：兽魂附体，而不是头顶挂件**
  - ① 预兆（0–0.15 秒）：猎手身上的契纹（护手、腰链兽牙）亮起对应形态的微光；周围尘土向脚下吸 0.3 米。
  - ② 出手（0.08 秒）：对应兽魂从猎手身体里「撑出」——狼：灰狼兽魂从背后扑出半个身位再收回，披在肩背；熊：熊魂从地面立起罩住猎手上半身后沉下，肩背变宽一圈（兽魂外壳，`GhostMesh` 厚度 0.25 米）；鹰：鹰魂从胸口展翅冲上 3 米再俯冲落到肩上。主光源（形态色）闪 0.06 秒。
  - ③ 持续（形态期间）：狼 = 肩背半透明狼皮 + 毛尖静电（雷狼系才有电，否则只有冷雾）；熊 = 肩背厚重熊皮、脚步每步扬尘；鹰 = 肩上羽翼剪影、移动时身后飘羽屑。**去掉头顶浮头和脚下发光环。**
  - ④ 命中：无（换形技单独出，见第 4 节）。
  - ⑤ 余韵（3 秒）：换形点地面留下对应痕迹——狼爪印 / 熊掌坑 / 一圈被风压倒的草与羽毛。
- 材料：`GhostMesh`（灰青 #A9C3C6 + 形态毛色叠层）；不用 `glow()`、不用加色。
- 镜头 / 音效：轻推镜 FOV −2°（0.2 秒回弹）；狼嚎短音 / 熊鼻息闷吼 / 鹰唳，各 0.4 秒。
- 实现：`hunter_model.ts` 的 `formAura` 改为挂 `GhostMesh` 兽皮外壳（骨骼跟随 Spine2 / 肩），粒子上限 高 60 / 中 36 / 低 18；低画质兽皮外壳改为静态半透明网格、不做毛流噪声。

### 3.2 兽魂（资源，满 40 强化「兽魂·」；换形 ≥25 自动变「灵契·」）

- **现状问题**：`hunter_data.ts:143–150` 只在 HUD 弧条显示（`show: 'arc'`，`#c8843a`），施放「兽魂·」强化技能和「灵契·」换形技时**画面上没有任何区别**（`hunter_runtime.ts:96–103` 只改名和倍率）。
- **新做法**
  - 积累（0–39）：契刃刃背契纹从刀根往刀尖逐段点亮（青铜刻痕微光 #9ED9C4，4 段）；无粒子。
  - 就绪（≥40）：刃身契纹全亮，猎手呼出的气变成灰青魂雾（每 1.2 秒一口，普通混合）；技能图标外框青铜色加深一档。
  - 「兽魂·」强化出手：对应技能的兽魂体型 ×1.25，兽魂眼睛出现两点冷白（唯一允许的点光，亮度 ≤ 1.3），命中层多一层「兽魂撕扯」——灰青雾从命中点向外撕开成 3 条爪痕状雾带，0.4 秒散去。
  - 「灵契·」换形技：换形技兽魂变为**半实体**（菲涅尔边缘加粗、内部透明度 0.55），落地时地面印出完整兽足 / 熊掌 / 羽翼印贴花，8 秒淡出。
- 音效：就绪时一声低沉兽鸣（不重复播放，掉到 40 以下再回来才再响）；强化出手叠一层兽吼。
- 实现：`hunter_fx.ts` 读 `s.displayName` 前缀「兽魂·」/「灵契·」或 `appliedModifiers` 含 `res:beast` / `form:shift_emp` 决定强化层；不改数值。

## 5. 技能分节

> 每节统一格式。「形态差异」写同一技能在狼 / 熊 / 鹰下的不同画法（形态修饰见 `hunter_runtime.ts:28–47` `formMods`）。雷狼系的「+雷电」层只在点了雷狼关键节点后出现。粒子上限写作「高 / 中 / 低」。

### 契刃斩（hp_slash）· 普攻 · 物理（雷狼：+雷电） · 瞬发

- **定位**：普攻，21 伤害 / 0.8 秒，2.6 米单体。狼：附流血、每第 3 下撕咬 ×2；熊：重掌 +25%；鹰：变远程羽矢 16 米。数值不改。
- **现状问题**：`hunter_fx.ts:64` 三道爪痕是 `ghostMat` 加色发光面片（`fx_kit.ts:13、67–76`，亮度 ×1.6，进泛光）；`hunter_fx.ts:65` 每下 10 颗白色火花；狼第 3 下「撕咬」只在 `hunter_runtime.ts:135–137` 改名改倍率，画面与普通一刀相同；鹰形羽矢是发光羽刃（`fx_kit.ts:60–65`）。
- **分镜**
  - ① 预兆（0–0.06 秒）：契刃刃口契纹一闪（刻痕内，非整刃）；脚下扬起少量尘。
  - ② 出手（0.06 秒）：长柄弯刃划出一道**空气扭曲刀风**（`WindVortex` 单弧，淡灰拖尾 #8A8F96，宽 0.25 米），刀风末端带出 3 道兽爪残影（灰青雾状，不发光）。
  - ③ 飞行 / 持续：近战无；鹰形见形态差异。
  - ④ 命中（0.12 秒）：按材质 `HitLayer`（血肉 → 血雾 + 小血滴；骨 → 骨屑；金属 → 火星 #FFC56B；石 → 碎石）；目标表面留三道爪痕贴花（深色划痕，非发光）。
  - ⑤ 余韵（4 秒）：地面零星血滴 / 碎屑贴花淡出。
- **形态差异**
  - 狼：刀风后紧跟一只狼爪兽魂横扫；**第 3 下撕咬**——狼头兽魂（0.9 倍）从刃上探出咬住目标，甩头一下，喷出一团血雾（`VolSmoke` 普通混合 #A3262B）+ 地面血迹贴花；雷狼：爪痕边缘爬 1–2 条 0.08 秒分叉电弧，撕咬时电弧从狼齿钻进目标。
  - 熊：刀风变厚重（尘土拖尾 #8B6F4E），熊掌兽魂叠在刃上一同砸下；命中处尘土环 + 3–5 块碎石。
  - 鹰：拉弓动作；羽矢是**实体**——铁箭头 + 青铜箭杆 + 苍羽尾羽（`Projectile3D`），尾迹是 0.15 秒的空气扭曲线 + 偶尔掉落的羽屑；命中时羽矢钉在目标上 0.5 秒后消失。
- **材料与色板**：刀风 #8A8F96（普通混合，透明 0.35）；兽爪残影 #A9C3C6；血 #6E0F12 / #A3262B；雷 #7B6CFF / #6FD3FF / 白芯 #F4F1FF（只给电弧芯）；熊尘 #8B6F4E；鹰羽 #B9BDB8 / #6B5A48。
- **多元素变体**（形态不变，仍是一刀 / 一箭）
  - 双元素（物理 + 火，装备附火）：刀风后缘拖一条细火舌（`FlameSeq` 小号，占 20%），爪痕贴花边缘是焦黑；命中多一层火星 + 余烬。鹰形：羽矢箭头烧红，尾迹带黑烟。
  - 三元素（物理 + 雷 + 冰，雷狼 + 冰附加）：爪痕三层——主体灰色刀风（60%）、电青分叉电弧（20%）、霜白结晶边（20%）；命中时雷向周围 1 个目标跳弧，冰在爪痕里结出霜纹，二者交汇处「冰晶导电」小电弧乱窜 0.3 秒。

- **音效**：刀风「呼」+ 材质命中层；狼形加爪撕「嚓」，撕咬加低吼 + 湿润撕裂；雷狼加 0.1 秒噼啪；熊形闷重掌击；鹰形弓弦 + 破风「咻」。每类 3 变体，音高 ±5%。
- **实现要点**：`WindVortex`（单弧）+ `GhostMesh`（爪 / 狼头）+ `HitLayer`；鹰形 `Projectile3D`。撕咬判定读 `S.basicN % K.bite`（`hunter_runtime.ts`，经 `onHits` 改名「狼·撕咬」）——在 `hunter_fx.ts` 按 `displayName === '狼·撕咬'` 出狼头。粒子上限 40 / 24 / 12；低画质关刀风扭曲，改淡灰面片拖尾。替换 `fx_kit.ts` 的 `clawMarks` 为贴花版。
- **新图标**：深色岩石底 + 青铜八角框，灰色槽位边；主体：一柄长柄弯刃斜劈，刃后三道灰青爪痕雾，刃口一道细铜刻痕。右下按元素加角标（雷狼时一个蓝紫点）。

## 6. 实现总则（猎手专属）

1. **只改 DLC**：表现全部在 `src/dlc/dlc1/hunter_fx.ts`、`fx_kit.ts`、`hunter_model.ts`、`hunter_sfx.ts`；释放方式字段写在 `hunter_skills.ts` / `hunter_data.ts` 的技能定义里。总纲组件（`ArcBolt / StormCell / GroundFx / VolSmoke / FlameSeq / IceForm / WindVortex / GhostMesh / RuneDecal / Projectile3D / HitLayer / CineCam`）若本体尚未落地，先在 `fx_kit.ts` 内做同名、同参数的轻量版，本体落地后直接换实现。
2. **材质**：`fx_kit.ts:13` 的 `ghostMat`（加色、`toneMapped:false`、亮度 ×1.4–3）只允许用在电弧芯和刻痕；兽魂一律 `GhostMesh`（普通混合 + 菲涅尔，`toneMapped:true`），替换 `spiritMat`（`fx_kit.ts:18`）里的 `glow()`。
3. **删掉**：`F.ring`（几何圈 + 实心色盘）、`F.sigil`（加色六芒法阵）、`'star'` 白色闪光、本体 `F.whirl` 加色彩带；可读性用「地面材质边缘 + 音效 + 小地图标记」，必要时留 15% 不透明度细边。
4. **多元素**：`hunter_fx.ts:19` 的 `formOf()` 只看形态标签，**完全不读 `s.elements`**（`src/core/types.ts:122`）——要按总纲第 4 节：形态归技能、颜色归元素；主元素占 60%，附加元素各 20–25%。
5. **预算**：同屏粒子 ≤ 3000（中 1500，低 600）；本体 `src/web/vfx.ts:241–247` 现为加色 2500 + 普通 1000（移动端 1200 + 450），猎手写实化后大部分粒子应走普通混合池，建议把两池比例调为加色 900 / 普通 2100（本体改动，需确认）。贴花 ≤ 36；动态点光 ≤ 6（猎手只给落雷、兽魂眼睛用）。
6. **低画质**：关屏幕空间扭曲、软粒子深度淡出、毛流噪声；`GhostMesh` 改无菲涅尔的半透明网格；电弧只画主干。
