# 怪物 · 动作与绑骨 · 现状排查与修复方案（v1，2026-10-30）

> 起因：用户 10-30 23:35 反馈——比赛版 Lux3D 写实怪物「模型滑过来跳数字」。总纲第 1 节已列为必须杜绝的错误。
> 本文件只做排查与方案，**不改代码**。所有结论都标了代码位置（以仓库当前 master 工作区为准）。
> 依赖关系：《精英与稀有》《野外BOSS》《副本BOSS》《长副本》四份文件里的「预备 / 出手 / 收招 / 受击 / 死亡」动作都建立在本方案的体型模板上。

---

## 0. 一页结论

1. **比赛版几乎所有怪都是无骨骼静态网格。** `assets_aholo/creatures/*.glb`（83 个）+ `assets_aholo/dlc1/creatures/*.glb`（17 个）共 **100 个 Lux3D 模型**，逐个解析 GLB 头：`skins = 0`、`animations = 0`、单节点单网格、约 4000–10000 顶点（脚本见第 5 节）。本体按显示名覆盖（`enemy_types.ts LUX_MOBS` 108 个名字 → 83 个模型），副本 / 深渊 / 世界首领走同一个 `wildModel → luxMob`（`raid.ts:626`、`packboss.ts:19`），资料片走 `lux_dlc.ts luxOr` 与 `dlc1/models.ts lux()`。
2. **移动 = 整体平移。** `main.ts:1694–1697`（位移在 1697 行）每帧 `e.pos += moveDir * speed * dt`；Lux 模型 `tick()` 里只有 `body.position.y = sin(t*0.5) * bob * h`（本体 `bob 0.01` = 2 米的怪上下 2 厘米），顶点着色器的「身体波浪」`wave` 本体全部是 **0**（`enemy_types.ts:148`），资料片 0–0.04（对人形是左右扭的蛇形摆，反而怪）。转身 `main.ts:1715–1719` 是整体 yaw 以 8 rad/s 转。没有步伐、没有起伏、没有转身动作。
3. **攻击 = 整体前倾，而且和扣血同一帧。** `EnemyBrain.ts:99–104` 冷却到了就 `doAttack` → `enemies.ts:124 enemyStrike` 第一行 `attackAnim = 0.35`（125 行） 同一个调用里 `dealDamage`（`enemies.ts:139`）；`main.ts:1736–1737` 把 `body.rotation.x = sin((1 - t/0.4)·π) · 0.5` ——**前倾的起点就是扣血时刻，没有预备、没有后摆**，所以玩家看到的是「数字先跳、模型再点头」。首领同理：`worldboss.ts:106–110`、`enemies.ts:227–231` 的 `BossBrain` 回调里同帧 `attackAnim = 0.4` + `dealDamage`；`groundSlam` 有 1.2–2.2 秒红圈预警，但首领本体在预警期**没有任何动作**。
4. **受击 = 整体后仰 0.22 弧度**（`main.ts:1739–1742`），**死亡 = 整体绕 z 侧翻 90° + 1.2 秒后溶解下沉 + 紫色灵魂粒子**（`main.ts:1677–1685`）。巨鲸死亡就是一条 7.5 米的鲸原地侧翻。
5. **远程怪**：`enemies.ts:126–134` 出手即发射 `makeOrb` 发光球（违反总纲「不用光球」），无拉弓 / 抬手。
6. 仍有骨骼动画的只剩 KayKit 角色（`chars.ts`，CC0 骨骼 + `walk/run/attack1/heavy/hit/death` 片段）：比赛版里只覆盖到暗岩矿洞首领格罗克、腐根祭司、钟楼两位「回响」首领（名字没接上 Lux）、宝藏怪。它们的问题只剩「攻击片段和扣血同帧」。
7. **修复**：浏览器端**程序化蒙皮**（按包围盒 + 顶点分区自动生成简易骨架和权重，结果缓存），按 5 个体型模板（H 人形 / Q 四足 / C 甲壳多足 / F 漂浮幽魂 / G 巨型鲸）+ 2 个补充（S 静物、W 蛇形）出步行循环、攻击三段、受击、死亡；动画器实现和 `CharAnim` 一样的 `loop / play / update` 接口，`main.ts / enemies.ts` 现有调用（`e.rig.anim?.loop('walk')`、`play('attack1')`、`play('death')`）直接生效。攻击改为「**预测式预备**」：动作提前播，扣血时刻不变（第 2.6 节）。低画质 / 自动绑骨失败时走顶点着色器分区变形兜底。
8. **先修评委路线**：倒钟广场 → 镜湖西岸巨鲸战，P0 共 8 个模型（第 4 节）。

## 2. ② 修复方案

### 2.1 总体路线

```
GLB 解析（已有）→ 转浮点 → 归一化（脚底 y=0、头朝 +Z，已有 + yaw 表）
   → 模板选择（LUX 表新增 rig 字段，缺省按包围盒推断）
   → 地标提取（截面宽度剖面 + 近地顶点聚类）
   → 生成骨架（THREE.Bone 树，≤ 24 根）
   → 计算权重（骨段距离 + 分区约束 + 平滑，每顶点 4 权重）
   → SkinnedMesh + partId 属性（碎裂死亡复用）
   → 结果缓存（按模型 id，IndexedDB + 内存；版本号随算法变）
   → ProcAnim（与 CharAnim 同接口：loop / play / update / revive）
```

- **为什么不离线绑骨**：100 个模型 + 长副本新增 10+ 个首领，离线绑骨（Mixamo / Blender）每个至少 20–40 分钟且要重新导出、改资产流水线；Lux3D 后续还会出新模型（铸造台的武器已经是运行时进来的）。浏览器端自动绑骨：7000 顶点 × 20 骨，单模型计算 < 15 ms（Web Worker），首次加载后缓存。
- **质量取舍**：自动权重会在腋下、胯部有拉伸；用「分区约束」（手臂区顶点不受腿骨影响等）+ 动作幅度控制（肩部 ≤ 70°）把问题藏住。这是 ARPG 俯视 45° 镜头下的「看起来在走、在挥、在倒」，不追求近景特写质量；首领近景（处决、阶段转换）多用身体大动作与镜头遮挡。
- **兜底**：低画质或某模型自动绑骨失败（地标检测置信度低）→ 顶点着色器分区变形（第 2.7 节），不会退回「整体平移」。

### 2.2 地标提取（通用算法）

1. **截面剖面**：沿 y 轴把顶点分 48 层，每层算 xz 宽度（P10–P90 分位，去掉武器 / 飘带离群点）与质心。
2. **近地聚类**：取 y < 0.3h 的顶点，在 xz 平面做 DBSCAN（eps = 0.06h）：簇数 = 着地肢体数（人形 2、四足 4、多足 6–8、长袍 / 漂浮 / 鲸 0–1）。**簇数与模板不符** → 置信度低 → 走兜底并在控制台列出，供人眼复核。
3. **头尾**：H / F 头 = 最高层质心；Q / C / G 头 = 沿 +Z（归一化后）最前端 15% 的质心；尾 = 最后端。
4. **关节高度**：
   - H：胯 = 剖面「两腿合并点」（近地两簇在向上扫描中合并成一簇的高度）；胸 = 胯上方宽度最大层；颈 = 胸上方宽度最小层；肩 = 胸层的 x 极值点；手 = 胸层以下、离躯干质心最远的两团顶点（DBSCAN）。
   - Q：肩 / 髋 = 前 / 后两对腿簇向上扫描与躯干合并的高度；脊柱 = 髋到肩的质心折线；颈 = 肩前方剖面收窄处。
   - C：躯干 = 最大连通团；腿 = 近地簇，每簇向上找到与躯干相连的根；钳 / 尾针 = 躯干最前 / 最后、高于躯干的离群团。
   - F：无腿；躯干 = 最高 40% 的质心链；袍摆 = 最低 30%。
   - G·鲸：沿 Z 的质心链分 6 段；下颌 = 最前段 y 较低的那半；鳍 = 中段 x 极值离群团；尾鳍 = 最后段宽度突增处。

### 2.3 权重

- 每根骨视为一条线段（父 → 子），顶点权重 = `exp(−d² / (2σ²))`，σ = 该骨段长度 × 0.35；取最大 4 个、归一化。
- **分区约束**：先按地标把顶点分区（`partId`：头、躯干、左臂、右臂、左腿、右腿、尾、翼…），每个区只能被本区骨 + 父骨影响；跨区接缝 6% 高度内做线性过渡。
- **平滑**：按网格邻接做 2 次拉普拉斯平滑（Lux 网格是三角网，有 index）。
- **武器 / 附件**：离躯干远、细长的离群团（剑、斧、锚、法杖）整团 100% 绑到最近的手骨——Lux 模型的武器是和身体一体生成的，这样武器会跟着手挥。

### 2.4 体型模板（骨架 + 动作）

所有时长以「标准体型」给出；**H·巨 / G** 一律 ×1.4–1.6（重量感），小体型（< 1.2 米）×0.8。攻击三段：**预备（明显后摆，0.3–0.6 秒；首领 = 预警 / 读条时长）→ 出手（0.08–0.15 秒，伤害帧）→ 收招（0.3–0.5 秒，可被打断回 idle）**。

| G 时长（给 H·巨） | 所有动作 ×1.5；落脚时地面 `quakeRing` 小号尘土 + 镜头微震（距离 < 12 米）；转身 ≤ 1.5 rad/s，转身时先转头、再转肩、最后转脚 |

#### 补充 S 静物 —— 6 个模型（图腾、冰柱囚笼、鼓风炉、熔渣罐）
不绑骨。顶点着色器：呼吸式缩放 1 ± 0.01、表面裂纹光脉动（已有 Voronoi 代码）；熔渣罐 `fd_bomber` 会移动 → **跳跃位移**（每 0.7 秒一次蹲 → 跳 → 落地挤压 0.9 / 拉伸 1.1）。死亡 = 碎裂。

#### 补充 W 蛇形 —— 萨卡尔、沙穴幼蠕、寄生鳗（长副本）
脊柱链 8–12 节，行波（已有的 `wave` 着色器改为骨骼行波），钻地 = 头部沿路径没入地面、后续节依次跟随（路径跟随，不是整体下沉）。

### 2.5 移动：杜绝原地平移

| 规则 | 做法 |
|---|---|
| 步伐与位移锁定 | 动画器每帧读取本帧实际位移 Δ，步行相位 += Δ / 步幅（而不是按时间）；位移为 0 时相位不前进 → 不会「原地踏步滑行」，也不会「不动腿平移」 |
| 起停 | 起步 0.25 秒加速（第一步先迈）、停步 0.3 秒减速（最后一步收脚）；速度曲线乘到 `it.speed` 上（只影响表现层位移，AI 目标点不变） |
| 起伏 | 每步髋 / 躯干上下（H 2.5%、Q 2%、G 1.5%），G 每步地面震 |
| 转身 | 最大角速度按模板（H 6、Q 4、C 5、F 5、G 1–1.5 rad/s）；角度差 > 60° 时原地转身播「踏步转身」（H 两步、Q 四步）；移动中转弯身体向内侧倾 5–8° |
| 推挤 | `main.ts` 末尾怪物互相推开的位移也要计入步行相位（被挤时会迈步，不会横着滑） |
| 断言 | 测试里：移动中的怪，脚骨（或拖尾链）世界坐标在一个步行周期内必须出现「着地静止」帧（速度 < 0.05 米/秒），否则判为滑步（第 3 节） |

### 2.6 攻击与伤害判定对齐（预测式预备）

**原则：不改伤害时刻和数值，把动作往前挪。**

| 对象 | 现状 | 改为 |
|---|---|---|
| 普通怪近战 | 冷却到 → 同帧扣血 + 前倾 | `EnemyBrain` 增加「预备」窗口：`attackCd ≤ windup` 时发出 `intent.windup = true`（只是通知），表现层开始播「预备」；`attackCd = 0` 时仍按原逻辑扣血，扣血帧 = 动作「出手」帧。**唯一的时序变化**：进入攻击范围后的第一次攻击，从「立刻」改为「延后 windup 秒」（0.3–0.6 秒），这本身就是读条可躲的预兆，要求在数值 sim 里复跑一次 `npm run feel / sim` 看 DPS 影响（预计普通怪 DPS 首轮略降，可通过首击 windup 只取 0.3 秒压低影响） |
| 远程怪 | 出手即发光球 | 预备 0.4 秒拉弓 / 蓄能 → 出手帧发射 `Projectile3D`（实体箭 / 毒囊 / 冰锥），飞行时间与命中结算不变 |
| 首领 `groundSlam` | 预警期首领不动；结算时同帧前倾 | 预警期 = 首领「预备」动作（时长 = `telegraph`，分「后摆 70% + 停顿 30%」两段），结算帧 = 「出手」帧 |
| 首领 `cast` | 读条期只有聚能法阵 | 读条期 = 读条姿态循环；成功 = 出手；打断 = 受击后仰 0.4 秒 + 收招 |
| 首领普攻 | 同普通怪 | 同普通怪，预备 0.5–0.7 秒（G 时长） |
| KayKit 片段 | `attack1 / heavy` 片段从头播，片段里的出手帧在 30–45% 处 | 同样提前：`play()` 时把片段的出手帧对齐到扣血时刻（`time = clip.duration × hitFrac − windup`） |

可读性要求：**所有攻击在扣血前至少 0.3 秒有可见后摆**；首领 ≥ 0.6 秒；控制技能 ≥ 1.0 秒（报告公平规则）。

### 2.7 兜底：顶点着色器分区变形

- 用 2.2 节同样的分区结果写 `partId`（顶点属性，uint8），每个分区一个枢轴点 + 旋转（uniform 数组，≤ 12 个分区）。
- 着色器：`transformed = pivot[p] + rotate(q[p], position − pivot[p])`，接缝用 `partBlend` 属性在相邻两区之间插值（6% 高度过渡带）。
- 动作数据与骨骼方案**共用同一份**（分区 ≈ 粗骨骼），只是关节数少：H = 头 / 躯干 / 左右臂 / 左右腿 6 区；Q = 头 / 躯干 / 4 腿 / 尾 7 区；鲸 = 6 段脊柱。
- 用于：低画质；自动绑骨置信度低的模型；同屏 > 30 只怪时的远处 LOD（> 25 米）。
