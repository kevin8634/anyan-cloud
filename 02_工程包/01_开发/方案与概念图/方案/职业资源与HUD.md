# 职业资源与 HUD 方案（待 Rhett 确认，v0.7.4-br.A 起草）

## 目标
每个职业有一种「看得见、攒得起、花得爽」的资源，并且资源和技能组合互相增强；资源显示从左上角头像下面挪到视线中心附近。

## 四个职业的资源
| 职业 | 现在 | 方案 | 怎么攒 | 怎么花 / 增强 |
|---|---|---|---|---|
| 战士 | 无（只有冷却） | **怒气 0–100** | 挨打、普攻命中、冲锋命中 +10 | 满 50 时下一个技能变「强化版」（旋风斩 +1 圈、雷霆一击眩晕翻倍）；100 时可开大招不读冷却 |
| 法师 | 无 | **奥能充能 0–4 层** | 每放一个不同元素的技能 +1 层（火→冰→奥术） | 4 层时下一个技能双发 / 范围 +50%，放完清空 —— 鼓励轮换元素 |
| 时砂行者 | 时砂 6 格 + 时痕 | **时砂（保留）+ 连击点 0–5（新）** | 时轮命中同一目标连续不断 +1 点，断档 3 秒清零 | 位移 / 控制技能按连击点增强：沙影步每点 +10% 伤害，停滞之刻每点 +0.3 秒；5 点时终刻冷却 -30% |
| 炼金投弹手 | 三色试剂各 3 格 | **试剂（保留）+ 反应热度 0–100（新）** | 每次地面反应（爆燃 / 蒸汽 / 晶毒）+20 | 热度满时下一瓶混合药剂变「沸腾版」（伤害 ×1.5、范围 +30%），大釜开场直接满热度 |

原则：每个职业只加 1 种新资源，旧资源不删；资源只增强已有技能，不加新按钮。

## HUD 位置
- **角色头顶**（主显示）：连击点 / 奥能层数这种「离散的点」画在角色头顶上方，3D 空间里的小光点，跟着角色走；战斗中显示，脱战 3 秒淡出。
- **准星下方弧形条**（桌面）：怒气 / 热度这种「连续条」画成屏幕中下方、角色脚边的一段弧形，不挡视线。
- **手机**：同样头顶显示；弧形条改成技能大招键外圈的环。
- 左上角头像下面的条保留成小号「备份显示」，设置里可以关。
- 满层 / 满条时：角色身上发光 + 一声提示音，强化版技能图标外框变金色。

## 实现计划（建议 v0.7.5-br.A 或交给 B 在觉醒版本统一做）
1. core/Resource.ts：通用资源（离散点 / 连续条、衰减、上限、事件）—— 4 个职业共用

4. 天赋 / 符文 / 橙装可以读资源（例如「连击点满时暴击 +20%」）
5. 测试：playtest res（4 职业各攒满一次、头顶点数正确、手机环位置）
