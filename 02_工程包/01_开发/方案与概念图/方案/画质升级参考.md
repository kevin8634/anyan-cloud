# 画质升级参考（备选方案，非任务）

> 记录于 2026-10-25。**只有当用户觉得观感不好、并明确说开工时才实施。** 现在不改代码。

## 结论：继续用 Three.js
不换 Babylon.js / PlayCanvas，理由：
- 画风是 Q 版 / toon + 描边 + 固定斜俯视 2.5D，换引擎收益小；
- 现有约 5.1 万行 TS、62 个文件依赖 three，迁移估计 3–5 周，会打乱 Aholo 黑客松（11-18 提交）；
- Lux3D → 减面 → refineChar → three.js 本身就是开源流水线卖点。
- 赛后如需写实大地图、复杂物理或编辑器协作，再评估 Babylon.js。

## 更划算的升级手段（Three.js 内）
1. **后处理**：引入 pmndrs `postprocessing`，加 SSAO、Bloom 和更好的描边。
2. **资产**：Lux3D 出的模型统一走 Draco / Meshopt 压缩 + KTX2 贴图，性能和清晰度一起提升。
3. **灯光**：场景用烘焙光照贴图，实时光只留给角色和技能。
4. **性能**：敌人和场景物件用 InstancedMesh，再加 LOD。
5. **以后可选**：试 Three.js 的 WebGPURenderer，不换引擎就能拿到新渲染管线。
