# 2. 技能特效写实化：少发光，多「物质」

**问题根源**：现在 `gfx.ts` 用全屏 UnrealBloom（强度 0.65–0.9、阈值 1.05），加上大量加色（additive）粒子，所有技能都会「发白发亮」。写实化的关键不是加更多特效，而是**换材料**：用烟、尘、水、冰、血这些「有体积、会挡光」的东西，取代纯光。

## 2.1 原则

1. **亮度预算**：技能特效最亮处不超过场景最亮点的 1.5 倍；只有「本身是光源」的东西（火焰芯、雷电、符文刻痕）能进泛光层。
2. **选择性泛光**：全屏泛光改为只对发光层生效（画质阶段一起做），武器和技能不再整体发白。
3. **半透明优先**：烟、尘、毒气、血用普通混合（会变暗、会遮挡），加色只留给火芯和电弧。
4. **每个特效都要留下痕迹**：焦痕、冰面、血迹、湿地、碎石贴花持续 4–8 秒再淡出，场景才像真的被打过。
5. **地面不画几何圈**：范围用材质表达（冰面蔓延、裂缝、毒雾边缘），可读性靠「边缘纹理 + 音效 + 小地图标记」。

# 3. BOSS 地板技能的写实渲染

把 BOSS 的「红圈预警」换成**场景本身在变化**：预警期间地面先出现裂纹、结霜、冒烟，伤害瞬间才真正爆开；同时保留一层很淡的边缘提示 + 音效 + 震动，保证可读。

| 地板 | 预警（1.2–1.8 秒） | 生效 | 残留 |
|---|---|---|---|
| 熔岩龟裂 | 从落点向外蔓延的分叉裂缝，缝里先暗红后变橙，冒烟 | 岩板翘起、熔岩喷出，站在缝上吃火伤 + 燃烧 | 冷却成黑色裂纹地面 6 秒，仍有余热（轻微 DoT） |
| 冰裂湖面 | 白色蛛网裂纹扩散，冰下黑水变清晰 | 冰面碎开，掉下去 = 冻结 2 秒 + 冰伤 | 浮冰块 + 黑水洞 8 秒（不可站） |
| 冰封囚笼 | 目标脚下结霜、身上长冰晶（4 秒倒计时） | 被冻进一整块冰（见下） | 碎冰块散落 |
| 毒雾 | 地缝渗出黄绿雾，先贴地流动 | 雾里每秒中毒叠层，视野变暗 | 腐蚀地面贴花 |
| 血潮 | 地面渗出暗红水洼并上涨 | 站在血水里受到治疗 -50%、流血加深 | 湿漉漉的血迹 |
| 火海 | 书页 / 木地板先冒烟、焦黑 | 火焰沿可燃物蔓延（不是圆形扩散） | 焦黑地板 + 余烬 |

**冰块冻结规则**（单人可解）：被冻住 4 秒；期间连按移动键或翻滚键，每次 -0.4 秒；周围的 AOE（包括 BOSS 自己的冰刺）打到冰块会提前击碎；冰块碎裂时对周围 4 米造成冰伤——所以冻住前要走离小怪 / 柱子，也可以故意站到冰刺路线上被打碎。

# 4. 打击感

现状：`HitFeel` 只有震屏和顿帧（开关式）。升级为一整套分级反馈：

| 层 | 做法 |
|---|---|
| 顿帧分级 | 轻击 40ms / 重击 80ms / 暴击 100ms / 大招最后一击 140ms；多目标只顿一次 |
| 受击反馈 | 受击闪白 0.06 秒；小怪受击后仰 / 硬直动画；击退 0.3–1.2 米（精英减半、首领只抖动不位移） |
| 镜头 | 震屏带方向（沿攻击方向推）；大招轻微推拉镜头；击杀精英时 0.1 秒慢动作 |
| 按材质的命中特效 | 血肉 → 血雾 + 血迹；骨头 → 骨屑；金属 → 火星；石头 → 碎石；幽魂 → 灵雾散开 |
| 音效分层 | 挥砍风声 + 命中声 + 材质层 + 暴击低频；每类武器（剑 / 斧 / 锤 / 匕首 / 弓 / 法杖 / 铁棺）一套 |
| 武器轨迹 | 刀光改为空气扭曲 + 淡灰拖尾，重武器带尘土，去掉发光描边式拖尾 |
| 数字与提示 | 暴击数字放大跳动；打断成功显示「打断」；破甲 / 冻结显示状态字 |
| 击杀 | 小怪按类型：倒地、碎裂、化灰、散成灵雾；精英可「处决」（见第 15 节建议） |
| 手柄 | 支持手柄时加震动（Gamepad API），轻重分级 |

# 5. 技能释放方式合理化

## 5.1 五种释放方式（统一规则）

| 方式 | 规则 | 例子 |
|---|---|---|
| 瞬发 | 按下即生效，不打断移动 | 旋风斩、暴风雪（新）、冰霜新星 |

# 6. BOSS 状态与控制机制库（仅资料片）

## 6.1 持续掉血

| 状态 | 规则 | 解法 |
|---|---|---|
| 中毒 | 叠层（最多 8），每层每秒 0.6% 最大生命；到时间会传染身边 3 米 | 走出毒雾；解毒药剂；翻滚无敌帧不叠层 |
| 燃烧 | 不叠层但高伤（每秒 2%），持续 6 秒 | 踩进水 / 淬火池立刻熄灭（可能附带别的代价） |
| 流血 | 叠层（最多 5），**移动时每秒额外 +50% 伤害** | 站定 2 秒止血 -1 层；与「躲技能」形成取舍 |
| 冰蚀 | 移速 -10% 每层，叠 5 层冻结 | 离开冰面、靠近火源 |

## 6.2 控制

| 控制 | 时长 | 表现 | 解法 / 规则 |
|---|---|---|---|
| 恐惧 | 2.5–3 秒 | 角色不受控乱跑；幽魂围绕尖叫 | 站在「光源」（灯笼 / 篝火）里免疫；有预警读条可打断 |
| 冰冻（冰块） | 4 秒 | 冻进冰块 | 连按挣脱 / AOE 击碎（见第 3 节） |
| 眩晕 | 1–2 秒 | 头顶星星换成「耳鸣」画面抖动 | 可躲（有动作预兆） |
| 沉默 | 3 秒 | 技能栏变灰，只能普攻 / 翻滚 | 打断 BOSS 读条可避免 |
| 魅惑 / 吸引 | 2 秒 | 被强制走向 BOSS 的诱饵灯 | 翻滚可提前脱离 |
| 定身 | 2 秒 | 被锁链 / 冰霜钉住，可攻击 | 翻滚不能动，但可放技能 |

**公平规则**：玩家被硬控（恐惧 / 冰冻 / 眩晕 / 魅惑）单次 ≤ 4 秒；15 秒内同类控制递减（第二次减半、第三次免疫）；所有控制都有 ≥ 1 秒的视觉 + 音效预警；BUFF / DEBUFF 显示在现有 buffhud（玩家头像旁 + 首领血条下）。

## 6.3 锁血阶段转换

- 首领血量到阈值（如 70% / 35%）时**锁血**：再打也不掉，进入「不可破」并开始阶段转换。
- 转换期间要完成场景机制（坐升降梯下层 / 敲钟 / 关阀门 / 打碎真身），完成后进入下一阶段；超时读条团灭（沿用 DLC1 已定的「机制秒杀，不靠伤害秒杀」原则）。
- 场景跟着阶段变化：平台坍塌、重力翻转、水位上涨，让长副本「场景化」而不是换一套技能。

# 8. 写实音效

**现状**：`audio.ts` 的音效全部是 WebAudio 实时合成（约 50 个），听感偏电子；只有音乐和首领配音是真实音频。写实化 = 换成真实采样 + 空间化 + 环境声源。

## 8.1 原则

1. **采样优先，合成兜底**：所有现有接口（hit / swing / bossSlam…）先查采样库，没加载到才用合成，调用处不用改。
2. **分层**：一次命中 = 挥动风声 + 命中 + 材质层（+ 暴击低频），每类 2–3 个变体轮换、音高随机 ±5%，不会听腻。
3. **空间化**：环境声源和怪物音效走 3D 定位（HRTF），按距离衰减；同类声源最多同时 4 个。
4. **空间混响**：按区域切混响（洞穴、大厅、户外、水下），钟井和倒塔各一套。
5. **和画面同步**：写实特效出现的地方必有声音——火有噼啪、冰有开裂、毒雾有嘶嘶、幽魂有低语。

# 9. 剧情设定：第十章「余响」

**承接**：第九章玩家在岔路口选了「再鸣」或「断绳」，并在沉眠者地窖结束了它。

**设定**：沉眠者不是一个整体。千年前鸣钟人封印它时，把它拆成了「潮」与「影」——潮是它的身体与饥饿，影是它的梦与意志。沉眠者倒下后，这两半各自逃走了：

- **潮**沉进了**潮渊钟井**：鸣钟人铸下第一口钟的地方，一口竖井一直通到地底之海的底部。它在井底长成了巨大的深潮之喉「莫尔维斯」，井里的守钟人、渡者全成了它的回响。
- **影**爬上了**镜渊倒塔**：倒挂在穹顶的初代城主宫殿。第一任城主「艾瑟隆」当年和沉眠者立约，换来了镜渊城的千年繁华；如今影回到他身上，他成了「倒影之王」。

**两条线怎么走同一段剧情**：副本相同，只是引路人与奖励不同——

| | A「再鸣」守钟人 | B「断绳」渊噬者 |
|---|---|---|
| 引路人 | 伊奥拉（已成为新的钟声） | 卡戎 |
| 目的 | 安抚潮与影，让沉眠者真正长眠 | 吞下潮与影，补完渊噬之躯 |
| 尾王掉落的回响 | 安魂后成为领地居民（莫尔维斯之回响 → 潮汐码头守望者；艾瑟隆之回响 → 档案馆） | 变异部位（深潮之喉 → 「心」；倒影之冠 → 「影」） |
| 终章台词 | 钟声第一次传到井底 | 潮水第一次听从你的号令 |

**终章钩子（引 DLC2）**：艾瑟隆消散前说出真相——「钟不止一口」。墨言笔记最后一页：远方，另一口钟自己响了。

# 14. 剧情动画与插画

## 14.1 两种做法

| | 插画式动画（OpenFilm） | 重要过场（AI 视频，用 Credits 额度） |
|---|---|---|

## 14.4 制作流程

1. **分镜**：我写每部片的分镜表（镜头、时长、台词、音乐点）。
2. **角色设定图**：伊奥拉、卡戎、墨言、六职业主角各一张多角度设定图，作为所有插画和视频的参考图，保证人物前后一致。
3. **关键帧**：gpt-image-2 / Seedream 带参考图出关键帧（插画式和写实电影式两种画风分开）。
4. **视频**：先用同一个镜头试 3 个模型（Seedance 2.0、Veo 3.1、Sora 2），比较画面和单价后定主力模型；之后图生视频，每镜头 5–8 秒，首尾帧控制衔接。
5. **剪辑**：OpenFilm 拼镜头、加字幕、配音（沿用现有配音管线）、音乐，渲染 MP4。
6. **进游戏**：新增过场播放器（可跳过、字幕、背景音乐自动压低）；在线版 720p 流式播放；离线 DLC 版附带压缩版（插画片约 0.6 Mbps，30 秒约 2 MB）。
