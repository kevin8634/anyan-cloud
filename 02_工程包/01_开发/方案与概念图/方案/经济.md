# 暗岩传说 · 金币经济（v0.5 C）

v0.5 C 取消了装备出售（以前一件 30 级紫装能卖 1000 金，是最大的收入来源）。现在金币来自四个地方：**怪物掉的金币、灰色杂物（进商人自动卖）、分解顺带的零钱、任务奖励**。支出是**药水、修理、强化、重铸、兑换里的金币部分**。

表格由 `npm run economy` 用真实掉落表（`data/loot.ts`、`data/zones_wild.ts`）、任务奖励（`data/quests.ts`）、强化表（`data/shop.ts`）模拟生成，每档 200 小时取平均；`npm run economy -- --write` 会把下面两张表重新写进本文件。

## 目标（`npm run economy` 会检查）

1. **药水 + 修理付得起**：≤ 每小时收入的 35%（实际 3~4%：修理是 v0.5 A 的公式，阵亡一次 16 / 32 / 48 金）。
2. **强化目标（主线 v0.6.6 改）**：部位强化换装不丢，一个部位 +10 ≈ 0.5 小时 30 级净收入（≤ 2 小时）；16 个部位全部 +10 ≈ 8 小时（6~30 小时），+15 约为 +10 的 4 倍。B 原来的「一件装备 +10 ≈ 2~4 小时」目标是给会掉级、换装就丢的强化定的，已不适用。
3. **分解只是零钱**：分解金币 ≤ 收入的 25%（实际约 17~18%）。
4. 净收入随等级上涨；+10 需要的魔尘 / 星辉碎片在 30 级野外 4 小时内能分解出来（虚空精华主要来自副本 Boss）。

## 本次调整（为了达到上面的目标）

| 项目 | 原来 | 现在 | 原因 |
|---|---|---|---|
| 装备出售 | 可卖，30 级紫装 ≈ 1000 金 | **取消**（`Inventory.sell` 只留给模拟 / 测试） | 方案 5.3 |
| 灰色杂物 | 没有 | 小怪 50% 掉 1~2 件：兽牙 2 / 布片 4 / 小饰物 9 / 残骸 14 金（按区域） | 卖装备的手感换成「进商人自动结账」 |
| 分解金币 | 没有 | `(1 + 0.35 × 装等) × 品质倍率`（白 0.5 / 绿 1 / 蓝 2 / 紫 4 / 橙 7） | 方案 5.5「分解顺带给少量金币」；初版 `2 + 0.5 × 装等` 占收入 26~27%，超过 25% 上限，下调 |
| 任务金币 | 原值 | 原野、腐沼神殿、三张新地图任务 **×1.5**（`QUEST_GOLD_MUL`），灰石营地 / 矿洞前期任务不变 | 取消出售后任务是唯一「保底」收入 |
| 强化掉级 | +9、+10 失败掉级 | **+8、+9、+10** 失败掉级 | 方案 5.3 强化保护符要有用武之地（+7..+10 区间） |（主线 v0.6.6 取消）
| 强化金币 +8 / +9 / +10 | 210 / 270 / 350 | **180 / 220 / 280** | +8 也会掉级后 30 级胸甲 +10 ≈ 3.8 小时，贴近上限；下调到 ≈ 3.3 小时 |（主线 v0.6.6 取消）

强化金币公式不变：`基础金币 × (1 + 0.08 × 装等) × (1 + 0.15 × 品质序号) × 部位倍率`（双手 1.4，戒指 / 项链 / 护腕 / 腰带 0.8，饰品 0.9）。
