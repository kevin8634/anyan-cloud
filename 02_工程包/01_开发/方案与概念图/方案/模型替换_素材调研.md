## 0. 结论先行

1. **人形角色统一用 Quaternius 新一代「Universal」体系**（CC0，免费，不用登录）：Universal Base Characters（平均约 13k 三角面，人形骨骼）+ Modular Character Outfits – Fantasy（12 套服装、62 个部件、每套 3 种配色）+ Universal Animation Library 1/2（120+ 和 130+ 个动作，含连招、死亡、僵尸步态，可以重定向到 Mixamo 骨骼）。比例写实，手绘风 PBR，接近魔兽那种感觉，**不是 Q 版**。4 个职业、DLC 职业、NPC、强盗、邪教徒、守卫都能用同一套骨骼和动作做出来，风格也统一。
2. **人形怪物**用同一作者的 **Bestiary – Dungeon Monsters Kit**（QAL 授权：可商用、不用署名、不能把素材单独转卖）：狼人、小恶魔、哥布林、骷髅、巨人/食人魔、恶魔骑士、黑甲骑士，共 7 种，每种 3 个配色，人形骨骼，可以直接套 UAL 动作。
3. **四足和特殊怪**（熊、蜘蛛、狼、巨魔、元素、龙、巫妖、牛头人、野猪、蝎子）从 **Sketchfab 的 CC-BY** 模型里挑。全部需要**登录免费 Sketchfab 账号**才能下载，每个都要署名。
4. **没有合适免费模型的**（巨蟾、树人/古树魔像、腐根首领、藤蔓、沙葬法老、骨猛犸、骨龙幼体、各种傀儡、负棺人的棺材、祭坛/传送阵）：用 **TRELLIS / TRELLIS.2** 从概念图生成，再减面、绑骨。
5. **不建议用的**：Fab 上 Epic 的 Paragon / Infinity Blade（限虚幻引擎）；Sketchfab 上标了 CC-BY 但其实是游戏拆包或二次上传的模型（上古卷轴 Blades、D&D Heroes、Dota、Mir4、Raid、Tarisland、Unity 商店的模型、Mixamo 角色的转传）；KayKit / Kenney / Quaternius 旧包（Ultimate Monsters、RPG Characters 等，都偏可爱）。

**生成模型怎么选：**
- **TRELLIS**（`microsoft/TRELLIS-image-large`）：MIT 授权，项目已经在用。部分子模块有自己的授权。
- **TRELLIS.2**（`microsoft/TRELLIS.2-4B`）：模型和代码是 MIT，但导出 GLB 那一步依赖的 nvdiffrast / nvdiffrec 用的是 NVIDIA 自己的授权（「非商业，仅限研究 / 评估」）。生成出来的资产商用有没有问题**目前没有定论**，正式发行前要确认。
- **Hunyuan3D-2.1**：腾讯社区许可证明确「**不适用于欧盟、英国、韩国**」。用户的大致位置在荷兰（这是推测，未确认），游戏如果面向欧盟发行，**不建议用**。

**流程**（和 `docs/plan/职业装备限定与怪物建模路线.md` 一致）：三视图概念图（A-pose、纯色背景）→ TRELLIS 生成 → gltf-transform + meshoptimizer 减面（小怪 4k 以内，首领 15k 以内）、贴图压到 512/1024 → 人形用 Mixamo 自动绑骨（要 Adobe 登录，中国区账号不行）或 Blender Rigify，再套 UAL 动作；非人形在代码里程序化建骨骼。

## 4. 建议替换顺序（观感提升最大的先做）

1. **4 个玩家职业**（一直在屏幕中央，提升最明显）：UBC + Outfits + UAL；炼金可以先用 Plague Doctor（CC-BY）。同时把 `chars.ts` 的 makeCharacter 改成支持新骨骼，gear.ts 的挂点从 KayKit 的 handslot 重新对应到新手骨。这一步打通之后，后面所有人形都能复用。
2. **人形首领和人形怪**（16 个首领 + 劫掠者 / 弓手 / 酋长 / 矿工 / 邪教徒）：Bestiary（巨人、恶魔骑士、黑甲骑士、骷髅）+ Outfits 暗色配色。代码只要改 makeBoss / makeCultist / makeRaider 等几个函数。
3. **高频野怪**：蜘蛛（顺便删掉 178 处几何体调用）、狼、野猪、傀儡，再加新的熊 / 巨魔 / 元素。来源是 Sketchfab CC-BY 加署名表。
4. **营地 NPC**（约 36 个）：和第 1 步同一套资源，只是换装和换色，成本很低。
5. **特殊首领**：龙（换成带骨骼的版本）、巫妖、牛头人，加上第 3 节 TRELLIS 那批（巨蟾、树人、法老、骨猛犸等）。
6. **道具**：宝箱、炼金锅、铁砧、熔炉用 Fantasy Props MEGAKIT；祭坛 / 传送阵用 TRELLIS 底座加程序特效。
7. **DLC 职业**（链甲猎人、负棺人）：等 DLC 开工时再做，资源已经覆盖到了。

**性能提醒**：设计文档要求同屏骨骼动画怪 ≤ 40。UBC 约 13k 三角面，40 个就是约 52 万面，小怪最好减到 5–8k 并做 LOD。Sketchfab 模型贴图大多是 2k，进游戏前统一压到 512/1024。

**署名**：所有 CC-BY 模型要在制作人员名单 / 关于页写清楚「模型名 by 作者 (链接)，CC-BY 4.0」。QAL 和 CC0 不要求署名，但建议一起列上。
