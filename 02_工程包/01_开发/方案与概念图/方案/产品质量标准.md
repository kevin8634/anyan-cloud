# 产品质量标准（2026-10-29 v1，每版交付前逐条核对）

## 1. 模型与贴图（硬性）
- 新增任何模型（场景件、天空、建筑、怪物、NPC、武器）必须带纹理/材质（PBR 或手绘贴图），**不允许纯色 / 无贴图件进版本**（10-27 Rhett 定）。
- 写实件一律不套卡通描边 / 轮廓 pass（武器、遗迹、岩体已去，紫描边视为缺陷）。
- 面数与贴图：场景件 ≤12000 面 + 1024 JPEG/WebP；人物 / 首领 ≤40000 面 + 2048 WebP；单件 GLB ≤1.5 MB（人物 ≤4 MB）。
- 接缝 / 法线：无黑条、无破面、无漂浮（贴地 ≤2 cm）；蒙皮件跑一遍待机 + 攻击无穿模。
- 低 / 中画质与商用基础包必须有回退（不加载比赛资产也能玩）。

## 2. 画面验收
- 每个改动区域固定机位前后对比截图（dev/*shots.mjs），**逐件检查贴图**，和概念图并排拼图。
- 禁止出现：大片纯黑地面、纯色圆盘 / 方块占位、青色碎线、过曝白团、紫色描边、悬空物体。
- 评委路线（标题 → 选角 → 倒钟广场 → 铸造 → 巨鲸 → 拍照）每个画面都要能截图当宣传图。

## 3. 功能与测试（每版必跑）
- tsc 三套、四套构建、check-purity、check-assets、寻路自检。
- smoke、audio_e2e、weapon_stow_e2e、forge_e2e、keyshot（假 Key，零积分）、judgeshot（三步 ALL PASS，0 页面错误）。
- 发评委包前：zip 解压后 file:// 复测（zipcheck）。

## 4. 安全与积分
- 评委包绝不内置 Rhett 的 Aholo Key；评委自填，只存本机 localStorage。
- 测试一律拦截 Lux3D 请求，零积分；真实生成只用于已列清单的项目。
- 内部成本文档不进评委包、开发日志、参赛报告。

## 5. 性能与体积
- 2060 6G 高画质 ≥45 帧（倒钟广场、巨鲸战）；超高档 ≥30 帧。
- 比赛版 DLC 单文件增长每版 ≤10 MB，超了说明原因；评委 zip ≤150 MB。
- 加载画面有进度，首屏 ≤10 秒（本机实机）。

## 6. 体验
- 评委 3 分钟能走完三步；任何失败都有中文原因提示，不出现「在线生成失败」这类生硬文案。
- UI 不遮挡战斗画面中心；新增文字中文、无错字。
- 音乐：标题曲、广场曲、战斗曲正常播放，音量归一（-16 LUFS）。

## 7. 交付
- 测试全过 → version.ts → 版本记录 → 交接 → commit + tag → 工程包 + 离线版 → 云盘 01/02/03/04/05 同步。
- 概念图、参考图、提示词当轮传云盘 04。
