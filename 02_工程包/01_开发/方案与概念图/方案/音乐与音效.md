# 音乐与音效模块（10-26 纳入开发计划）

现状：src/web/audio.ts 全部 WebAudio 代码合成（15 个主题 + 约 50 个音效），听感偏「电子合成」。
目标：比赛版换成真实采样，合成保留为回退（加载失败 / 商用版）。非商用，只用于比赛展示，素材出处登记 assets_aholo/AUDIO_SOURCES.md。

## 来源
- 音乐：Rhett 在 suno.com 生成 mp3 交给我（不接第三方 Suno API）。我负责剪无缝循环、响度统一（-16 LUFS）、ogg 80kbps 立体声。
- 音效：Kenney（CC0）+ Sonniss GDC 免版税包打底；招牌音用 ElevenLabs 文生音效；代码里叠层 + ±5% 随机音高 + 2–3 个变体轮换。
- 体积预算：音乐 ≤7 MB，音效 ≤3 MB（比赛版单文件目标 ≤30 MB 内）。

## 实现
- src/web/sfxbank.ts：按键名加载采样（比赛版内嵌 base64 / 单文件），未加载时回退 audio.ts 合成。
- audio.ts 现有方法（hit / swing / anvil / bossSlam…）内部先查 sfxbank，接口不变，调用处不用改。
- 环境床：按区域交叉淡入淡出，与音乐总线分开调音量。
- 设置面板：音乐 / 音效 / 环境三条音量。
- 测试：dev 下 ?audiotest 列出所有键一键试听。
