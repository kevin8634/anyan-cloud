# 副本地图 + 长副本路线 / 环境改版方案（2026-10-18，账号 B）
示意图：design/raid_route_plan.png（源文件 raid_route_plan.html）。版本 v0.6.10，接在 v0.6.9 大地图之后，复用地图面板组件。

## 1 长副本路线：枢纽 + 两翼 + 支线 + 捷径（不再一条线）
熔心王座：入口 → 1 戈拉克 → 余烬十字厅（枢纽/存档点）→ 西翼 焰灵回廊（2 双生焰灵，焰之印）/ 东翼 熔岩河道（3 萨穆尔，鳞之印）任意顺序 → 封印之门（2 印，或 1 印 + 支线精英「门卫」）→ 4 卡萨 → 二选一 A 祭司阶梯（精英多、宝箱+1）/ B 熔瀑侧道（环境伤害高、省 1 分钟）→ 5 瓦尔卡兹。
- 先打的两翼首领死后，另一个获得「余怒」（+1 机制，+1 暗金碎片）。
- 捷径：萨穆尔死后河道熔岩冷却成黑曜石，河道尽头直通祭坛前。
- 隐藏：熔炉密室，三个阀门按壁画顺序拉开 → 密道直通封印之门 + 宝藏怪。
- 异变房间 / 遗物三选一放在岔路节点上。
- 节奏（装等 40 英雄）：全清 18–22 分钟；最快路线约 13 分钟；全支线约 26 分钟。
永霜墓穴：入口 → 1 莫戈斯 → 北道 冰柱长廊（2 维瑟拉）/ 南道 风雪峡谷（3 寒脊）→ 骑士团大厅（需点亮 4 盏魂灯，南北各 2）→ 4 骑士团 → 5 伊瑟兰。
- 维瑟拉死后冰湖冻结，可直穿回另一条路（路程减半）。北道打碎冰柱架桥；南道周期暴风雪压低视野。隐藏：冰封书库。

## 2 环境变化：4 种驱动
① 周期（熔岩潮汐 45 秒涨落、暴风雪、喷口节奏）；② 进度（首领死亡：熔岩冷却、湖面冻结、回廊熄灭、开门）；③ 玩家（阀门、火盆、打碎冰柱架桥）；④ 每周（每周畸变带环境主题：余烬风暴、深冻）。
规则：都有预警（地面变色 / 音效 / 地图倒计时）；首领战中只出现本场机制，不叠加跑图环境。

## 3 副本地图
副本内 M（手机 ≡ → 地图）：俯视轮廓 + 节点（首领 / 存档点 / 支线 / 异变 / 封门）、迷雾、已杀首领灰掉；激活过的存档点互传（战斗中不可用）；环境倒计时；路线建议 + 自动寻路（NavGrid / AutoPath，目标 = 下一个未完成节点）；侧栏：首领进度、用时 / 最佳、印记、遗物、誓约、壁画线索；入口预览（副本学者 / 传送阵，不含隐藏点）；三首领普通副本用简化版；小地图切为副本小地图。

## 4 实现
- data/raid_routes.ts：节点、连线、门条件（bossDead / sigils / lever / envState / elite）。
- web/raidenv.ts：环境控制器（周期 / 进度 / 玩家 / 每周），统一预警接口。
- web/raidmap.ts：副本地图面板、迷雾、存档点互传、入口预览。
- 存档：本趟路线状态放 RaidSave.run（可选字段），迷雾 / 本周已开捷径写入 RaidSave；不升版本号。
- 测试：npm run routes（所有路线可通关、门条件不卡死、捷径正确）；p610a 战士英雄熔心王座走两翼；p610b 法师史诗永霜墓穴走冰湖捷径；地图截图（桌面 + 手机）。
- 之后：深渊 20 层复用路线图（每层随机岔路）；副本音乐给环境变化配音效。
