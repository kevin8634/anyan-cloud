# 资料片地图地面 / 海底视觉升级方案（2026-10-26，Rhett 要求记录）

概念图：docs/黑客松素材/场景概念/floor_seabed_concept.png（零积分，图像生成）。

## 目标
沉钟海岸 / 镜渊城 / 无声钟楼的地面从「平铺贴图」升级为退潮后的湿地海床：湿黑玄武岩与碎石板、一层薄海水反光、发光潮池、焦散光纹、海草藤壶、半埋的铜钟碎片与锁链、贴地薄雾。

## 分档实现（只放 src/dlc/dlc1/ 与通用材质 src/web/）
| 项 | 低 | 中 | 高 / Ultra |
|---|---|---|---|
| 地面材质：玄武岩 + 沙 + 海草三层混合（顶点色 / 噪声遮罩） | 单层贴图 | 三层混合 | 三层 + 法线 + 粗糙度变化 |
| 湿地反光：积水遮罩处降低粗糙度、加环境反射 | 关 | 假反射（环境贴图） | 屏幕空间反射或平面反射（仅潮池） |
| 焦散光纹：两张滚动噪声相乘投到地面（着色器） | 关 | 开（半强度） | 开 + 随潮汐强弱 |
| 发光潮池：小圆面 + 菲涅尔 + 呼吸发光，接 Bloom | 静态色块 | 开 | 开 + 粒子微光 |
| 贴地薄雾：高度雾 + 2–3 层慢速滚动雾片 | 关 | 1 层 | 3 层 + 体积光束（地标处） |
| 散布物：贝壳 / 藤壶 / 铜钟碎片 / 锁链（实例化） | 少量 | 中量 | 满量 + 碎片复用场景 GLB 的小件 |
| 潮汐联动：涨潮时水面升起、焦散变强；退潮露出宝箱区湿痕 | 只改水位 | 开 | 开 + 浪沫线 |

## 约束
- 演示机 ≥50fps；新增着色器全部可按档位关闭；低档不比现在更慢。
- 不花 Lux3D 积分；散布小件优先从已生成场景 GLB 拆出或程序化。
- ACES / 雾改动后全场景回归截图（dev/sceneshots.mjs），真机 GPU 再看一次。
- 排期：魔搭上线联调之后，与「地标仰视镜头 + 光束」同一版（v1.2.47 左右）。

## 实现状态（2026-10-27，分支 seabed，未发版）
海底地图 = DLC 沉钟海岸 / 镜渊城 / 无声钟楼（本体没有海底区域）。本次只做镜渊城 · 倒钟广场（比赛 Demo 地图），全部代码在 src/dlc/dlc1/，本体零改动。
- `seabed.ts`（新）：水 / 沙 / 发光遮罩（512² canvas，CPU 留一份采样）；浅水面（高 / 超高 = three Reflector 平面反射 0.45 / 0.6 倍分辨率，倒影随底波 + 涟漪法线扭曲；中 / 低 = 夜空环境贴图）；月光高光、岸边浪沫；水滴（围着镜头视线落地点随机下落的水线 → 两圈环形涟漪 + 溅水花，16 滴环形缓冲，玩家蹚水也起涟漪）；发光水潭 / 符文坑 13 个；漂浮青色光点（GPU）；贴地薄雾 2 层；海草（程序化褶皱丝带叶片 instanced + 顶点摇摆，比赛版加 Lux3D 海草丛同一套摇摆）；半埋铜钟、断锁链（程序化链环 + Lux3D 锁链堆）、藤壶礁石、远处沉船（scene_shipwreck）。
- 地面：plaza_tex.ts `makeSlate` 深色湿板岩方砖（1 米一块，砖缝积水、裂缝、缺角、碎砖、层理）替换石板；`seabedFloorPatch` 给地面 shader 加水下焦散（可平铺迭代焦散两层叠加 + 大尺度斑驳，水下 / 发光坑旁更强）、积水遮罩（压暗 + 粗糙度 0.08）、沙地波纹（颜色 + 法线）、夜空环境反射。
- 去掉镜渊城地面霓虹裂纹（palette cracks: 0）；修正鹅卵石遮罩 canvas 纹理 flipY（之前 z 翻转）。
- 倒影里隐藏天空球（天顶亮蓝）和固定像素大小的星点，清屏换深色夜空。
- 档位：low 无反射 / 焦散 / 水滴 / 雾 / 光点，海草 26 丛；medium 环境反射 + 半强度焦散 + 水滴 + 1 层雾；high / ultra 全开。
- 截图：node dev/seashots.mjs <html> <目录> <前缀> ultra [编号,..]

## 第二轮（2026-10-27，分支 seabed）
对照概念图差距按优先级修，全部在 src/dlc/dlc1/（seabed.ts / plaza_tex.ts / plaza_dress.ts）与 dev/seashots.mjs：
- 地砖：板岩底色改深灰黑（反照率约 0.06–0.12，每块明暗差拉大），干砖面压掉方向光 / 环境高光（只湿处保留镜面），水下再压暗。
- 焦散：换成两层域扭曲 Voronoi（F2−F1）细亮网纹，fwidth 抗锯齿；只集中在水边 / 浅水（4 点采样水遮罩）、发光潭、钟口溢光区，深水中央减弱，14–48 米随距离衰减；中档单层、低档关。
- 沙地：沙斑 + 全图零散沙斑（先填砖缝低处再盖砖面），砖缝沙淤（贴图里），沙纹法线加强。碎砖翘起（instanced 板片）+ 碎块 / 贝壳砾（高 160 / 中 80 / 低 24 片）。
- 铜钟：3 口程序化主角大钟（车削真实钟形 + 钟纽 + 箍，铜绿锈贴图含流痕 / 金属度 / 法线），钟顶埋进沙丘、钟口斜朝上溢青光（内壁发光 + 钟口光面 + 地面溢光 + 高档点光源），放在钟影潭水边；原角落 Lux 钟换成程序化。
- 海草约 3 倍（高 210 / 中 140 / 低 40 簇），聚簇在钟 / 礁石 / 水边 / 发光潭，深绿 / 橄榄 / 黄橄榄 + 高光；锁链从钟纽拖出平滑随机蜿蜒。
- 水面：正上方更透、掠射角镜面；月光倒影亮斑（窄核 + 碎闪，方向与天上月亮精灵一致）；岸边连续白色浪沫线 + 碎沫；薄雾 3 层，按水遮罩在水边贴地更浓。
- 光点：改为实例化朝镜头四边形圆形柔光；本图里把本体无贴图 / 固定像素的方块点（星点等）运行时克隆材质改成圆形（不改本体代码）。
- 新机位：seashots 8_概念构图（水边低机位看钟楼倒影）。
