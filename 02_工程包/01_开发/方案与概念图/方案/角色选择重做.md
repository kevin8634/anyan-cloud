# 角色选择重做（select-ui 分支，2026-10-27）

概念图：04_方案与概念图 select_A_arc（默认）+ select_B_detail（选中）。

## 交互
- **A 态（默认）**：实时 3D 背景，全部职业弧形站位（本体 4 个 / DLC 6 个），脚下只有名字牌；左上标题，左下小按钮（重看开场 / 开场动画 / 全屏 / 操作说明），右下一个按钮：
  - 有选中的角色 →「进入 · 角色名」直接进游戏；没有 →「选择职业」打开 B 态。
  - 选中的职业脚下有橘色光圈。
- **点名字牌或直接点 3D 模型** → B 态：镜头推到该职业前方（角色偏左），右侧玻璃详情面板滑入，底部名字牌变成头像条（可直接切职业）。
- **B 态面板**（数据全部取自职业表 / CLASS_INFO，不新增数值）：职业名、定位、简介、初始生命 / 暴击 / 护甲 / 攻击方式、操作难度、专精（天赋树 specs）、招牌技能（点一下看演示）、该职业的角色列表 +「新建角色」空位、名字 / 配色、进入按钮，导入 / 导出 / 删除。
- ✕ 或 Esc 回 A 态。

## 结构
- `src/web/selectstage.ts`：背景区域、站位、镜头（A 机位 / B 推近）、名字牌投影、点选判定。选中职业那一位由玩家模型站（带选中角色的配色和装备）。
- `src/web/title.ts`：renderTitle 改成新面板；`#class-pick` / `#start` / `#cs-slots`（仍 8 个子节点，非本职业的加 `.hide`）等 id 全部保留，老测试照常点。
- `core/ContentPacks.ts`：`PackManifest.selectStage`（区域 + 机位 + 弧线 + 放大倍数 + 提亮）。没有包提供 = 本体营地。
- `src/dlc/dlc1/select_stage.ts`：倒钟广场「低角全景」机位（相机位置不变，视线 y 5→2.5），站位在前景浅水石滩，模型放大 1.4 倍，环境光 +80%。
- 画质「低」或触屏：DLC 背景不生成，退回营地（省内存 / 加载）。
- 截图：`node dev/selectshots.mjs <html> <目录> <前缀> [画质] [宽x高] [调参.json] [B 态点第几个]`；对比拼图 `python3 dev/selectcompare.py`。
- 调参：`window.__selTune = { cam, arc, fov, focus, fill }`。
