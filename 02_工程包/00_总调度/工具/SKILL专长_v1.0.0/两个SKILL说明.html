Lux3D 资产流水线 + 积分账本

lux3d-asset-pipeline
一句话生成 3D 模型，自动处理成网页能用的资产；花积分前先过预算闸门，超了直接拦下。
  • 生成：文生 / 图生 / 四视图生 3D、绑骨
  • 压缩：自动减面 + webp + meshopt，实测体积降 37 倍
  • 预算：按用途分额度，单次上限，批量先估价
  • 对账：导出积分明细，可直接写进参赛报告
# 立预算 → 估价 → 演练 → 生成 node scripts/ledger.mjs init --total 475 --cat … node scripts/plan.mjs estimate plan.json node scripts/plan.mjs run plan.json --yes

WebGL 视觉回归 QA

webgl-visual-qa
发版前自动截图，和上一版逐张对比，画面被改坏、黑屏、报错一眼看出来。
  • 截图：等加载、等特效散、隐藏 UI、固定镜头
  • 对比：区域 SSIM + 差异热图，小物体变色也能抓到
  • 体检：控制台报错、帧率、空白帧
  • 资产：GLB 面数 / 贴图 / 体积超标检查
# 一条命令：截图 → 对比 → 预算 → 报告 bash scripts/qa-run.sh qa.json qa/ assets/ v1.0 # 0 通过 · 3 待人工确认 · 1 不通过 node scripts/glb-budget.mjs assets/
