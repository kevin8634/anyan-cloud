## 2) DLC 主城「鸣钟港 Bellharbor」评估

**结论：可行，但不建议照构思稿全量在赛前做。** 框架都有现成挂点（新野外区域、营地、传送阵、交互点、包 NPC、存档字段），技术上没有硬阻塞；真正的成本在「把 NPC / 任务 / 领地 / 副本入口搬家」，这部分会碰剧情和存档，而且和 raidA 的长副本合并、11-18 提交抢时间。建议**赛前只做「新增不搬家」的精简版，全量（取代旧营地 + 结局分化）放赛后**。

### 2.1 与现有内容的冲突（已核对代码）
1. **「取代」营地会坏回城。** web/travel.ts `recallDest()` 回的是「当前野外的 main 营地」（`w.camps.find(c => c.main)!`），`allCamps()` 直接从各野外 `camps` 生成传送列表；潮痕营地（coast.ts:89 `cs_camp`）、倒钟广场（mirror.ts:97 `mr_camp`）、钟楼脚下（belltower.ts:130 `bt_camp`）都是 main 营地。删掉会让回城/读档落点报错。→ 旧营地必须保留（可降级为「前哨」），想让 DLC 内回城统一回鸣钟港，要在本体加一个**通用可选挂点**（如 PackWild 增加 `recallTo` / PackManifest 增加 `recallHome(zone)`，core/ContentPacks.ts + travel.ts `recallDest()`），只用通用词。
2. **剧情时序：卡戎还没登场。** 构思稿第七章末解锁，但卡戎在 8-1 才首次出现（chapter8.ts:14 `cs8_1` turnIn `charon`）。双塔圣所西侧的卡戎据点必须 `questState('cs8_1')` 之后才出现。
3. **NPC 是「按区域分身」的，任务写死了 NPC id。** 伊奥拉有 `iola`（海岸）/`iola_m`（镜渊城）/`iola_b`（钟楼），卡戎有 `charon`/`charon_b`；chapter7–9 的 giver/turnIn 都指向这些 id（例：9A-4 turnIn `iola_m`）。整体迁入鸣钟港 = 改三章任务链和对话。→ 建议剧情 NPC 原地不动，鸣钟港只放**服务型分身**（做法同 coast_gate.ts 在灰石营地加墨言分身）。
4. **结局 A/B 与「双塔圣所」矛盾。** 结局 A：伊奥拉留在钟楼成为新的钟声；结局 B：伊奥拉的回响消散（DLC1_沉钟之海.md §四）。结局后两人同时在圣所站岗不成立 → 圣所要按 `DLC1_FATE.choice()` 分化（A：东塔只剩钟声与伊奥拉的光影，卡戎离开；B：东塔熄灭成纪念碑，卡戎留下）。
5. **「活人后裔」与设定冲突。** 设定里伊奥拉是「最后一个鸣钟人的回响」，地底没有活着的鸣钟人后裔。→ 改为「从地表下来的冒险者 + 沉船拾荒者」，正好接上比赛版营地 A「沉船拾荒营」（camp_lux.ts）的美术。
6. **结局 A 领地的位置。** 领地 8 座建筑建在镜渊城 8 块地上（domain.ts `BUILDINGS[].plot`，domain_world.ts 在镜渊城建造），结局字幕是「镜渊城的灯一盏盏亮起」。构思稿「鸣钟港原地升级」= 重写 domain_world + 改结局文案。存档 `dlc.dlc1.domain` 只按建筑 id 存等级，不存坐标，所以**搬位置本身不需要存档迁移**，但剧情上建议领地留在镜渊城，鸣钟港各区只「反映」领地等级（如训练场等级高 → 港口训练场多一排木桩）。另外映射对不齐：构思稿把「回响学会 + 档案馆」并一区、「训练场」拆一半给远征厅，「钟楼」对钟心广场，需要重排。
7. **40 级副本名字和位置。** 代码里 40 级副本叫「钟铜熔炉」（forge.ts，`dlc1_forge_dg`），入口是钟楼脚下营地西侧铜梯（belltower.ts:133 `dungeonGates`，forge.ts:20 `FORGE_GATE_BT`），设定是「无声钟楼地下的铸钟熔炉」。构思稿叫「铸钟坊」并要把入口搬走 → 建议保留原入口，在鸣钟港铸钟坊**加第二个入口**（新野外的 `dungeonGates` 里再挂一次即可），名字统一为「钟铜熔炉」，「铸钟坊」只指港口里的铸造工坊。
8. **40 级长副本不是「无声钟楼」。** 无声钟楼是第九章的 38–40 级剧情区；40 级长副本 A 是 raidA 分支的「潮渊钟井」（raid_well.ts：从无声钟楼脚下锈梯进入，海岸 B 区井口是地标），尚未合并主线，B 还没定。远征厅赛前只能做占位/传送，接任务线要等 raidA 合并（ContentPacks.ts / title.ts / main.ts 要逐段合）。
9. **铸造台入口。** 现在从伊奥拉（潮痕营地）/ 戈兹（镜渊城）对话框按钮进（smithy.ts 头注）；鸣钟港加一个 `interacts` 交互点即可，不冲突。铸造 CG 接入（11-05–11-07）可以直接以铸钟坊为舞台。
10. **解锁等级与「30–40 主城」不符。** 第七章末（cs7_6，minLevel 32）才解锁，30–32 级还在潮痕营地 → 名义上「取代」不了。建议 7-1 交任务后就开（或 7-0 下行后直接落在港口），潮痕营地保留为前哨。
11. **存档。** 新野外 id（如 `dlc1_hub`）、新营地 id 进 `GameSave.waypoints[]`，位置存 `GameSave.map/pos`，都不需要 SAVE_VERSION（现 10）+1；包数据走 `manifest.saveData` 新开 `dlc.dlc1.hub`。老存档：已完成 cs7_6 的直接视为已解锁（参照 7-0 的老存档处理）。本体读 DLC 存档时在 DLC 区域会被送回营地（框架已有）。
12. **纯净规则。** 鸣钟港所有内容放 src/dlc/dlc1/；本体只加通用挂点；`purity.json` tokens 要补「鸣钟港」「Bellharbor」「铸钟坊」「远征厅」「双塔圣所」等专名（manifest 的 name 会自动收）。
13. **性能。** 又一座密集城镇；沉钟海岸 ultra 已 6520 件实例。鸣钟港要按四档画质分级、实例化合批，手机 30 帧仍是硬指标。比赛版 Lux3D 件只进 assets_aholo/，商用包要有程序化回退。

### 2.2 建议调整
- 定位：「新增的 DLC 枢纽」而不是「取代」；旧营地降级为前哨，剧情 NPC 不搬。
- 解锁提前到 7-1 后；回城统一回港口用本体通用挂点实现。
- 区域重排为与领地一一对应：钟心广场=钟楼、铸钟坊=铁匠工坊（铸造台 + 钟铜熔炉第二入口）、回响学会=回响学会、潮汐码头=潮汐码头（渡船=到海岸/镜渊城/钟楼的传送）、双塔圣所=圣所、港口市集=市集、训练场=训练场、远征厅=档案馆（远征名册 + 长副本任务线，raidA 合并后接）。
- 领地仍在镜渊城，港口只做「镜像」反馈；结局分化放赛后。
- 可选项排序：观景台（拍照模式机位，0 新系统，宣发直接受益）> 回声剧场（复用 CG/预告）> 悬赏板（世界首领每日悬赏）> 沉钟潮周事件 > 结局 A/B 分化。
