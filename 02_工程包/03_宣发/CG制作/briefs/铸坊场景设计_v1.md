# 鸣钟人铸坊：可走进去的铸造场景 v1（2026-10-31）
现状：smithy.ts 由 NPC / 评委引导按钮打开面板；forgeshow.ts 是叠在画面上的成形演出。
改为：NPC「带你去铸坊」，传送进一个小场景（src/dlc/dlc1/foundry.ts，DLC 铁律），五个工位按地面符文路线走完。
1 图纸台：羽毛笔写一句话 → 在线出 3 张图纸（Credits，经云函数代理）钉在桌上，走近挑一张；离线用预制图纸。
2 选材架：沉钟铜 / 潮晶 / 骨铁，只改材质颜色与流光（铸造只改外观，不改属性）。
3 熔炉：图纸投进炉口；等 Lux3D 的 30–120 秒做成「拉风箱 + 跟钟声节奏敲铃」小互动，敲准火更旺、出炉流光更亮（纯外观）。
4 浇铸池：沿用 forgeshow 溶解成形，图纸线条自下而上烧成金属。
5 淬火池 + 试刀桩：插进淬火池冒蒸汽、颜色冷却，拿去试刀桩砍几下，接拍照 / 分享卡。
快捷：第二次起 NPC 处保留「快速铸造」直接开面板；评委引导第 1 步改为进铸坊（可跳过演出）。
工作量约 2 天；场景件约 8 件（铁砧、风箱、炉口、图纸台、材料架、浇铸池、淬火池、试刀桩），Lux3D 估 80–160 积分，走储备，需 Rhett 确认。建议放阶段 3（11-05–11-07 评委路线精修）。
