# 《暗岩传说：深渊回响》角色中英名表 v1

整理：2026-11-01 · 只读整理，未改动任何游戏代码。来源：`anyan/src/data/*.ts`、`anyan/src/dlc/dlc1/*.ts`、`anyan/src/web/enemy_types.ts`、`anyan/docs/设计/DLC1_沉钟之海.md`、`anyan/docs/设计/未来开发报告/未来开发报告.md`、`cloud/01_交接/NPC换模型方案_1031.md`。

## 说明
- **英文名风格**：欧洲黑暗奇幻，庄重、好读、可在预告片里念。人物用音译 + 称号（称号单列）；怪物 / 首领用意译。汉式人名（墨言、青禾、徐砚等）用拼音。已在 CG 资料使用的 **Iola / Charon / Morveth / Aethelon** 保持不动。
- **英文全称怎么拼**：人物 = 英文名 + 「, 」+ 称号，例 *Moyan, the Chronicler*、*Morveth, The Abyssal Maw*；无本名的怪物直接用英文名。
- **性别**：写了「文档：…」的是代码 / 文档原文依据；镜渊城回响居民的性别取自 `plaza_dress.ts` 的写实底座（m / f）；「推定」是按名字、称号或模型推断，需要时请确认。
- **声线建议**只给会说话的角色（有台词、喊话或配音稿的 NPC / 首领）；「—」= 不说话，只有音效。主角团在游戏内不说话，括号里的声线只在预告需要时参考。
- **代码 id** 只作对照参考，不是英文正式名。
- 「普通怪（首领召唤物）」指首领战里召出的小怪；「精英（稀有）」= 稀有首领。
