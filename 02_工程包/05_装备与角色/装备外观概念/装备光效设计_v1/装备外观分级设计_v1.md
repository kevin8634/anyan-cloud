# 装备上身外观分级设计 v1（换装即换外观）
2026-11-03 16:00 CST · 03 宣发 · 设计稿，待 Rhett 审；实现归 01 开发

## 0. 光效会不会影响装备模型？
- 不改网格：光效 = 同一个模型上的「材质层」（Shader 参数）+ 挂在骨骼上的粒子 / 脚下 Decal。换装备不用为光效另做模型。
- 要做的只有一张「发光遮罩」贴图（MaskMap 的一个通道，标出哪里能亮：甲缝、符文、宝石、刃口）。橙装、暗金、套装件出模时一起出遮罩。
- 不影响绑骨：粒子和 Decal 不加骨头，只挂在现有骨骼节点（手、胸、脚底）上；装备件仍按绑骨硬规则走 Lux3D 链路，权重从基础身体转移。

## 1. 换装系统（Unity 模块化角色）
- 一副骨架（Lux3D humanoidAutoRig 出的标准人形）+ 基础身体 + 7 个可换槽：头、肩、胸、手、护腕、腿、武器（主手/副手）。
- 每个装备件都是蒙皮到同一骨架的 SkinnedMesh，换装 = 替换 mesh + 材质，骨架不动；身体被盖住的部分用「隐藏遮罩」关掉，防穿模。
- 甲型按职业分 4 套底模：板甲（战士）、布甲（法师）、皮甲（时砂行者）、炼金防护服（炼金投弹手）。同部位同甲型共用一个底模。
- 装备件出模规则：先在严格 T 字基础身体上做（绑骨硬规则 2），出模后把身体权重转移到装备件；不合格件进 _archive_Apose/。

## 2. 品级外观
| 品级 | 网格 | 材质 / 光效 | 统一还是独特 |
|---|---|---|---|
| 白 / 绿 | 每甲型每部位 1 个底模 | 旧铁、粗布、磨损；不发光 | 统一 |
| 蓝 | 同底模 | 换贴图：加铜边、铆钉、布纹镶边 | 统一 |
| 紫 | 同底模 + 1 个小挂件（护心镜、肩钉、宝石扣） | 宝石微弱呼吸光 | 统一 |
| 套装 | 每套 6 件专属网格（整体轮廓 + 统一配色 + 签名纹样） | 2/4/6 件逐级点亮，6 件签名光效（见装备光效设计 v1） | 每套独特 |
| 橙（传说） | 每种武器 1 个精修网格（更多面数、雕纹、宝石） | 发光遮罩 + 流光 Shader，按武器种类定色 | 同武器种类统一 |
| 暗金 | 每件 1 个专属网格，轮廓一眼认得出 | 专属材质 + 专属粒子 / 动态 | 每件独特 |

武器（绿/蓝/紫）：每种武器（单手剑、斧、锤、巨剑、巨斧、盾、法杖、魔杖、轮刃、药瓶……）一个底模，品级只换贴图：绿 = 素铁，蓝 = 铜护手 + 刃纹，紫 = 宝石 + 符文槽（不亮或微亮）。
橙武器：同种类统一精修模型；刃口 / 杖头符文沿遮罩流光，挥动带淡拖尾。
暗金武器（举例）：
- 裂地者（巨斧）：斧刃是一整块熔岩岩石，裂缝里岩浆缓慢流动；劈砍落地留下发光裂痕 Decal 2 秒。
- 寒脊之骨（剑）：剑身是骨龙脊椎骨节，节间冰晶；握柄结霜，挥动掉落冰屑，周围有冷雾。
- 霜心（魔杖）：杖头是一块碎镜，镜里映着一个微笑的女子（维瑟拉）；镜面偶尔闪出她的脸，施法时碎镜片环绕旋转。

## 3. 套装上身（6 件凑齐的样子）
- 狂怒战魂：黑铁重甲 + 兽骨角盔 + 骨刺肩，暗红披布，甲缝熔血纹。
- 霜誓秘仪：冰蓝镶白法袍，冰晶肩饰与兜帽，左半身霜花，右手冷焰。
- 时痕：深棕皮甲 + 黄铜钟表零件，背后小钟盘，金沙纹。
- 赤青碧：鸟嘴面罩兜帽 + 长衣，腰间赤青碧三色药瓶，三色药雾。

## 4. 优先级与显示
- 显示顺序：暗金武器 > 橙武器 > 套装 > 紫 / 蓝 / 绿。
- 外观幻化（以后可做）：允许把已收集的外观盖在当前装备上，属性不变。
