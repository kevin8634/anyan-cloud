# 装备外观系统规格 v0.1（05 装备与角色 → 01 接入）

2026-11-03 23:55，方向已由 Rhett 批准：属性与外观分离，参照暗黑 4 的幻化思路，商业化只卖外观。
本文只是规格，代码由 01 接入，05 不改主线。

## 1. 外观 ID（appearanceId）
- 外观是独立的数据表 `APPEARANCES`，与装备属性脱钩。
- ID 规则：`{职业}_{部位组}_{名称}`，例如 `warrior_body_default`、`warrior_body_set_fury`、`mage_weapon_staff_A`。
- 字段：`id, cls, part('body'|'head'|'shoulder'|'weapon:<weaponType>'), mesh(glb 路径或 null), kind('default'|'base'|'set'|'dark'|'shop'), source（解锁来源）`。
- 以后加付费套装，只需往表里加一行并配上 mesh，不改代码。

## 2. 初始外观：问题的解法
- 每个职业绑好骨的本体（`models_hd/LUX_{职业}.glb`）就是该职业的默认身体外观 `{cls}_body_default`，建号时自动解锁，永远可选。
- **绿、蓝、紫、橙普通装备不带 appearanceId**，穿上后不换模型，显示规则是：当前幻化外观（未幻化时为 default）叠加该部位最高品质的换色和光效。
- 套装件和暗金件带自己的 appearanceId，**首次获得时自动解锁并收藏**。
- 存档新增：`appearance.unlocked: string[]` 和 `appearance.equipped: Record<part, id|null>`（null 表示跟随装备，也就是 default）。老存档默认全部为 null，不需要迁移。

## 3. 品质表现（不换网格，只用 shader）
| 品质 | 护甲遮罩区 | 武器 |
|---|---|---|
| white / green | 原色 | 无特效 |
| blue | 品质色乘算 15% | 刃口微光 |
| purple | 乘算 25% + 细节流光 | 常亮辉光 |
| orange | 乘算 30% + 较强自发光 | 辉光 + 挥砍拖尾 |
| dark | 有独特模型；没有模型时按 orange 处理，颜色改用 #C9A44C | 独特武器加专属小特效 |
- 颜色直接引用 `QUALITY_COLOR`（Loot.ts），和背包品质框、地上光柱保持一致。
- **分 4 区染色（23:58 定）**：每个职业的贴图配一张 RGBA 的 `armorMask`，由 05 出（0 积分）。R 管头部和肩部，G 管胸甲和腰带，B 管护腕和手套，A 管腿甲和鞋子；披风不显示。每区取其中两件里较高的品质。
- 只给金属和饰边上色，布料和皮肤不上色，以免五件不同品质穿在身上时花成一片。
- 同一品质穿满 8 件时，全身加一层同色的微弱轮廓光，作为凑齐奖励。
- 元素词缀决定武器光的色相（火红、冰蓝、毒绿），品质只决定强度。属于可选项，放 DLC1。

## 4. 武器
- `weaponType` 决定通用模型，每类 3 个模型 A/B/C（23:58 定），沿用现有 15 类：sword, axe, mace, greatsword, greataxe, shield, staff, wand, dagger, tome, orb, chakram, hourglass, flask, reagent。
- 挂在手部骨骼插槽上（mixamorig:RightHand / LeftHand 或转 UE 后的同名插槽），不需要绑骨。
- 模型选择：按物品 uid 哈希取 A/B/C，同一件装备的外观固定不变。
- 武器幻化同样走 appearanceId，限定为同一 weaponType。

## 5. 硬质挂件（DLC1，可选）
- 肩甲、头饰、护腕挂到骨骼上，是不变形的小网格。紫、橙随机挂一个，加强轮廓。可以从套装网格里拆件复用。

## 6. 幻化界面（DLC1）
- 角色面板加「外观」页签：按部位列出已解锁外观，点一下即应用，并提供转动预览。
- 免费，不收费。商城以后只卖 `kind:'shop'` 外观，不带属性。
