## 1. 总体设计

### 1.1 一条原则：一件武器 = 一条改写打法的规则

六件都不给「技能伤害 +X%」「冷却 -X%」这类纯数值行；强大来自**一条新规则**，再用 1~3 条配套修饰器把规则和本职业的资源 / 三系 / 大招接上。底材属性（强度、暴击等）和随机词条照旧（双手 4 条、双持每件 2 条），那是装备本来就有的，不算特效。

| 职业 | 武器 | 一句话规则 | 打法从 → 到 |
|---|---|---|---|
| 战士 | **偿潮**（双手巨剑） | 受到的伤害先记账（潮债），用刀还；大招一次性清账爆发 | 躲伤害 → **主动吃伤害换输出**，负债越高越不可阻挡 |
| 法师 | **相冲星仪**（双手杖） | 火 / 冰 / 奥三相，**换元素施法就起反应**（蒸裂 / 凝滞 / 跃迁） | 单系转圈 → **编排元素顺序**，普攻也成了反应引子 |
| 灵契猎手 | **三魂同契**（双手长柄弯刃） | 换形技命中后，离开的形态**残留 10 秒**；三相齐亮 → 下一招「祖契」 | 常驻一个形态 → **三形态轮舞**，一招同时带感电 + 破甲 + 标记 |
| 负棺人 | **不眠棺**（葬棺） | 棺里的魂**按种类给被动**；棺满再收魂，最老的魂自动出棺 | 攒满就开 → **留着还是放？**，杀怪 = 连续的小开棺 |
| 时砂行者 | **赊刻之轮 + 还时沙漏**（双持） | 冷却中的技能可以**向未来赊**一次；回溯把过去 3 秒的技能**重演**；两件齐 = 回溯**清掉赊账** | 等冷却 → **透支爆发 → 回溯重演并还清** 的循环 |
| 炼金投弹手 | **蚀骸药瓶 + 吞潮试剂匣**（双持） | 死在药区里的敌人**化成新药区**；推进烟雾**吸走药区**，下一瓶**整片倒在落点**；两件齐 = 倒下的药区**彼此反应** | 定点布场 → **收场搬场**，把整片战场倒到首领脚下 |

### 1.2 与现有 40 级暗金（v1.2.38b）的关系：**建议替换**，不做第二件

理由：
1. **同槽位互斥**：两件都是武器（双手 / 主副手），身上只能装一件；拓印也只在武器之间互通。做成「第二件」不会让玩家同时拥有两套效果，只会稀释掉落。
2. **掉落稀释**：沉眠者 8% 只掉本职业一组；数组里变成 2 件（双持职业变 4 件），拿到想要那件的期望时间翻倍。
3. **旧件偏数值**：回响星盘 3 条里 2 条是纯数值（+15% 伤害、大招冷却 -20%）；渊噬试剂匣是条件 +22%；双持「成长」套 2 件是纯 +25%；沉钟裂潮 / 九钟安魂 / 潮汐祖灵是「叠层 → 爆炸 / 余震」，和 40 级套装、钟楼套的爆炸余波重复。正是 Rhett 这次要避开的方向。
4. **主题延续**：新六件沿用旧件的底材、槽位、幽影绿发光和「沉钟之海」主题，替换后外观风格不断档。

替换做法（二选一，需 01 按存档现状定）：
- **A（旧件还没进玩家存档）**：直接删旧 `DLC1_DARK` / `D40_SETS` / 旧 `hitRules`，换成本规格的定义。
- **B（已有存档持有旧件）**：旧件定义保留（照常能穿，不再掉落），只从 `DARK_BY_CLASS` 拿掉；另给一个一次性迁移表 `D40_MIGRATE = { d40_w_tide: 'd40_w_ebb', … }`（同本体 `RELIC_TO_DARK` 写法），读档时把旧件换成同职业新件、保留词条。**我建议 B + 迁移**：玩家手上的旧件直接变成新武器，不会觉得被削。

### 1.3 双持职业（时砂 / 炼金）的结构

沿用现有槽位：**主手 oneHand + 副手 offHand 两件暗金**，各自一条**能单独成立**的规则；两件齐了再给一条「闭环」套装效果（把两条规则接成循环），**替换**旧「潮涌」+2.5%/层。套装 id 沿用假 cls 写法（`dlc1_d40_chrono` / `dlc1_d40_alchemy`），避免被 `classSet()` 当成长副本职业套装。

## 2. 战士 · 偿潮 `d40_w_ebb`

| 项 | 内容 |
|---|---|
| id | `d40_w_ebb` |
| 名称 | **偿潮** |
| 槽位 | `twoHand`（**双手巨剑**） |
| 底材 | `b_greatsword_d40`（沉钟巨剑，沿用） |
| 词条 | 4 条随机 |
| 风味 | 海从不白给。它借你一口气，你就得用一刀还回去。 |

### 2.1 核心特殊效果：潮债（初稿数值）

**① 记账**：你受到的伤害（护甲 / 减伤结算之后）有 **35%** 不立刻扣血，记为「潮债」，在 **4 秒**内匀速流失（每次新入账重算流速）。潮债上限 = **最大生命 50%**，超出部分照常立刻扣。潮债流失**可以致死**（不是免死，是延后）。

**② 偿还**：
- 技能 1~4 命中：本次施放清掉当前潮债的 **30%**，并附加一段**同元素**伤害，潮债越多越痛（修饰器：每 1% 潮债 = 本技能 3% 伤害，50% 封顶 = +150%）。
- 普攻（英勇打击 / 致死打击）命中：清掉 **10%**，附加每 1% 潮债 = 1% 伤害。
- 偿还伤害算「这次技能的一段独立元素伤害」（`elemHit`，独立暴击）。元素随技能走：物理技能还物理，雷霆一击 / 地震波 / 震荡波还自然。

**③ 退潮（大招）**：天神下凡 / 剑刃风暴 / 战旗 / 盾墙 施放时**一次清空全部潮债**，命中时额外爆开「退潮」（半径 7，每 1% 潮债 = 6% 伤害，30% 潮债 ≈ +180%），并按退潮伤害吸血（每 1% 潮债 = 1% 吸血）。

**④ 负债霸体**：潮债 **≥15%** 最大生命时，你免疫眩晕和击退（「被海托着」）。

### 2.2 打法怎么变

- 以前：战士靠冲锋切入、旋风清场，掉血就拉开或吃药，伤害和受伤无关。
- 现在：**受伤 = 弹药**。首领的重击不再是一次掉 40% 血，而是 26% 立刻 + 14% 记账；你要在 4 秒内用技能把账「还」掉（还的那部分不再扣血，还变成伤害）。负债 ≥15% 有霸体 → 战士会**主动站在红圈边缘吃一下**，带着债冲进去。大招从「冷却好了就放」变成「**攒满债再放**」：吃一波伤害 → 账面 30%+ → 天神下凡清账爆发 + 吸血回满。
- 风险：账没还完就脱离战斗，潮债会照样流完 → 不能「吃一口就跑」。

### 2.3 与三系 / 大招

| 系 | 怎么咬合 |
|---|---|
| **裂伤**（流血；终极 致死打击） | 偿还段是**物理技能命中**的一部分 → 叠撕裂 / 深创流血；致死打击是普攻，也偿还 10%，配合「对有持续伤害目标 +20%」 |

## 3. 法师 · 相冲星仪 `d40_m_clash`

| 项 | 内容 |

| 槽位 | `twoHand` |
| 底材 | `b_staff_d40`（星盘长杖，沿用） |
| 词条 | 4 条随机 |
| 风味 | 三股潮水在星仪里相撞——火遇冰会炸，冰遇星会停，星遇火会跳。 |

### 3.1 核心特殊效果：三相潮印 + 相冲反应

**① 点亮潮印**：你的任意技能（含普攻）命中后，星仪上对应元素的潮印亮起 **5 秒**：火 → 火印，冰 → 冰印，奥术**或自然**（闪电链）→ 星印。印记挂在**星仪（你身上）**，不挂在敌人身上 → 换目标、打群怪都成立。

**② 相冲**：技能 1~4 施放时，如果星仪上亮着**另一种元素**的潮印，就熄灭那枚印、发生反应：

| 反应 | 组合（顺序不限） | 效果（初稿） | 内置冷却 |
|---|---|---|---|
| **蒸裂** | 火 × 冰 | 命中处爆炸（半径 3，100% 伤害） | 1.5 秒 |
| **凝滞** | 冰 × 星 | 冻结 1.2 秒 + 打断 + 减速 50%（3 秒）；首领只打断 | 3 秒 |
| **跃迁** | 星 × 火 | 本技能弹向 3 个附近敌人（7 米，每跳 60%） | 1.5 秒 |

一个技能可以同时撞两枚印（例：冰技能撞上火印 + 星印 → 蒸裂 + 凝滞 一起出）。同元素不起反应。普攻只点亮、不触发（避免普攻刷反应）。

**③ 大招相冲**：大招施放时，所有亮着的异元素潮印**同时反应且不熄灭**，效果翻倍（蒸裂半径 4 / 200%，凝滞 2 秒，跃迁 5 跳 70%）。陨星（火）、冰河时代（冰）、奥术风暴（奥）各自能撞的印不同 → 大招选择会影响前置的施法顺序。

### 3.2 打法怎么变

- 以前：单系法师按冷却转圈，奥能充能鼓励换元素但只是「4 次后一发强化」。
- 现在：**每一次换元素都是一次反应**。施法顺序变成编排题：「奥能弹（亮星印）→ 烈焰弹（跃迁弹 3 个）→ 霜环（火印还在？蒸裂；星印还在？凝滞）」。普攻奥能弹第一次成为**反应引子**，不再只是填空。三相印会在技能栏 / buff 栏显示，玩家能看见「下一招会撞出什么」。
- 和奥能充能叠加：换元素同时 +1 奥能，4 层满溢那一发多 1 发、范围 +50% → 满溢技能撞两枚印 = 一次大型双重反应。

### 3.3 与三系 / 大招

| 系 | 怎么咬合 |
|---|---|
| **炽焰**（火焰暴击、炽燃；终极 熔火陨星） | 炽焰主火，奥能弹天然给星印 → 每发火球都能「跃迁」，炽燃随弹跳扩散；熔火陨星是火大招，撞冰 / 星印双倍反应后再留熔岩 |
| **凛冬**（冰脆、寒流；终极 碎裂霜环） | 冰 × 星 = 凝滞（冻结），正好喂「冰脆」+20% 与碎裂霜环「冻结目标 +40%、碎裂」；冰河时代撞火印 = 双倍蒸裂 |
| **星痕**（奥术易伤叠层、满溢；终极 连锁禁锢） | 连锁禁锢本身弹 3 次，撞火印再跃迁 → 一次禁锢打满一片；奥术易伤靠多次命中叠，反应额外段都算命中；奥术风暴撞冰 / 火印 |

### 7.1 核心特殊效果

**主手 · 蚀骸**：敌人**死在你的药剂区域里**时化成一片同种新区域（半径 ×0.7、持续 4 秒；精英半径 ×1.2）。同一片区域最多「生」2 次。尸体同时躺在**两种不同**区域里 → 立刻在尸体处发生对应地面反应（爆燃 / 蒸汽 / 冰晶毒，照常 +20 热度），不用再投药。

**副手 · 吞潮**：推进烟雾（F）向后跳的同时，把 **8 米内你的药剂区域**（最多 4 片）和**大釜**吸进匣子：每吸一片 +1 格该颜色试剂、+10 热度。你的**下一瓶药**（技能 1~3 / 混合）落地时，「倾倒」：吸进去的区域全部在落点周围重新铺开（持续时间回满、半径 ×0.85），大釜在落点重新放下（剩余时间 +3 秒）。

**两件齐 · 炼潮**：倾倒出来的区域**彼此之间立刻反应**（每一对一次：火 + 毒 = 爆燃、冰 + 火 = 蒸汽、毒 + 冰 = 冰晶毒），这些反应给的热度 **×2**。

### 7.2 打法怎么变

- 以前：炼金在固定点布区域，靠下一瓶药落在旧区域上引反应；推进烟雾是逃生键；区域放下就只能等它消失。
- 现在：**区域是可以搬的弹药**。小怪群里：铺毒池 → 怪死在池里继续生池（蚀骸）→ 场面越清越满。首领战：在安全处铺好火、毒、冰，F 后跳吸走，下一瓶直接把整片战场倒在首领脚下，三种区域同时铺开、互相爆燃 / 蒸汽 / 冰晶（炼潮），热度一下满到沸腾。推进烟雾从逃生键变成**每 12 秒一次的「搬场」**。
- 炮台流的大釜第一次能**移动**：吸走 → 倒在新位置。

### 7.3 与三系 / 大招

| 系 | 怎么咬合 |
|---|---|
| **爆破**（火焰暴击、范围；终极 连锁殉爆） | 倒下三片毒池 + 一瓶红 → 连锁殉爆把 6 米内所有毒 / 酸池接连点爆；炼潮的火 + 毒对子自带一次爆燃 |
